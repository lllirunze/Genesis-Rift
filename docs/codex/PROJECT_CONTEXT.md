# 项目快速上下文

《开天辟地之大地的裂变》是致敬《爱情公寓》第三季同名桌游的局域网多人数字桌游。项目以“探索世界、获得资源、角色构筑、推进隐藏使命并完成任意三项使命获胜”为核心循环；规则应保留原作的聚会感，但必须公开、可验证且不破坏公平。

项目是 npm workspaces 单仓库，使用 TypeScript。`apps/web` 是 React 19、Vite、Zustand 与 Socket.IO Client 的浏览器界面；`apps/server` 是 Node.js、Socket.IO 的局域网权威服务；`packages/game-core` 是无框架、无文件系统依赖的纯规则层；`packages/game-data` 保存静态定义与启动校验；`packages/shared` 保存跨端类型、配置与网络协议。规则只依赖 shared，服务端负责命令校验、状态编排、权限投影和日志，前端只展示服务端允许查看的状态并提交意图。

一局游戏只有一个活动房间和一个权威游戏会话。完整 `GameSessionState` 聚合玩家角色、资源、状态、背包、装备、手牌、地图、环境与随机状态。服务端通过 `ServerGameSession` 不可变地替换状态；对外快照区分公开信息和仅本人可见的私有信息，不能泄露背包详情、手牌、使命、信仰、契约或完整属性。随机结果必须来自主种子派生的独立随机流，禁止直接使用 `Math.random`；日志必须使用统一日志工具，禁止 `console.log`。

静态资源使用稳定六位编号，例如 `item_000001`、`event_000001`；名称、品质、类型等业务属性不能编码进 ID。定义、配置、运行时状态和执行逻辑必须分离。数值以整数结算为主，配置驱动；装备、状态与其他修饰统一进入属性聚合。元宝是背包中的可堆叠物品，同时也是经济支付单位。

游戏设计真相在 `docs/概念设计/`，工程与代码规则在 `docs/代码开发规范/`。本目录仅用于低 Token 导航，不能替代设计文档或复制源码。进入未知业务前先查 `MODULE_INDEX.md`；已明确目标文件的小改动可直接读取目标文件。完成改动后仅在模块边界、重要规则、路径或架构变化时增量维护本目录。

常规验证命令为 `npm test`、`npm run typecheck`、`npm run build` 与 `npm run format:check`。测试与实现同目录放置并使用 Vitest；配置新增需要同时具有校验或测试。代码使用两空格与 Prettier，文件路径使用 kebab-case，函数变量使用 camelCase，类型和类使用 PascalCase；注释与 TSDoc 使用中文，业务日志消息使用英文。
