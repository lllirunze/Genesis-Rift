# 《开天辟地之大地的裂变》战斗流程

## 1. 文档目的

本文档用于规定单次攻击从发起、响应到最终结束的统一执行流程。

战斗以“单次攻击行为”为基本结算单位，不进入独立战斗场景，也不默认建立攻击双方持续轮流行动的战斗子回合。

玩家、NPC、事件、技能及其他合法来源发起的攻击，均应复用本文档规定的流程。攻击数值与具体伤害公式由《03-攻击与伤害计算》统一定义，本章节不重复规定具体系数。

---

## 2. 战斗触发

### 2.1 主动攻击

玩家可以在自己的回合中，将普通攻击作为一次主要行动发起。

发起攻击前，系统需要检查：

* 攻击方是否拥有当前行动权限。
* 目标是否属于可攻击对象。
* 目标是否处于有效攻击距离内。
* 攻击方是否能够看见或合法锁定目标。
* 攻击方当前状态是否允许攻击。
* 武器、技能或手牌是否满足使用条件。
* 法力、弹药、物品或其他必要资源是否充足。
* 地图、地形及其他规则是否允许本次攻击。

只有全部条件通过后，攻击才视为正式发起。

若任意条件不满足，本次攻击请求立即失败，并且不消耗主要行动、移动力、技能资源、手牌或物品。

### 2.2 其他攻击来源

NPC 行为、事件效果、状态触发及其他世界规则也可以发起攻击。

此类攻击可以不受“玩家必须处于自己的回合”限制，但仍然需要按照自身规则检查目标、距离、状态及资源条件，并复用统一的防守响应、闪避与伤害结算流程。

攻击来源只能跳过自身规则明确排除的步骤，不能因为来源不同而默认忽略防御、闪避或护盾。

### 2.3 攻击与移动

玩家可以先移动再攻击，也可以不移动而直接攻击。

攻击通过合法性检查并正式发起后，攻击方当前剩余移动力立即变为：

```text
当前剩余移动力 = 0
```

即使本次攻击随后被主动防御完全抵消、被自然闪避或未造成有效伤害，已经清空的移动力也不会返还。

正常情况下，攻击完成后不能继续进行普通移动。特殊技能、装备、状态或事件可以改变该规则，但必须明确说明允许移动的时机、距离及是否消耗移动力。

---

## 3. 标准攻击流程

一次标准攻击按照以下顺序执行：

```text
选择攻击目标与攻击方式
            │
            ▼
检查目标、距离、视野、状态与资源条件
            │
       ┌────┴────┐
       │         │
     非法       合法
       │         │
       ▼         ▼
不消耗任何内容  支付攻击成本并清空剩余移动力
                 │
                 ▼
             锁定攻击信息
                 │
                 ▼
          防守方主动响应阶段
                 │
                 ▼
          攻击是否完全失效？
           ┌─────┴─────┐
           │           │
           是           否
           │           │
           ▼           ▼
        攻击结束    自然闪避判定
                       │
                       ▼
                是否闪避成功？
                 ┌─────┴─────┐
                 │           │
                 是           否
                 │           │
                 ▼           ▼
              攻击结束    计算攻击值
                             │
                             ▼
                    结算防御与穿透
                             │
                             ▼
                       计算基础伤害
                             │
                             ▼
                         暴击判定
                             │
                             ▼
                       结算伤害修正
                             │
                             ▼
                         护盾吸收
                             │
                             ▼
                         生命值扣除
                             │
                             ▼
                      击倒与状态检查
                             │
                             ▼
                     记录结果并结束攻击
```

攻击流程中的每个阶段必须完成当前效果及其直接响应后，才能进入下一阶段。

正常情况下，一次攻击结算完成后不会自动触发目标反击。反击、追击、连击及追加攻击只有在技能、装备、手牌、状态或其他特殊规则明确说明时才会发生。

---

## 4. 攻击信息锁定

攻击正式发起时，系统需要建立本次攻击的结算信息。

包括但不限于：

* 攻击方与防守方。
* 攻击来源。
* 攻击方式。
* 伤害类型。
* 武器或技能标识。
* 攻击距离与目标位置。
* 已经支付的行动及资源成本。
* 当前允许使用的响应类型。

攻击方、目标及攻击方式在正式发起后默认锁定，不能在响应过程中随意更换。

防守效果可以按照自身规则修改攻击数值、改变目标或使攻击失效，但这些变化必须记录在同一次攻击上下文中，不能重新创建一项与原攻击无关的普通攻击。

角色属性、装备、状态或其他数据在攻击流程中发生变化时，仅影响变化之后尚未完成的阶段。已经完成的阶段不重新计算，特殊规则明确要求重新判定时除外。

---

## 5. 防守响应

### 5.1 响应阶段

攻击信息锁定后，防守方获得一次主动防御响应阶段。

防守方可以根据当前拥有的内容选择使用：

* 防御类手牌。
* 防御技能。
* 装备主动或触发效果。
* 特殊道具。
* 状态提供的响应能力。
* 其他明确允许在受到攻击时使用的效果。

防守方也可以放弃响应，不使用任何主动防御内容。

所有主动防御必须满足自身使用条件，并在响应阶段关闭前声明。响应阶段结束后，不得返回该阶段补充使用本应提前声明的能力。

### 5.2 主动防御结果

主动防御可以产生以下一种或多种结果：

* 使本次攻击完全失效。
* 降低本次攻击值或最终伤害。
* 提供或增加护盾。
* 修改本次攻击的闪避条件。
* 改变本次攻击的合法目标。
* 为攻击方或防守方添加状态。
* 触发规则明确允许的其他效果。

如果主动防御使攻击完全失效，则本次攻击直接结束，不再进行自然闪避、暴击及伤害结算。

如果主动防御没有使攻击完全失效，则保留其已经产生的合法修正，并继续进行自然闪避判定。

```text
主动防御使攻击失效
→ 攻击结束

主动防御未使攻击失效或防守方放弃响应
→ 自然闪避判定
```

### 5.3 自然闪避

自然闪避只由防守方已经计算完成的最终派生属性“闪避”决定。攻击方不提供“命中”属性，系统也不执行独立命中判定。

自然闪避成功后，本次攻击直接结束，不造成伤害，也不触发普通的“未被闪避后”效果。

自然闪避失败后，攻击直接进入伤害结算。攻击合法性检查只确认距离、目标、状态与使用条件，不得作为另一次隐含的命中判定。闪避与暴击的随机结果统一由战斗随机流产生。

---

## 6. 伤害结算流程

### 6.1 攻击值

攻击未被主动防御或自然闪避规避时，系统根据攻击方式计算本次攻击值。

物理攻击通常按照以下结构计算：

```text
物理攻击值
=
角色最终物理攻击
+
武器物理攻击力
+
技能或攻击方式修正
```

法术攻击通常按照以下结构计算：

```text
法术攻击值
=
角色最终法术攻击
+
武器或媒介法术攻击力
+
技能或攻击方式修正
```

固定伤害、混合伤害及其他特殊伤害类型由对应规则另行说明，不能默认套用不匹配的攻击属性。

### 6.2 防御与穿透

系统根据伤害类型读取目标对应的最终防御属性：

```text
物理伤害
→ 护甲穿透
→ 有效物理防御

法术伤害
→ 法术穿透
→ 有效法术抗性
```

攻击方拥有对应穿透属性时，先削减本次结算中实际生效的防御，再计算基础伤害。

防御、穿透及伤害均遵循数值系统的整数与边界规则。具体公式统一由《03-攻击与伤害计算》规定。

### 6.3 暴击与最终伤害

基础伤害确定后，对允许暴击的攻击进行暴击判定。

暴击判定完成后，再按照当前攻击、状态及防御效果结算其他合法伤害修正，得到本次最终伤害。

不允许暴击的攻击直接跳过暴击判定。主动防御、自然闪避或基础伤害为 `0` 的攻击，不会通过普通暴击规则重新产生伤害。

---

## 7. 护盾、生命与击倒检查

### 7.1 护盾与生命结算

最终伤害优先由目标当前有效护盾吸收，剩余伤害再扣除当前生命值。

```text
最终伤害
    │
    ▼
扣除当前有效护盾
    │
    ▼
是否仍有剩余伤害？
 ┌──┴──┐
 │     │
否     是
 │     │
 ▼     ▼
结束  扣除当前生命值
```

护盾只能吸收其规则允许承受的伤害。若某种护盾只对特定伤害类型有效，则不参与其他伤害的吸收。

伤害不能将当前生命值扣减至数值系统规定的下限以下。

### 7.2 击倒检查

生命值扣除后，系统必须立即检查目标的生命状态。

```text
当前生命值高于 0
→ 保持当前生命状态
→ 攻击结束

当前生命值等于 0
→ 进入击倒状态
→ 攻击结束
```

“击倒”是角色生命值降至 `0` 后的正式运行时状态，不再额外建立其他同义的死亡前状态。

进入击倒状态后，不在当前攻击流程中继续累计击倒回合或直接执行轮回。击倒限制、救援、正式死亡与轮回由《06-生命、击倒与死亡》及《16-模块系统/02-复活与中途加入》统一管理。

若本次攻击同时触发状态、任务、使命、事件或奖励条件，应先完成生命与击倒检查，再按照统一结算顺序将已经确认的战斗结果交给对应系统。

---

## 8. 攻击结束

满足以下任意情况时，本次攻击可以进入结束阶段：

* 攻击在合法性检查阶段被拒绝。
* 主动防御使攻击完全失效。
* 自然闪避成功。
* 伤害、护盾与生命结算已经完成。
* 特殊规则明确提前终止本次攻击。

攻击结束时，系统按照以下顺序进行收尾：

1. 完成当前攻击产生的直接后续效果。
2. 检查击倒及其他必须立即处理的状态。
3. 记录攻击发起、响应、判定、伤害与最终结果。
4. 将已经确认的结果提交给状态、事件、任务与使命等相关系统。
5. 关闭本次攻击的响应窗口与攻击上下文。
6. 返回发起攻击前的外层回合、事件或效果流程。

攻击结束不会自动使防守方进行普通反击，也不会自动推进完整轮次、昼夜、天气或其他世界时间。

---

## 9. 特殊流程

部分技能、装备、手牌、状态或事件可以改变标准攻击流程，例如：

* 攻击后允许继续移动。
* 无视特定类型的主动防御。
* 无视自然闪避。
* 攻击成功后追加额外效果。
* 受到攻击后立即反击。
* 攻击失败后重新判定。
* 同时或依次攻击多个目标。
* 改变攻击目标、伤害类型或结算顺序。

特殊效果只能修改自身明确声明的流程节点。未被明确修改的阶段仍然遵循标准攻击流程。

当多个特殊效果同时生效时，按照统一响应与结算顺序处理。任何反击、追击、连击、追加攻击或重新判定效果都必须明确触发次数与结束条件，不能形成递归触发或无限循环。

V1 阶段不建立复杂的连击、追击或自动反击体系，只保留标准攻击及少量具有明确次数限制的特殊效果。

---

## 10. 设计原则

战斗流程遵循以下设计原则：

单次结算原则

每次攻击均作为一项完整且独立的即时行为进行处理，结束后返回原有流程。

先检查后消耗原则

系统必须先完成攻击合法性检查，再清空移动力或支付其他攻击成本，避免非法请求造成资源损失。

响应优先原则

防守方主动响应先于自然闪避与伤害结算，响应窗口关闭后不得返回之前阶段补充操作。

顺序固定原则

攻击、响应、闪避、伤害、护盾、生命与击倒检查采用统一顺序，不为单个内容随意改变主流程。

职责分离原则

战斗流程负责组织结算，属性、装备、手牌、状态、任务与复活等数据仍由各自系统管理。

特殊规则受控原则

特殊效果只能修改明确声明的流程节点，并必须设置触发限制，避免无限响应与重复结算。

---

## 11. 小结

战斗流程以单次攻击为基本单位，将合法性检查、资源支付、防守响应、自然闪避、伤害、暴击、护盾、生命与击倒检查组织为统一结算链。

攻击开始后不会切换独立战斗场景，攻击结束后也不会自动产生目标反击。通过固定流程与受控扩展机制，玩家、NPC、事件及其他来源的攻击能够共享同一套规则，并为后续伤害公式、生命机制、技能与状态效果提供稳定基础。
