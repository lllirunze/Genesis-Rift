# 《开天辟地之大地的裂变》生命、击倒与死亡

## 1. 系统定位

生命、击倒与死亡系统用于管理角色受到伤害、恢复生命以及失去生存能力后的生命状态变化。

本系统主要负责：

* 当前生命值管理。
* 护盾承伤与扣减。
* 击倒状态进入与解除。
* 击倒回合计数。
* 自救与其他角色救援。
* 正式死亡条件判断。

角色当前生命值降低至 `0` 时不会立即正式死亡，而是先进入“击倒”状态。只有角色在击倒期限内未得到有效救援，或受到明确允许直接致死的特殊效果时，才会进入正式死亡。

整体流程如下：

```text
正常状态
    │
    ▼
受到伤害
    │
    ▼
护盾与生命值结算
    │
    ▼
当前生命值是否为 0？
 ┌──┴──┐
 │     │
否     是
 │     │
 ▼     ▼
保持正常  进入击倒状态
            │
            ▼
       等待自救或救援
            │
       ┌────┴────┐
       │         │
     成功       失败
       │         │
       ▼         ▼
恢复正常状态  达到击倒期限
                 │
                 ▼
              正式死亡
```

正式死亡后的灵魂状态、死亡代价、轮回及重新入场由《16-模块系统/02-复活与中途加入》负责，本系统只向其提交已经确认的正式死亡结果。

---

## 2. 生命状态

角色在一局游戏中使用以下生命状态：

| 状态 | 说明 |
| --- | --- |
| 正常 | 当前生命值高于 `0`，可以按照其他规则正常行动。 |
| 击倒 | 当前生命值为 `0`，角色保留在地图上并等待救援。 |
| 死亡 | 角色已经通过正式死亡判断，等待进入灵魂与轮回流程。 |

生命状态转换如下：

```text
正常
  │
  ├── 当前生命值降至 0 ──→ 击倒
  │                           │
  │                           ├── 当前生命值恢复至至少 1 ──→ 正常
  │                           │
  │                           └── 期限结束或受到处决 ─────→ 死亡
  │
  └── 特殊规则明确直接致死 ─────────────────────────────→ 死亡
```

“击倒”是生命值降至 `0` 后的正式运行时状态，不再额外建立其他同义的死亡前状态。

击倒和死亡属于角色生命生命周期，不作为普通 Buff／Debuff 实例管理：

* 不计算状态层数。
* 不能通过普通驱散移除。
* 不使用普通状态持续时间常量。
* 不能与同名状态重复叠加。

技能需要表现短暂失去行动能力时，应使用眩晕、倒地、冰冻等控制状态，不应复用生命系统的“击倒”状态。

---

## 3. 生命值

### 3.1 当前生命与最大生命

最大生命值属于角色派生属性，当前生命值属于角色运行时资源。

当前生命值始终受到以下边界限制：

```text
当前生命值
=
min（
    max（当前生命值，0），
    最大生命值
）
```

角色当前生命值不能低于 `0`，也不能高于当前最大生命值。

最大生命值发生变化时，当前生命值按照数值系统的统一边界规则处理，不按比例自动恢复或扣除额外生命。

### 3.2 生命值扣除

攻击或其他伤害完成护盾吸收后，剩余伤害用于扣除当前生命值：

```text
结算后生命值
=
max（0，当前生命值 - 剩余伤害）
```

当前生命值结算后仍高于 `0` 时，角色保持正常生命状态。

当前生命值结算后等于 `0` 时，系统在当前伤害及其直接效果完成后检查角色是否进入击倒状态。

### 3.3 生命恢复

治疗、药剂、技能及其他恢复效果可以增加角色当前生命值：

```text
结算后生命值
=
min（最大生命值，当前生命值 + 有效恢复量）
```

恢复量不能使当前生命值超过最大生命值。超出部分属于过量治疗，V1 阶段只记录结果，不自动转化为护盾或其他资源。

正常角色恢复生命时不会改变生命状态。击倒角色恢复至少 `1` 点当前生命值时，按照本章救援规则解除击倒。

---

## 4. 护盾

### 4.1 护盾定位

护盾是用于吸收伤害的额外运行时资源，不属于生命值，也不属于基础属性。

护盾通常来自：

* 技能。
* 装备。
* 道具。
* Buff。
* 事件或其他特殊效果。

护盾来源负责定义护盾数值、持续时间、可吸收伤害类型及移除条件。生命系统只读取当前合法护盾并完成承伤。

### 4.2 护盾承伤

最终伤害优先由能够吸收当前伤害类型的护盾承担：

```text
护盾吸收值
=
min（当前有效护盾，最终伤害）
```

```text
剩余伤害
=
最终伤害 - 护盾吸收值
```

```text
结算后护盾
=
当前有效护盾 - 护盾吸收值
```

护盾降低至 `0` 时只表示该护盾已经耗尽：

* 不会使角色进入击倒状态。
* 不会直接改变当前生命值。
* 后续剩余伤害继续作用于当前生命值。

护盾不能低于 `0`。护盾是否叠加、覆盖或分来源独立存在，由提供护盾的技能、装备或状态规则定义。

### 4.3 护盾与击倒

角色进入击倒状态时，默认不自动获得护盾，也不自动清除仍然有效的护盾。

击倒期间获得的新护盾可以继续吸收后续伤害，但护盾本身不能解除击倒。只有当前生命值恢复至至少 `1`，或特殊救援规则明确解除击倒时，角色才能恢复正常状态。

---

## 5. 击倒状态

### 5.1 触发条件

角色当前生命值从大于 `0` 降低至 `0`，并且当前效果没有明确造成直接死亡时，角色进入击倒状态。

```text
当前生命值 = 0
并且未触发直接死亡规则
→ 进入击倒状态
```

进入击倒状态时：

* 当前生命值固定为 `0`。
* 角色单位保留在当前地图位置。
* 中断尚未完成的主动攻击、移动或交互。
* 初始化本次击倒回合计数。
* 开放规则允许的求救、自救与救援操作。

如果同一次结算中包含多个伤害、治疗或状态效果，应先完成当前不可分割的直接效果，再根据最终当前生命值判断是否进入击倒，避免角色在同一效果中反复进入和退出击倒。

### 5.2 行动限制

击倒状态下，角色只能进行有限行动。

允许：

* 每个自身回合进行最多 `1` 格的合法移动。
* 使用明确标记为“击倒时可用”的自救道具或技能。
* 发起规则允许的求救操作。
* 接受其他玩家、NPC、事件或特殊能力的救援。
* 执行不改变游戏状态的查看与交流行为。

禁止：

* 发起普通攻击或敌对效果。
* 使用未明确允许在击倒时使用的主动技能。
* 制造、鉴定、交易或调整装备。
* 主动触发普通地图探索与地图事件。
* 执行其他要求角色处于正常生命状态的行动。

击倒角色的 `1` 格移动能力只是移动距离上限，不会绕过地图规则。目标必须是相邻、已探索、当前可通行且移动消耗不高于 `1` 的地块。

冰冻、束缚及其他移动限制仍然正常生效。任意有效规则禁止移动时，击倒角色不能移动。

### 5.3 击倒回合计数

默认击倒期限为：

```text
3 个该角色自己的回合
```

角色进入击倒状态的当前结算不立即计为一个击倒回合。从该角色下一次回合开始计算，并在每次自身回合结束时增加 `1` 点击倒回合数。

```text
进入击倒状态
      │
      ▼
第 1 个击倒回合结束：1 / 3
      │
      ▼
第 2 个击倒回合结束：2 / 3
      │
      ▼
第 3 个击倒回合结束：3 / 3
      │
      ▼
执行最后救援检查
      │
      ▼
仍未恢复生命值则正式死亡
```

即使角色无法执行任何有效行动，其自身回合仍然经过开始和结束阶段，并正常推进击倒计数。

击倒回合不会在其他玩家回合结束时增加，也不会因为攻击、响应或事件嵌套流程额外增加。

部分职业、装备、天气、事件或特殊能力可以修改击倒期限，但通常不应低于 `2` 个自身回合，也不应高于 `5` 个自身回合。

击倒期限发生变化时，已经累计的回合数保持不变。若新的期限不高于当前累计值，应在当前完整结算结束后执行最后救援检查，而不是在效果尚未完成时立即死亡。

### 5.4 击倒期间的其他效果

普通 Buff／Debuff 在角色进入击倒状态时默认继续保留，并按照各自规则结算与推进持续时间。

击倒不会自动清除负面状态，也不能作为稳定移除 Debuff 的手段。

持续伤害使击倒角色再次承受伤害时，按照本章第七节处理；持续恢复使当前生命值恢复至至少 `1` 时，可以按照救援规则解除击倒。

## 6. 击倒恢复与救援

### 6.1 救援成功条件

击倒角色通过合法效果将当前生命值恢复至至少 `1` 时，立即解除击倒。

```text
击倒角色当前生命值
从 0 恢复至至少 1
        │
        ▼
清除本次击倒回合计数
        │
        ▼
退出击倒状态
        │
        ▼
恢复正常生命状态
```

救援效果可以直接指定恢复值，也可以按照普通治疗规则计算。只解除击倒但不恢复任何生命值的效果，必须在自身规则中明确声明。

救援成功后：

* 当前生命值保留实际恢复后的数值。
* 清除本次击倒回合计数。
* 保留当前地图位置。
* 保留未被救援效果移除的其他状态。
* 不触发正式死亡及其代价。
* 不进入灵魂与轮回流程。

恢复正常生命状态不会返还本回合已经消耗的主要行动、移动力、物品或其他资源。角色是否还能继续行动，取决于当前回合剩余权限及救援效果自身说明。

### 6.2 自救

击倒角色可以使用明确允许在击倒状态下使用的：

* 回复药剂。
* 特殊道具。
* 职业技能。
* 装备能力。
* 其他自救效果。

普通治疗物品或技能不会因为具有恢复效果而自动允许在击倒时使用。其定义必须明确包含“击倒时可用”条件。

自救仍然需要满足物品、技能、资源、次数及使用时机限制。

### 6.3 其他玩家救援

其他玩家可以对击倒角色执行救援。

默认救援需要满足：

* 救援者处于正常生命状态。
* 救援目标当前仍处于击倒状态。
* 双方距离不超过 `1` 格。
* 救援者当前拥有一次合法主要行动。
* 救援者满足所使用治疗、道具或技能的其他条件。

```text
救援者选择击倒目标
        │
        ▼
检查距离、状态、行动与资源
        │
        ▼
支付救援成本
        │
        ▼
结算治疗或救援效果
        │
        ▼
目标生命值恢复至至少 1
        │
        ▼
解除击倒
```

具体治疗量、道具消耗及附加效果由救援来源定义。救援动作本身不额外保证固定恢复量。

### 6.4 NPC 与特殊机制救援

NPC、城镇、神殿、事件、信仰与神鬼契约也可以提供救援。

这些来源可以修改救援距离、行动消耗、恢复数值或其他条件，但必须调用统一的生命恢复与击倒解除流程，不能直接删除击倒标记而保留非法生命值。

---

## 7. 击倒期间受到攻击

击倒角色仍然可以成为合法攻击或伤害目标，除非其他规则为其提供保护。

### 7.1 普通伤害

击倒角色当前生命值已经为 `0`。再次受到普通伤害时：

* 护盾仍可按照规则吸收伤害。
* 当前生命值保持为 `0`，不会降低为负数。
* 不重复进入击倒状态。
* 不重置或额外增加击倒回合计数。
* 不因普通伤害自动正式死亡。

普通伤害仍应记录实际伤害、护盾吸收及过量伤害结果，以供日志或特殊效果使用。

### 7.2 处决与直接致死

少量技能、Boss 机制、事件或特殊规则可以声明“处决”或“直接致死”。

该类效果必须明确：

* 是否只能作用于击倒目标。
* 是否需要攻击未被闪避。
* 是否可以被主动防御、闪避、护盾或免疫阻止。
* 是否忽略剩余击倒期限。
* 是否直接进入正式死亡流程。

只有效果明确具有处决或直接致死能力时，才允许跳过剩余救援时间。

V1 阶段不将处决作为普通攻击的默认能力，也不鼓励大量配置此类效果。

---

## 8. 正式死亡

### 8.1 死亡条件

角色满足以下任意条件时，可以进入正式死亡：

* 达到击倒期限，完成最后救援检查后当前生命值仍为 `0`。
* 受到合法且已经完成结算的处决效果。
* 受到明确允许跳过击倒状态的特殊直接致死规则。

普通伤害将正常角色生命值降至 `0` 时，默认只能使其进入击倒，不能直接正式死亡。

### 8.2 死亡确认流程

正式死亡按照以下流程确认：

```text
满足死亡条件
      │
      ▼
完成当前不可分割效果
      │
      ▼
执行最后生命与救援检查
      │
      ▼
当前生命值仍为 0
      │
      ▼
确认正式死亡
      │
      ▼
中止角色未完成的个人行动
      │
      ▼
提交复活与中途加入系统
```

系统不能在攻击、治疗、响应或事件效果尚未完成时提前确认死亡，避免同一结算中的合法救援失效。

### 8.3 死亡后的职责边界

正式死亡确认后，本系统负责：

* 将角色生命状态更新为死亡。
* 中止角色尚未完成的主动行为。
* 输出正式死亡结果。
* 通知状态、地图、任务、日志及复活等相关系统。

以下内容由《16-模块系统/02-复活与中途加入》负责：

* 从地图移除死亡角色单位。
* 结算死亡代价与物品处理。
* 进入灵魂状态。
* 轮回等待与 D20 判定。
* 安全区域重新入场。
* 轮回后的资源恢复与保护。

角色的等级、使命、信仰、图纸和永久成长是否保留，也以复活系统及对应成长系统的规则为准。

## 9. 结算顺序

生命、击倒与死亡采用以下统一顺序：

```text
接收最终伤害或恢复结果
        │
        ▼
结算合法护盾变化
        │
        ▼
更新当前生命值
        │
        ▼
完成当前效果的直接后续结果
        │
        ▼
应用生命值边界
        │
        ▼
判断正常、击倒或死亡
        │
        ▼
执行状态转换
        │
        ▼
通知相关系统并记录日志
```

同一结算同时包含伤害与治疗时，必须按照效果明确规定的顺序逐项执行，不得只计算净变化后省略中间触发条件。

击倒期限到达时，应先结算当前回合结束效果和合法救援，再执行最后死亡检查。

正式死亡确认后，不再继续执行要求角色处于正常或击倒状态的个人效果；明确允许在死亡时触发的效果除外。

## 10. 与其他系统的关系

生命、击倒与死亡系统与其他模块的职责如下：

| 相关系统 | 主要职责 |
| --- | --- |
| 数值系统 | 提供最大生命、生命边界及统一取整能力。 |
| 战斗系统 | 提供已经确认的最终伤害及攻击结果。 |
| 角色资源系统 | 保存当前生命与护盾等运行时资源。 |
| 技能系统 | 提供治疗、护盾、自救、救援与处决效果。 |
| 状态系统 | 提供持续伤害、持续恢复及生命相关属性修饰。 |
| 地图系统 | 校验击倒移动、救援距离及角色所在位置。 |
| 经济与背包系统 | 管理救援物品、元宝及相关消耗。 |
| 任务与使命系统 | 根据已经确认的击倒、救援或死亡结果推进目标。 |
| 复活与中途加入系统 | 处理正式死亡后的代价、灵魂、轮回与重新入场。 |
| 日志系统 | 记录护盾、生命、击倒、救援与死亡结果。 |

本系统不负责计算攻击伤害，不负责决定治疗来源，也不负责执行死亡后的轮回流程。

---

## 11. V1 设计范围

V1 阶段支持：

* 当前生命值及最大生命边界。
* 护盾优先承伤。
* 正常、击倒与死亡三种生命状态。
* 默认 `3` 个自身回合的击倒期限。
* 击倒状态下最多移动 `1` 格。
* 自救与其他玩家救援。
* 回合结束时推进击倒计数。
* 普通伤害不直接处决击倒角色。
* 受控的特殊处决入口。
* 正式死亡结果输出。

本章节不重复设计以下内容：

* 灵魂状态玩法。
* 轮回与中途加入判定。
* 复杂复活分支。
* 死亡代价与物品掉落。
* 轮回后的出生点与保护效果。

上述内容已经由《16-模块系统/02-复活与中途加入》统一管理，不属于本章节的实现职责。

## 12. 设计原则

生命、击倒与死亡系统遵循以下设计原则：

生命非负原则

当前生命值最低为 `0`，过量伤害单独记录，不通过负生命值表示。

击倒优先原则

普通伤害将生命值降至 `0` 时先进入击倒，为玩家保留明确的救援机会。

有限行动原则

击倒角色仍可进行受限移动、自救与求救，但不能继续执行正常攻击、技能和交互行为。

救援明确原则

默认只有将当前生命值恢复至至少 `1` 才能解除击倒，特殊解除方式必须明确说明。

普通伤害不处决原则

击倒期间再次受到普通伤害不会自动正式死亡，也不会加速击倒计数；直接致死必须来自明确的处决规则。

结算完整原则

死亡只能在当前不可分割效果与最后救援检查完成后确认，不能提前中断合法响应。

职责分离原则

本系统管理生命状态转换，伤害公式、状态来源、任务进度与死亡后的轮回分别由对应系统负责。

---

## 13. 小结

生命、击倒与死亡系统通过护盾、当前生命值与三阶段生命状态，为角色受伤后的生存变化建立统一流程。

普通伤害将生命值降至 `0` 时，角色先进入击倒并获得三个自身回合的救援时间。有效治疗可以解除击倒，期限结束或明确处决则使角色正式死亡，并将后续处理交给复活与中途加入系统。

通过限制负生命值、普通补刀和提前死亡，同时保留受限行动、自救与协作救援，本系统能够让死亡具有明确代价，又避免玩家因一次攻击立即退出游戏。
