# 《开天辟地之大地的裂变》战斗系统概述

## 1. 系统定位

战斗系统用于处理玩家、NPC 及其他可战斗对象之间的直接攻击、主动防御、闪避、伤害与生命结算。

本游戏中的战斗不会进入独立战斗场景，也不采用双方脱离地图后持续轮流攻击的传统 RPG 模式。攻击发生在当前地图与世界状态中，并作为玩家主要行动、NPC 行为、事件效果或其他合法触发流程中的一次即时结算进行处理。

一次标准攻击可以概括为：

```text
攻击方发起攻击
        │
        ▼
防守方进行响应
        │
        ▼
完成闪避与伤害结算
        │
        ▼
本次攻击结束并返回原流程
```

正常情况下，被攻击方不会因为受到攻击而自动反击。反击只由明确声明该能力的技能、装备、手牌、状态或其他特殊机制触发，并作为当前攻击流程中的额外效果进行处理。

战斗系统的核心定位可以概括为：

**在不打断地图与回合节奏的前提下，通过一次完整响应与伤害结算解决单次攻击行为。**

---

## 2. 核心战斗规则

### 2.1 攻击发起

玩家只能在自己的回合内，并且拥有合法主要行动时主动发起普通攻击。

NPC、事件、状态或世界规则也可以在对应的合法时机发起攻击，但仍然复用同一套目标检查、响应窗口与伤害结算流程，不为不同来源建立独立伤害规则。

攻击通常需要满足以下条件：

* 攻击方当前拥有攻击权限。
* 攻击方尚未消耗本回合对应的主要行动。
* 目标属于当前规则允许攻击的对象。
* 目标处于武器、技能或攻击方式的有效距离内。
* 攻击方当前状态允许执行攻击。
* 武器、技能、资源及其他使用条件已经满足。
* 攻击方与目标之间不存在阻止本次攻击的地图或视野限制。

攻击距离主要由武器、技能或具体攻击方式决定。角色不能仅凭自身物理攻击或法术攻击属性获得额外攻击距离。

系统必须在支付主要行动、清空移动力或消耗其他资源前完成合法性检查。非法攻击不会消耗行动、移动力、手牌、技能资源或物品。

### 2.2 攻击与移动

攻击方可以先完成部分或全部移动，再发起攻击；也可以不移动而直接攻击。

一旦攻击通过合法性检查并正式开始结算，攻击方当前剩余移动力立即变为：

```text
当前剩余移动力 = 0
```

即使本次攻击之后被主动防御完全抵消、自然闪避或未造成有效伤害，已经清空的移动力也不会返还。

因此，在正常规则下，玩家可以“先移动后攻击”，但不能“先攻击后继续普通移动”。技能、强制位移、传送及其他明确说明不消耗普通移动力的效果不属于继续普通移动，应按照各自规则处理。

普通攻击默认属于主要行动。每名玩家在自己的正常回合中默认只有一次主要行动，具体规则遵循《03-回合结构/01-回合结构》的主要行动阶段。

### 2.3 主动防御

攻击正式开始后，防守方首先获得一次主动防御响应机会。

防守方可以使用当前时机允许的：

* 防御类手牌。
* 防御技能。
* 装备主动或触发效果。
* 特殊道具。
* 状态提供的响应能力。
* 其他明确允许响应当前攻击的效果。

主动防御可以改变攻击数值、提供护盾、施加状态、改变目标或使攻击完全失效。具体能力只能影响自身规则声明的内容，不能默认跳过后续全部结算。

除非效果明确允许，其他玩家不能替代防守方使用个人防御资源。协助防御、保护或转移攻击等能力需要在自身规则中说明目标、时机与结算方式。

如果主动防御使攻击完全失效，则本次攻击直接结束，不再进行自然闪避、暴击和伤害结算。

### 2.4 自然闪避

主动防御结束后，如果攻击仍然有效，则进行自然闪避判定。

自然闪避只使用防守方已经计算完成的最终派生属性“闪避”。本项目不设置“命中”属性，也不进行独立的命中判定。

自然闪避属于低概率的基础防御手段，应保持较低数值与明确上限，不能通过大量叠加形成长期稳定规避所有攻击的玩法。

自然闪避成功时，本次攻击不造成伤害，也不继续进行暴击判定。攻击附带的“未被闪避后”效果同样不会触发；明确声明“即使闪避仍然生效”的特殊效果除外。

### 2.5 不设置命中机制

攻击通过距离、目标、状态与使用条件检查后，只需依次经过主动防御与自然闪避。若攻击未被完全防御，且目标闪避失败，则直接进入伤害结算，不再进行额外的攻击方命中检定。

后续文档中的“攻击生效”或“未被闪避”，均表示攻击已通过闪避阶段，不代表存在隐含的命中数值。特殊效果可以修正、重新判定或跳过闪避，但不应创建独立的命中率。

## 3. 战斗数值与伤害

### 3.1 战斗属性来源

战斗系统直接读取角色数值系统已经计算完成的最终派生属性，不重新计算基础属性、装备修正、Buff、Debuff 或其他来源。

战斗结算主要使用以下数值：

```text
当前生命值与最大生命值
物理攻击
法术攻击
物理防御（护甲）
法术抗性（魔抗）
闪避
护甲穿透
法术穿透
暴击率
暴击伤害
护盾
```

“护甲”是战斗与装备语境中对物理防御能力的常用称呼，“魔抗”是对法术抗性的常用称呼。底层数值标识应与派生属性系统保持一致，不为显示简称重复创建两套属性。

护盾属于战斗中用于吸收伤害的运行时资源，不属于基础属性。护盾的来源、持续时间与叠加方式由技能、装备、状态或其他提供者定义，战斗系统只读取当前有效护盾并完成扣减。

### 3.2 攻击值组成

武器自身的攻击力独立参与战斗结算，不直接并入角色最终攻击属性。

一次攻击的基本攻击值可以概括为：

```text
攻击值
=
角色对应攻击属性
+
武器攻击力
+
技能或攻击方式修正
```

物理攻击通常读取角色物理攻击与武器物理攻击力；法术攻击通常读取角色法术攻击与法术攻击力。混合伤害、固定伤害及其他特殊攻击方式不在本概述中展开。

武器攻击力与角色攻击属性保持分离，可以使更换武器直接改变单次攻击表现，同时避免装备数值被永久写入角色自身派生属性。

### 3.3 防御与穿透

物理伤害受到物理防御影响，法术伤害受到法术抗性影响。护甲穿透与法术穿透分别用于削减本次伤害结算中实际生效的对应防御。

```text
物理攻击 → 护甲穿透 → 有效物理防御 → 物理伤害

法术攻击 → 法术穿透 → 有效法术抗性 → 法术伤害
```

物理防御、法术抗性及对应穿透均采用小数值整数设计，其作用是有限调整最终伤害，而不是形成复杂百分比公式或允许玩家通过无限堆叠获得近乎免疫的防御能力。

防御与穿透的下限、有效值及伤害扣减公式统一在《03-攻击与伤害计算》中说明，本概述不提前规定具体数值。

### 3.4 暴击、护盾与生命

攻击未被闪避并完成基础伤害计算后，可以根据攻击规则进行暴击判定。

暴击率决定本次攻击是否暴击，暴击伤害决定暴击后的伤害放大结果。只有规则明确允许暴击的攻击才会进入该阶段。

最终伤害优先由目标当前有效护盾承担：

```text
最终伤害
    │
    ▼
优先扣除护盾
    │
    ▼
剩余伤害扣除当前生命值
```

护盾不足时，超出护盾的伤害继续作用于当前生命值；护盾足以完全吸收伤害时，当前生命值保持不变。

生命值、护盾、暴击和完整伤害公式分别在后续对应章节中详细说明。

## 4. 标准攻击流程

一次普通攻击遵循以下统一流程：

```text
攻击方选择目标与攻击方式
            │
            ▼
检查行动、目标、距离、视野、状态与资源条件
            │
       ┌────┴────┐
       │         │
     非法       合法
       │         │
       ▼         ▼
不消耗任何内容  支付攻击成本并清空剩余移动力
                 │
                 ▼
          防守方主动防御响应
                 │
                 ▼
          攻击是否完全失效？
           ┌─────┴─────┐
           │           │
           是           否
           │           │
           ▼           ▼
        攻击结束    自然闪避判定
                       │
                       ▼
                是否闪避成功？
                 ┌─────┴─────┐
                 │           │
                 是           否
                 │           │
                 ▼           ▼
              攻击结束    计算攻击值
                             │
                             ▼
                    计算防御与穿透
                             │
                             ▼
                       计算基础伤害
                             │
                             ▼
                         暴击判定
                             │
                             ▼
                         护盾吸收
                             │
                             ▼
                         生命值扣除
                             │
                             ▼
                      击倒与状态检查
                             │
                             ▼
                          攻击结束
```

一次攻击结束后，系统返回发起攻击前的外层回合、事件或效果流程。攻击响应不会创建独立世界回合，也不会自动推进昼夜、天气、任务有效时间或其他按完整回合计数的内容。

如果攻击流程产生反击、追加攻击或其他嵌套效果，应按照统一响应与结算顺序处理，并设置明确的触发限制，避免无限循环。

## 5. 击倒与死亡衔接

当攻击结算使角色当前生命值降低至 `0` 时，角色不会立即正式死亡，而是进入“击倒”状态。

击倒状态下，角色只能进行有限行动，每回合最多拥有 `1` 格移动能力，并可以接受其他玩家救援。角色在规定回合内未恢复至少 `1` 点生命值时，才会正式死亡并进入灵魂与轮回流程。

生命、护盾、击倒、救援与正式死亡判断以《06-生命、击倒与死亡》为准。正式死亡后的代价、灵魂状态与轮回规则以《16-模块系统/02-复活与中途加入》为准。

冰冻、眩晕或技能明确施加的“倒地”等控制状态，与生命值降至 `0` 后的击倒状态属于不同概念。控制状态按照 Buff／Debuff 与技能规则处理，不能直接视为角色死亡。

## 6. 与其他系统的关系

战斗系统只负责组织单次攻击与直接战斗结果：

```text
发起攻击
    │
    ▼
防守响应
    │
    ▼
闪避与伤害计算
    │
    ▼
护盾、生命与击倒检查
```

其他数据和后续行为由对应系统负责：

| 相关系统 | 主要职责 |
| --- | --- |
| 回合系统 | 提供攻击时机、主要行动以及攻击后的外层流程。 |
| 地图系统 | 提供双方位置、距离、视野、障碍与合法目标关系。 |
| 角色与数值系统 | 提供已经计算完成的最终派生属性与当前运行时资源。 |
| 装备系统 | 提供武器攻击力、攻击距离、伤害类型与装备效果。 |
| 手牌系统 | 提供攻击、防御及其他允许响应战斗的手牌效果。 |
| 技能系统 | 提供技能成本、目标、攻击方式与特殊战斗效果。 |
| 状态系统 | 提供 Buff、Debuff、控制状态及属性修正结果。 |
| 随机系统 | 提供闪避、暴击及其他战斗随机判定。 |
| 复活与中途加入系统 | 处理击倒、救援、正式死亡、灵魂与轮回流程。 |
| 任务与使命系统 | 根据已经确认的战斗结果推进对应目标。 |

战斗系统不重复计算角色属性，不管理装备与状态的来源，也不直接修改任务、使命或世界状态。

例如，战斗系统可以确认“玩家击败指定目标”，再向任务系统提交结果；是否推进某项任务以及推进多少进度，由任务系统自行判断。

## 7. V1 实现范围

V1 阶段只实现以下基础战斗能力：

* 单次普通攻击。
* 攻击目标、距离、视野与状态检查。
* 攻击后清空剩余移动力。
* 防守方主动响应窗口。
* 自然闪避。
* 物理与法术攻击。
* 物理防御、法术抗性及对应穿透。
* 暴击率与暴击伤害。
* 护盾吸收与生命值扣除。
* 击倒状态检查。
* 基础战斗结果记录。

以下内容不属于 V1 基础范围，统一保留至战斗系统 `V2` 目录：

* 连击与复杂追加攻击。
* 复杂反击链。
* 多人协同攻击。
* 仇恨与威胁值系统。
* 复杂战斗 AI。

V2 内容必须继续复用 V1 的攻击合法性、响应、伤害、护盾与生命结算规则，并保持战斗发生在当前地图与外层流程中的基本定位，不能建立另一套互不兼容的战斗场景或基础公式。

## 8. 设计原则

战斗系统遵循以下设计原则：

即时结算原则

战斗作为当前回合或效果中的即时行为进行结算，不切换独立场景，也不默认建立持续战斗轮次。

玩家决策原则

攻击方决定目标与攻击方式，防守方拥有明确响应机会。随机判定用于处理不确定结果，但不能代替玩家的主要选择。

流程统一原则

玩家、NPC、事件与技能发起的攻击均复用统一目标检查、响应与伤害流程，不为单个来源编写特殊战斗框架。

数值直观原则

防御、穿透与其他战斗属性采用易于理解的小数值整数设计，避免复杂百分比叠加和无限数值成长。

职责分离原则

战斗系统读取其他系统提供的最终状态并返回战斗结果，不重复维护属性来源、装备配置、地图坐标、任务进度或复活规则。

响应受控原则

反击、追加攻击与其他嵌套效果必须明确触发次数和结束条件，避免形成递归触发或无限结算。

配置优先原则

武器、技能、攻击方式与特殊效果应通过统一定义和处理器扩展，不为单项内容在战斗主流程中增加特殊判断。

---

## 9. 小结

战斗系统通过单次即时攻击流程，将目标选择、主动防御、自然闪避、伤害、暴击、护盾、生命与击倒检查组织为一个完整结算。

玩家可以在地图与自身回合中直接发起攻击，防守方则在攻击结算中获得明确响应机会。攻击结束后立即返回原有游戏流程，不进入独立战斗场景，也不自动产生持续互相攻击。

通过复用角色、数值、装备、手牌、地图、随机与复活系统提供的能力，战斗系统能够保持流程简单、数值直观且易于扩展，并为后续技能、状态和 V2 战斗机制提供统一基础。
