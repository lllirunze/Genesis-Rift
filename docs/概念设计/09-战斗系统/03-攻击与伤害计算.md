# 《开天辟地之大地的裂变》攻击与伤害计算

## 1. 文档目的

本文档用于规定一次攻击从攻击值、防御与穿透到最终伤害、护盾吸收及生命扣除的统一计算方式。

战斗系统不重新计算角色基础属性、派生属性或属性修饰器，而是直接读取角色数值系统已经生成的最终派生属性。

整体计算流程如下：

```text
读取角色最终派生属性
        │
        ▼
计算本次攻击值
        │
        ▼
计算目标有效防御
        │
        ▼
计算基础伤害
        │
        ▼
进行暴击判定与伤害放大
        │
        ▼
应用最终伤害边界
        │
        ▼
护盾吸收
        │
        ▼
生命值扣除
```

攻击与伤害计算遵循以下原则：

* 公式保持简单，主要使用整数加法、减法、乘法与除法。
* 武器本体攻击力独立参与单次攻击计算。
* 防御属性用于降低伤害，而不是使未被闪避的普通攻击长期失去效果。
* 穿透只能削减对应防御，不能产生负防御或反向增加伤害。
* 暴击倍率使用整数百分数表示，不依赖浮点数运算。
* 伤害在完整计算后统一取整并应用边界规则。
* 百分比修正保持少量且受控，避免多层乘算造成数值膨胀。

---

## 2. 计算数据来源

一次攻击可以读取以下数据：

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 角色最终物理攻击 | 数值系统 | 已包含基础属性、静态偏移量及动态偏移量。 |
| 角色最终法术攻击 | 数值系统 | 已包含基础属性、静态偏移量及动态偏移量。 |
| 武器本体攻击力 | 装备配置 | 只参与使用该武器发起的对应攻击。 |
| 技能或攻击方式修正 | 技能或攻击配置 | 只影响当前攻击。 |
| 目标最终物理防御 | 数值系统 | 战斗语境中可以简称为护甲。 |
| 目标最终法术抗性 | 数值系统 | 战斗语境中可以简称为魔抗。 |
| 攻击方最终穿透 | 数值系统 | 根据伤害类型读取护甲穿透或法术穿透。 |
| 暴击率与暴击伤害 | 数值系统 | 分别用于暴击判定与暴击伤害放大。 |
| 当前护盾与生命值 | 角色运行时资源 | 用于承受已经确定的最终伤害。 |

装备可以通过属性修饰器提高角色最终物理攻击或法术攻击，这类修正已经包含在角色最终派生属性中。

武器本体攻击力则是装备配置中专门用于当前攻击的基础数值，不并入角色最终攻击。系统必须区分这两类数据，避免将同一项武器数值重复加入攻击值。

## 3. 攻击值计算

攻击值表示一次攻击进入目标防御计算前的基础强度。

### 3.1 普通物理攻击

普通物理攻击按照以下公式计算：

```text
物理攻击值
=
角色最终物理攻击
+
武器物理攻击力
```

例如：

```text
角色最终物理攻击 = 18
长剑物理攻击力 = 12

物理攻击值
= 18 + 12
= 30
```

角色没有装备武器，并且当前攻击方式允许徒手攻击时，武器物理攻击力视为 `0`。徒手攻击是否拥有额外基础数值，由对应攻击方式配置决定。

### 3.2 普通法术攻击

普通法术攻击按照以下公式计算：

```text
法术攻击值
=
角色最终法术攻击
+
武器或施法媒介的法术攻击力
```

法术攻击不应默认读取武器物理攻击力。只有武器、技能或攻击方式明确声明时，才允许将其他指定数值加入法术攻击值。

### 3.3 技能与攻击方式修正

技能攻击在对应攻击属性与武器本体攻击力的基础上，增加当前技能或攻击方式提供的固定修正：

```text
攻击值
=
角色对应的最终攻击属性
+
武器对应攻击力
+
技能或攻击方式修正值
```

例如，“重击”提供固定物理攻击修正 `+8`：

```text
角色最终物理攻击 = 18
长剑物理攻击力 = 12
重击修正值 = 8

攻击值
= 18 + 12 + 8
= 38
```

不同技能可以按照自身配置选择读取：

* 物理攻击。
* 法术攻击。
* 武器物理攻击力。
* 武器或媒介法术攻击力。
* 其他明确允许参与攻击的派生属性。

V1 阶段优先采用固定整数修正，不建议为普通技能大量配置攻击倍率。

### 3.4 攻击值边界

攻击值完成加总后，其最低值限制为：

```text
合法攻击值 = max（0，计算后的攻击值）
```

攻击值为 `0` 时，普通攻击仍可以完成闪避及相关效果判定，但不会仅凭最低伤害规则自动产生伤害；特殊规则明确声明“未被闪避后至少造成 `1` 点伤害”时除外。

## 4. 有效防御计算

目标受到攻击时，系统根据伤害类型读取对应防御与穿透。

### 4.1 物理防御

物理伤害读取目标最终物理防御，并使用攻击方最终护甲穿透进行削减：

```text
有效物理防御
=
max（0，目标最终物理防御 - 攻击方最终护甲穿透）
```

例如：

```text
目标最终物理防御 = 10
攻击方最终护甲穿透 = 3

有效物理防御
= max（0，10 - 3）
= 7
```

### 4.2 法术抗性

法术伤害读取目标最终法术抗性，并使用攻击方最终法术穿透进行削减：

```text
有效法术抗性
=
max（0，目标最终法术抗性 - 攻击方最终法术穿透）
```

例如：

```text
目标最终法术抗性 = 8
攻击方最终法术穿透 = 2

有效法术抗性
= max（0，8 - 2）
= 6
```

### 4.3 穿透边界

穿透只用于减少本次攻击中实际生效的对应防御。

当穿透高于目标防御时，多余部分不继续转化为额外伤害：

```text
目标最终物理防御 = 5
攻击方最终护甲穿透 = 8

有效物理防御
= max（0，5 - 8）
= 0
```

V1 阶段不支持负防御，也不支持百分比穿透。

---

## 5. 基础伤害计算

### 5.1 物理伤害

物理基础伤害按照以下公式计算：

```text
物理基础伤害
=
攻击值 - 有效物理防御
```

当合法攻击值大于 `0`，并且攻击未被闪避时，普通物理攻击应用最低伤害 `1`：

```text
物理基础伤害
=
max（1，攻击值 - 有效物理防御）
```

### 5.2 法术伤害

法术基础伤害按照以下公式计算：

```text
法术基础伤害
=
攻击值 - 有效法术抗性
```

当合法攻击值大于 `0`，并且攻击未被闪避时，普通法术攻击应用最低伤害 `1`：

```text
法术基础伤害
=
max（1，攻击值 - 有效法术抗性）
```

### 5.3 最低伤害规则

最低伤害只在以下条件全部满足时生效：

* 攻击已经通过合法性检查。
* 攻击未被主动防御完全抵消。
* 攻击未被自然闪避。
* 本次合法攻击值大于 `0`。
* 攻击规则没有明确声明可以造成 `0` 点伤害。

最低伤害用于避免防御属性使正常攻击长期完全失效，但不会绕过主动防御、自然闪避、伤害免疫或其他明确使攻击无效的规则。

## 6. 暴击计算

### 6.1 暴击判定

攻击成功得到大于 `0` 的基础伤害后，只有规则允许暴击的攻击才会进行暴击判定。

暴击判定读取攻击方最终暴击率，并通过随机系统对应的战斗随机流完成。幸运值不参与暴击判定。

具体随机判定方式由随机系统统一提供，闪避率与暴击率的概率边界由数值配置统一维护。

### 6.2 暴击伤害表示

暴击伤害采用整数百分数表示：

```text
100 = 100%
150 = 150%
200 = 200%
```

例如，角色面板显示暴击伤害 `150%` 时，底层结算值为整数 `150`，不保存浮点倍率 `1.5`。

暴击伤害的最低合法值原则上为 `100`。低于 `100` 的结果按照属性边界规则限制为 `100`，避免暴击后的伤害低于未暴击伤害。

### 6.3 暴击伤害公式

未触发暴击时：

```text
暴击结算后伤害 = 基础伤害
```

触发暴击时：

```text
暴击结算后伤害
=
向下取整（基础伤害 × 暴击伤害 ÷ 100）
```

计算时必须先进行乘法，再进行整数除法与向下取整，避免提前除法造成精度丢失。

例如：

```text
基础伤害 = 21
暴击伤害 = 150

暴击结算后伤害
= 向下取整（21 × 150 ÷ 100）
= 向下取整（31.5）
= 31
```

概念说明中的 `31.5` 只用于展示数学结果。程序应直接使用整数乘除得到 `31`，不进行浮点数运算。

## 7. 伤害类型

V1 阶段支持以下三种基础伤害类型。

### 7.1 物理伤害

物理伤害具有以下特点：

* 通常读取角色最终物理攻击。
* 可以读取武器物理攻击力。
* 受到目标最终物理防御影响。
* 使用护甲穿透削减有效物理防御。
* 规则允许时可以暴击。

### 7.2 法术伤害

法术伤害具有以下特点：

* 通常读取角色最终法术攻击。
* 可以读取施法武器或媒介的法术攻击力。
* 受到目标最终法术抗性影响。
* 使用法术穿透削减有效法术抗性。
* 规则允许时可以暴击。

### 7.3 真实伤害

真实伤害由技能、状态、事件或其他特殊效果直接提供合法伤害值：

```text
真实伤害 = 对应效果提供的伤害值
```

真实伤害不读取物理防御、法术抗性、护甲穿透或法术穿透，也不应用普通防御扣减公式。

真实伤害默认不能暴击；只有效果明确允许时，才进入暴击判定。

真实伤害仍然受到以下规则约束：

* 伤害值不能低于 `0`。
* 仍然优先由规则允许吸收真实伤害的护盾承担。
* 仍然需要完成生命值与击倒检查。
* 伤害免疫或其他明确针对真实伤害的特殊规则仍可生效。

真实伤害属于特殊机制，V1 阶段不作为主要伤害来源。

## 8. 护盾与生命结算

### 8.1 护盾吸收

最终伤害产生后，优先由目标当前有效护盾承担。

```text
护盾吸收值
=
min（当前有效护盾，最终伤害）
```

```text
剩余伤害
=
最终伤害 - 护盾吸收值
```

```text
结算后护盾
=
当前有效护盾 - 护盾吸收值
```

例如：

```text
当前护盾 = 8
当前生命值 = 50
最终伤害 = 20

护盾吸收值 = min（8，20）= 8
剩余伤害 = 20 - 8 = 12
结算后护盾 = 8 - 8 = 0
```

护盾是否能够吸收某种伤害，由护盾自身规则决定。不能吸收当前伤害类型的护盾不参与本次计算。

### 8.2 生命值扣除

剩余伤害用于扣除目标当前生命值：

```text
结算后生命值
=
max（0，当前生命值 - 剩余伤害）
```

沿用上一示例：

```text
结算后生命值
= max（0，50 - 12）
= 38
```

生命值不能低于 `0`。生命值降至 `0` 时，战斗系统将角色转入击倒状态；后续规则由《06-生命、击倒与死亡》统一管理。

### 8.3 过量伤害

将生命值扣减至 `0` 后仍未消耗的伤害属于过量伤害。

V1 阶段只记录过量伤害，不使用过量伤害直接跳过击倒状态或触发额外死亡规则。技能、状态或后续扩展明确引用该数据时除外。

## 9. 数值范围与取整规则

### 9.1 整数规则

攻击值、防御、穿透、基础伤害、最终伤害、护盾及生命值的运行时结果均使用整数。

暴击伤害虽然以百分数展示，但底层仍使用整数百分数，并通过整数乘除完成结算。

除规则另有说明外，伤害计算在完整公式结束后统一向下取整。

### 9.2 属性定位

各类战斗数值采用以下定位：

| 数值类型 | 设计定位 |
| --- | --- |
| 物理攻击、法术攻击、生命值 | 主要成长数值，可以随角色与装备逐步成长。 |
| 物理防御、法术抗性 | 小数值防御属性，用于有限降低对应伤害。 |
| 护甲穿透、法术穿透 | 小数值修正属性，用于削减对应有效防御。 |
| 暴击率、闪避 | 概率相关属性，需要配置明确上下限。 |
| 暴击伤害 | 整数百分数属性，需要配置最低值与合理上限。 |
| 护盾 | 临时运行时资源，不属于基础属性。 |

物理防御、法术抗性及对应穿透不设计为高数值无限成长属性，避免攻击与防御数值同时快速膨胀。

数值系统中预留的“固定伤害减免”暂不接入 V1 标准伤害公式。后续启用该属性时，需要在战斗系统 `V2` 目录中明确其结算位置、适用伤害类型以及与最低伤害规则的关系，不能在装备或状态处理器中自行扣减伤害。

### 9.3 百分比限制

V1 阶段仅保留暴击伤害等少量必要的百分数表达，并统一采用整数表示。

闪避率、暴击率等概率属性由随机系统进行整数概率判定。战斗伤害公式不额外引入多层百分比增伤、百分比减伤或百分比穿透。

所有取整、最小值与最大值处理均应调用数值系统的统一能力，不在单个技能或武器中自行实现另一套边界逻辑。

## 10. 标准计算示例

角色 A 拥有以下数值：

```text
最终物理攻击 = 18
武器物理攻击力 = 12
护甲穿透 = 3
暴击率 = 20（界面显示为 20%）
暴击伤害 = 150（界面显示为 150%）
```

角色 B 拥有以下数值：

```text
物理防御 = 10
当前护盾 = 5
当前生命值 = 60
```

假设本次攻击未被闪避，且未触发暴击。

### 10.1 计算攻击值

```text
攻击值
= 18 + 12
= 30
```

### 10.2 计算有效物理防御

```text
有效物理防御
= max（0，10 - 3）
= 7
```

### 10.3 计算基础伤害

```text
基础伤害
= max（1，30 - 7）
= 23
```

### 10.4 暴击判定

本次攻击未触发暴击：

```text
最终伤害 = 23
```

若本次攻击触发暴击，则结果为：

```text
最终伤害
= 向下取整（23 × 150 ÷ 100）
= 34
```

### 10.5 护盾吸收

按照未暴击结果继续结算：

```text
护盾吸收值 = min（5，23）= 5
结算后护盾 = 5 - 5 = 0
剩余伤害 = 23 - 5 = 18
```

### 10.6 生命值扣除

```text
结算后生命值
= max（0，60 - 18）
= 42
```

最终结果：

```text
角色 B 当前生命值 = 42
角色 B 当前护盾 = 0
角色 B 未进入击倒状态
```

## 11. V1 范围限制

V1 阶段不设计以下复杂机制：

* 百分比减伤。
* 百分比穿透。
* 防御收益递减曲线。
* 负防御增伤。
* 多层防御计算。
* 固定伤害减免接入标准伤害流程。
* 复杂伤害类型转换。
* 连续攻击倍率叠加。
* 多个独立增伤区间相乘。

后续确有需要时，应在战斗系统 `V2` 目录中独立设计，并继续复用 V1 的攻击值、防御、穿透、护盾与生命边界规则。

## 12. 设计原则

攻击与伤害计算遵循以下设计原则：

属性复用原则

战斗系统只读取数值系统提供的最终派生属性，不重新追溯或计算属性来源。

整数计算原则

运行时伤害公式优先使用整数运算，百分数统一使用整数表示，并按照先乘后除的顺序完成计算。

武器独立原则

武器本体攻击力独立参与对应攻击，但不得与已经进入角色派生属性的装备修正重复计算。

防御有限原则

防御能够明显降低伤害，但普通成功攻击仍保留受控的最低伤害；主动防御、闪避与免疫不受该规则影响。

穿透对应原则

护甲穿透只削减物理防御，法术穿透只削减法术抗性，溢出穿透不产生额外伤害。

边界统一原则

攻击、伤害、护盾与生命值均调用数值系统统一的取整及边界能力，不在业务内容中分散实现特殊算法。

## 13. 小结

攻击与伤害计算通过“攻击值减去有效防御”的简单整数公式，分别处理物理伤害与法术伤害，并为真实伤害保留受控的特殊入口。

暴击伤害采用整数百分数完成放大，最终伤害优先由合法护盾吸收，再扣除当前生命值。通过限制负防御、百分比穿透和多层乘算，本系统能够保持结算直观、数值稳定，并为后续技能、装备与状态效果提供统一计算基础。
