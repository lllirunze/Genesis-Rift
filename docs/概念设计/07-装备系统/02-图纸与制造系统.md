# 《开天辟地之大地的裂变》图纸与制造系统

## 1. 系统概述

图纸与制造系统是装备系统的重要组成部分，也是玩家获取高品质装备的主要途径。

与直接获得成品装备不同，制造系统更强调玩家在探索世界的过程中逐步收集知识与资源。玩家需要通过不同方式获得装备图纸，并收集对应材料，在满足制造条件后打造装备。

该系统与地图探索、NPC、经济、任务和战斗等系统形成紧密联系，为玩家提供持续性的成长目标，同时提升探索与收集的乐趣。

整个制造系统遵循以下流程：

```text
获得图纸
↓
已知图纸自动掌握，未知图纸完成鉴定
↓
收集制造材料
↓
满足制造条件
↓
制造装备
```

其中：

* 图纸代表制造知识
* 材料代表制造资源
* 制造条件代表完成制造所需的地点、能力或其他前置要求

图纸与材料缺一不可。玩家即使拥有充足材料，也不能在尚未掌握对应图纸时制造装备；已经掌握图纸但缺少材料时，同样不能完成制造。

原剧已经将装备、角色成长、地图冒险、经济和战斗等内容放入同一套游戏规则之中。图纸与制造系统在这一基础上建立长期收集循环，使高品质装备成为玩家探索与积累的成果，而不是脱离其他系统独立存在的随机奖励。

## 2. 图纸系统

### 2.1 图纸的作用

图纸是制造装备的前置条件，用于记录某件装备的制造方式，而不是装备本身。

一份完整图纸至少应提供以下信息：

| 信息 | 说明 |
| --- | --- |
| 装备名称 | 当前图纸对应的装备。 |
| 装备类型 | 武器、护甲、鞋子、饰品或特殊装备。 |
| 装备品质 | 当前装备所属品质。 |
| 材料需求 | 制造该装备需要消耗的材料及数量。 |
| 制造地点 | 是否必须在铁匠铺、工坊或其他指定地点制造。 |
| 制造条件 | 制造能力、任务进度或其他必要条件。 |
| 成品信息 | 制造完成后获得的装备及数量。 |

玩家获得已知图纸或完成未知图纸的鉴定后，对应制造方式将自动记录至角色已掌握的制造知识中。后续制造同类装备时无需重复学习，也不会消耗已经掌握的图纸知识。

图纸知识属于角色的长期成长内容，不会因装备制造、装备交易或装备损坏而失效。

### 2.2 已知图纸

已知图纸拥有完整且公开的制造信息，不需要进行鉴定。

玩家获得已知图纸后，无需进行额外学习操作，即可永久掌握对应装备的制造方法。

已知图纸通常通过以下方式获得：

* 任务奖励
* 商店购买
* NPC 赠送
* 身份或转职解锁
* 制造组织或特殊地点传授
* 玩家交易

已知图纸的获取渠道相对稳定，主要用于建立玩家的基础制造能力和明确成长目标。

### 2.3 未知图纸

未知图纸在获得时无法直接查看其真实名称、装备效果和完整材料需求，需要先通过鉴定揭示具体内容。

未知图纸通常来自：

* 遗迹探索
* 宝箱
* 隐藏区域
* 特殊事件
* 稀有敌人掉落
* 世界裂变产生的异常地点

未知图纸用于增加探索过程中的未知性与惊喜感，但不应成为高品质装备的唯一来源。

鉴定可以由具备相应能力的角色、NPC、技能、工具或特殊地点完成，并统一使用《06-数值系统》中定义的鉴定能力。

鉴定完成后，未知图纸将揭示其真实内容，并转化为对应的已知图纸。对应制造方法同时永久加入玩家已掌握的制造知识。

### 2.4 图纸知识与重复图纸

图纸物品与已掌握的图纸知识属于两个不同概念：

| 内容 | 作用 |
| --- | --- |
| 图纸物品 | 可以被获取、携带、鉴定或交易的物品。 |
| 图纸知识 | 角色已经掌握的永久制造方法。 |

图纸不是一次性消耗品，不会因记录制造知识或制造装备而消失。玩家可以在掌握制造知识后继续持有或交易对应图纸物品。

当玩家再次获得已经掌握的图纸时，不会重复添加同一条制造知识。重复图纸仍可以根据其物品规则进行：

* 交易
* 出售
* 赠送
* 作为任务物品提交
* 转化为其他制造资源

具体交易价格和资源转化规则由经济系统负责，图纸系统只负责判断玩家是否已经掌握对应制造方法。

## 3. 材料与制造

### 3.1 材料来源

制造装备除了需要图纸外，还需要对应的制造材料。

材料是游戏中的基础资源，可以通过以下方式获得：

* 地图探索
* 资源采集
* 怪物或敌人掉落
* 任务奖励
* 商店购买
* 玩家交易
* 装备或资源转化
* 特殊事件

材料的具体获取渠道由地图、战斗、任务和经济等系统共同决定。

不同装备应拥有不同的材料需求。玩家需要根据图纸要求主动规划探索与收集路线，而不是通过单一活动获得所有制造资源。

### 3.2 制造条件

玩家制造装备时，至少需要满足以下两项基础条件：

* 已经掌握对应图纸
* 拥有足够的制造材料

部分装备还可以配置额外制造条件：

| 条件类型 | 示例 |
| --- | --- |
| 制造地点 | 必须位于铁匠铺、炼金工坊、神殿或特殊遗迹。 |
| 制造能力 | 角色的制造能力达到指定要求。 |
| 身份或转职 | 仅特定身份或转职路线能够制造。 |
| 任务进度 | 完成指定任务后开放制造。 |
| 地图状态 | 只能在特定区域、天气或裂变状态下制造。 |
| 特殊资源 | 除常规材料外，还需要元宝、任务物品或其他资源。 |

额外条件应由图纸明确记录，使玩家能够提前得知尚未满足的要求。

### 3.3 制造流程

当玩家已经掌握对应图纸，并满足材料和制造条件后，即可在相应制造地点发起装备制造。

标准制造流程如下：

```text
选择已掌握图纸
↓
检查制造地点与其他前置条件
↓
检查材料及资源数量
↓
确认制造
↓
统一扣除材料与资源
↓
生成装备成品
↓
将成品放入玩家背包
```

材料和其他消耗资源只在所有条件检查通过并正式确认制造后统一扣除。

如果任意条件不满足，制造不能开始，也不会扣除部分材料。

制造完成后：

* 对应材料和消耗资源被扣除
* 制造出的装备进入玩家背包
* 已掌握的图纸知识永久保留
* 玩家可以在重新收集材料后再次制造同类装备

制造成品进入背包后，不会自动穿戴。玩家需要按照《01-装备系统总览》中的装备整理规则进行穿戴。

### 3.4 制造结果

标准制造在图纸、材料和其他条件全部满足后必定成功，不进行额外的随机成功率判定。

制造能力主要用于：

* 判断角色是否满足高阶图纸的制造门槛
* 解锁特殊制造地点或制造方式
* 参与图纸或装备的特殊效果
* 影响后续可能加入的额外产出规则

默认规则不允许因一次随机失败而直接损失玩家长期收集的全部材料。

如果某个特殊图纸需要随机结果、额外产出或制造风险，必须在图纸中明确说明，并作为特殊机制单独配置，不能成为普通制造的隐藏规则。

## 4. 系统联动

图纸与制造系统本身只负责图纸知识、材料需求、制造条件和成品生成，不直接管理所有资源来源与玩法效果。

各系统职责如下：

| 关联系统 | 主要职责 |
| --- | --- |
| 地图系统 | 提供资源地块、制造地点、遗迹、宝箱和特殊区域。 |
| 角色系统 | 提供身份、转职及其他制造资格。 |
| 数值系统 | 计算鉴定能力、制造能力和相关属性修饰。 |
| 战斗系统 | 提供敌人掉落、战斗奖励及制造材料来源。 |
| 任务系统 | 提供图纸、材料、制造资格和特殊装备奖励。 |
| 经济系统 | 管理图纸、材料和成品装备的购买、出售与交易价值。 |
| 背包与物品系统 | 校验材料持有与消耗，管理图纸物品、材料和制造成品的存放位置。 |
| 装备系统 | 定义制造成品的类型、品质、效果和穿戴方式。 |

这种职责划分能够确保新增材料、图纸或制造地点时，不需要将地图、战斗、经济和装备逻辑全部写入制造系统。

## 5. 设计原则

图纸与制造系统遵循以下原则：

### 5.1 知识保留原则

图纸代表制造知识。玩家掌握制造方法后可以重复制造，不会在制造过程中消耗或遗忘该知识。

### 5.2 双重条件原则

制造装备必须同时满足图纸与材料两项基础条件，任何一项缺失都不能完成制造。

### 5.3 探索驱动原则

材料和图纸应拥有多种来源，并与地图探索、任务、战斗、NPC 和特殊事件形成联动。

### 5.4 高品质制造原则

高品质装备应优先通过图纸与制造获得，而不是完全依赖随机掉落。

### 5.5 经济流通原则

图纸物品、材料和成品装备均可成为经济系统中的交易资源，但已掌握的制造知识本身不直接作为普通物品交易。

### 5.6 结果明确原则

普通制造在条件满足后必定成功。所有特殊风险、随机结果或额外产出都必须提前写入图纸规则。

### 5.7 配置驱动原则

图纸、材料需求、制造地点和其他条件均由配置维护，新增装备时不修改制造系统的通用流程。

### 5.8 易于扩展原则

系统保持较低的学习成本，同时为后续新增装备、材料、制造地点、裂变配方和特殊制造方式预留扩展能力。

图纸与制造系统的意义不仅在于生产装备，更重要的是引导玩家不断探索世界、收集资源，并通过长期积累逐步完善自己的装备体系，从而形成稳定且具有成长感的游戏循环。
