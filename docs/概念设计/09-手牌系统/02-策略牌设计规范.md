# 《开天辟地之大地的裂变》策略牌设计规范

## 1. 设计原则

所有策略牌均应遵循**简单易懂、效果明确、方便结算**的设计原则。

策略牌主要用于丰富玩家的临场决策，而不是替代角色成长。因此，大部分策略牌应围绕战斗、探索、事件和生存等场景提供短期收益，避免出现永久性属性成长或直接影响角色养成的效果。

每张策略牌应尽量只表达一个核心效果，避免一张策略牌同时拥有过多机制，降低理解和结算成本。

策略牌设计需要满足以下基本要求：

* 玩家阅读牌面后能够理解使用时机和预期结果
* 系统能够判断策略牌是否合法使用
* 效果能够进入统一响应窗口和响应链
* 数值能够使用现有数值系统完成结算
* 持续效果能够交由状态系统管理
* 使用后能够明确进入弃牌堆或其他指定区域

策略牌可以制造意外、逆转和戏剧性，但不能依赖含糊文本或临时裁定产生强度。

---

## 2. 基本组成

每张策略牌应采用统一结构进行设计，以方便后续维护、配置与扩展。

### 2.1 必要信息

每张策略牌建议包含以下信息：

| 项目 | 说明 |
| --- | --- |
| 名称 | 策略牌的正式显示名称。 |
| 唯一标识 | 配置与程序使用的唯一标识。 |
| 品质 | 普通、优秀、稀有、史诗或传说。 |
| 类型 | 所属策略牌类型，具体类型由《03-策略牌类型》统一定义。 |
| 使用时机 | 可以主动使用，或能够响应何种行动与效果。 |
| 使用条件 | 满足何种条件时可以使用。 |
| 作用目标 | 自身、其他玩家、NPC、地块、区域、行动、事件或其他合法目标。 |
| 核心效果 | 策略牌产生的主要效果。 |
| 结算方式 | 瞬时结算或持续生效。 |
| 持续时间 | 持续效果的回合数、阶段或结束条件；瞬时效果不填写。 |
| 结算去向 | 使用后进入弃牌堆、返回手牌或进入其他指定区域。 |
| 关键字 | 用于表达通用规则的标准化术语。 |
| 备注 | 无法通过标准字段表达的少量补充说明，可选。 |

其中，“是否立即生效”统一通过“结算方式”表达。

瞬时结算不代表打出后立刻跳过其他玩家的响应。其含义是：

```text
策略牌合法打出
↓
进入响应窗口与响应链
↓
所有玩家连续放弃响应
↓
响应窗口关闭
↓
一次性结算该牌效果
```

只有响应窗口关闭后，策略牌才会进入最终结算。任何品质、类型或关键字都不能在没有明确系统规则的情况下绕过该流程。

### 2.2 信息完整原则

策略牌文本必须能够回答以下问题：

* 什么时候可以使用
* 谁可以使用
* 需要满足什么条件
* 响应的是哪个行动或效果
* 选择哪个目标
* 产生什么结果
* 效果持续多久
* 使用后进入哪里

如果任意问题无法从标准字段或牌面文本中得到答案，该策略牌不能进入正式配置。

### 2.3 统一设计模板

新增策略牌时，建议使用以下模板：

```text
名称：
唯一标识：
品质：
类型：
核心定位：

使用时机：
使用条件：
响应对象：
作用目标：

核心效果：
结算方式：瞬时 / 持续
持续时间：
结算去向：弃牌堆 / 手牌 / 其他区域

关键字：
获取方式：
备注：
```

“核心定位”应使用一句话说明该牌解决什么问题。“获取方式”用于帮助品质与实际稀有程度保持一致，但不直接参与策略牌效果结算。

## 3. 品质设计

策略牌共分为五个品质：

| 品质 | 设计定位 |
| --- | --- |
| 普通 | 提供基础效果，获取相对容易，是策略牌的主要组成部分。 |
| 优秀 | 拥有更好的收益、适用范围或使用灵活性。 |
| 稀有 | 具有较强的功能性或特殊机制，获取难度较高。 |
| 史诗 | 能够明显改变局部局势，多作为高级奖励出现。 |
| 传说 | 极其稀有，拥有足以影响整场游戏的重要能力。 |

品质主要影响获取难度、机制影响范围与整体价值，并不意味着高品质策略牌在所有情况下都优于低品质策略牌。

部分普通策略牌在合适的场景下同样能够发挥关键作用。

### 3.1 品质差异原则

品质差异可以通过以下方式体现：

* 更高的获取难度
* 更广但仍然明确的适用场景
* 更强的局部影响能力
* 更独特的系统联动
* 更稀有的目标改变或结果修正能力
* 更高的使用条件或决策成本

品质差异不应简单表现为：

* 普通牌造成 `1` 点效果，传说牌造成 `100` 点效果
* 高品质牌可以无条件取消所有行动
* 高品质牌不允许其他玩家响应
* 高品质牌永久提高角色基础属性
* 高品质牌拥有大量彼此无关的效果

### 3.2 品质与复杂度

品质越高，可以拥有更加独特的机制，但牌面复杂度仍应受到限制。

普通与优秀策略牌通常只包含一个直接效果。

稀有、史诗和传说策略牌可以拥有一个核心效果与一个紧密相关的附加效果，但不应因此形成多段递归触发或独立子系统。

传说品质代表影响力和稀有性，不代表可以破坏基础规则或跳过系统职责边界。

## 4. 效果设计规范

### 4.1 单一核心效果

每张策略牌应尽量只包含一个核心效果。

例如，一张用于避免伤害的策略牌，可以围绕以下某一方向设计：

* 减少本次伤害
* 改变本次伤害的目标
* 为本次伤害提供护盾
* 使本次攻击重新进行命中判定

不应在同一张普通策略牌中同时加入减伤、反击、治疗、移动和抽取策略牌等多个无关效果。

### 4.2 效果文本明确

效果描述应使用明确、可验证的语言。

应优先写明：

* 明确数值
* 明确目标
* 明确持续时间
* 明确触发时机
* 明确效果结束条件

避免使用以下模糊表达：

* 大幅提高
* 有概率获得较强效果
* 持续一段时间
* 对附近目标生效
* 在适当时机触发

如果“附近”“较强”“一段时间”等概念确有必要，必须在通用规则或该牌文本中给出可计算定义。

### 4.3 优先短期影响

策略牌应优先修改当前回合、当前行动、当前事件或有限回合内的结果。

允许的典型效果包括：

* 修改本次攻击或防御
* 改变一次移动或探索结果
* 干预一个事件选项
* 获得有限回合的状态
* 立即恢复一定资源
* 改变一次交易或资源结算

策略牌原则上不得：

* 永久增加五项基础属性
* 永久提高派生属性
* 永久增加装备栏或手牌上限
* 直接授予永久转职或身份成长
* 绕过任务系统写入永久任务进度

具有永久影响的特殊内容应由任务、角色、装备或其他长期成长系统负责，策略牌最多作为触发对应系统流程的条件之一。

### 4.4 持续效果

持续多个回合或阶段的策略牌必须明确：

* 持续时间
* 生效对象
* 开始时机
* 结束时机
* 是否可以叠加
* 重复获得时如何处理
* 来源消失时是否提前结束

持续效果应转化为状态或其他已有运行时对象，由对应系统管理剩余时间、层数和移除条件。

策略牌进入弃牌堆后，其已经生成的持续状态仍可继续存在，直至满足结束条件。

### 4.5 随机效果

策略牌应避免大量随机效果，降低不可控因素。

如果必须使用随机结果，应明确：

* 随机范围
* 候选结果
* 每个结果的权重
* 是否受到幸运值或其他属性影响
* 随机发生的具体时机

随机过程由统一随机系统负责，策略牌不能自行定义含义不明的“较高概率”或“极低概率”。

### 4.6 系统联动

策略牌应尽量与战斗、探索、天气、昼夜、事件、经济和其他已有系统产生联动。

例如：

* 战斗牌调用命中、伤害和状态规则
* 探索牌读取地形、区域或视野信息
* 天气牌读取当前天气状态
* 事件牌修改一个尚未完成结算的事件
* 资源牌调用经济系统完成获取或支付

策略牌只声明需要产生的效果，不重复实现其他系统的底层逻辑。

### 4.7 禁止循环触发

策略牌效果不得形成无限响应、无限抽取、无限资源或无法结束的结算循环。

涉及再次使用、返回手牌、复制或触发其他策略牌的效果时，必须明确次数限制、目标限制和结束条件。

## 5. 数值设计规范

策略牌数值应遵循《06-数值系统》的整数、取整和边界规则。

### 5.1 整数优先

伤害、治疗、移动、资源、次数和持续回合原则上使用整数。

能够使用固定整数表达的效果，不应优先设计为百分比。

### 5.2 使用已有属性

策略牌应优先读取或临时修正已有基础属性与派生属性。

临时属性修正统一通过属性修饰器实现：

| 效果 | 数值系统处理方式 |
| --- | --- |
| 临时修正五项基础属性 | 写入 `primaryDynamicOffset` |
| 临时修正派生属性 | 写入 `derivedDynamicOffset` |

效果结束后必须移除对应修饰器，不得将策略牌的临时收益写入角色永久属性。

### 5.3 比例与概率

涉及比例或概率时，必须使用项目统一的整数单位，并明确：

* 计算顺序
* 取整方式
* 最小值
* 最大值
* 是否受到其他修饰器影响

策略牌不应为已有命中、暴击、闪避和幸运规则重新建立独立概率体系。

### 5.4 数值与品质

品质越高，不代表数值必须按固定倍数增长。

数值强度应与以下内容共同考虑：

* 使用条件
* 适用范围
* 目标数量
* 使用时机
* 获取难度
* 是否需要支付资源
* 是否存在明确反制方式

不能仅根据品质确定伤害、治疗或资源收益。

## 6. 命名规范

策略牌名称应简洁、直观，并能够体现其主要作用或叙事主题。

建议采用以下命名方式：

| 命名方向 | 示例 |
| --- | --- |
| 动作类 | 疾跑、突袭、格挡、反击 |
| 道具类 | 急救包、传送卷轴、防毒面具 |
| 法术类 | 神迹、冰封术、时间暂停 |
| 特殊类 | 命运逆转、裂变干涉、世界树祝福 |

同一系列策略牌应保持统一命名风格，便于玩家记忆与识别。

命名还应遵循以下规则：

* 同一策略牌名称必须唯一
* 不同效果不能使用完全相同的名称
* 名称不直接堆叠品质词语，例如“超级”“终极”“至尊”
* 名称不使用无法从世界观或效果中解释的专业术语
* 名称不应暗示牌面不存在的效果
* 系列牌可以使用共同前缀或意象，但必须保留可区分部分

策略牌的唯一标识使用稳定的配置名称。显示名称可以在不影响存档与配置引用的情况下调整，唯一标识一旦进入正式版本则不应随意修改。

## 7. 关键字规范

关键字用于将重复出现的通用规则压缩为统一术语，减少牌面文本长度并保证相同效果采用相同结算方式。

### 7.1 关键字设计原则

一个关键字必须满足以下条件：

* 会被多张策略牌重复使用
* 拥有唯一且稳定的规则含义
* 能够显著减少重复文本
* 可以由系统统一识别和结算
* 不依赖单张牌的特殊解释

只在一张策略牌上出现的效果不应创建新关键字，应直接写入该牌效果说明。

### 7.2 建议通用关键字

当前阶段可以使用以下基础关键字：

| 关键字 | 统一含义 |
| --- | --- |
| 瞬时 | 响应窗口关闭后一次性完成效果，不产生持续状态。 |
| 持续 N 回合 | 生成持续指定回合数的状态，并由状态系统管理。 |
| 仅自己回合 | 只能在使用者自己的合法行动阶段使用。 |
| 全局响应 | 无论使用者与目标的位置关系，只要满足其他条件即可参与响应。 |
| 选择 | 使用时从牌面列出的合法效果或目标中选择一项。 |
| 随机 | 由统一随机系统从明确候选结果中产生结果。 |
| 消耗 | 结算完成后进入弃牌堆，且不能被本次效果再次使用。 |

“瞬时”不代表不可响应，“全局响应”也不代表忽略其他使用条件。

任何新增关键字都必须先写入通用规则，再用于具体策略牌。不能在不同策略牌中为同一关键字赋予不同含义。

### 7.3 关键字与效果文本

关键字用于表达通用行为，效果文本用于表达当前策略牌的具体数值、目标和结果。

例如：

```text
关键字：持续 2 回合
效果：目标的移动力 -1。
```

关键字不能取代必要信息。即使使用“持续”关键字，策略牌仍需明确目标、效果数值以及重复使用时的叠加规则。

## 8. 新增策略牌检查流程

新增策略牌时，应按照以下流程进行设计：

```text
明确使用场景
↓
确定核心效果
↓
确定策略牌类型
↓
确定使用时机与响应对象
↓
确定作用目标
↓
确定数值与持续时间
↓
确定品质与获取方式
↓
选择已有关键字
↓
检查响应、叠加与循环风险
↓
完成牌面文本
```

进入正式配置前，应至少确认：

* 是否只有一个明确核心效果
* 是否能够判断合法使用时机
* 是否明确响应对象与作用目标
* 是否优先产生短期影响
* 是否使用已有属性和系统规则
* 是否明确持续时间与结束条件
* 是否明确结算去向
* 是否可能形成无限响应或资源循环
* 品质是否与获取难度和影响能力匹配
* 名称与关键字是否符合统一规范
* 牌面文本是否能够独立理解

---

## 9. 后续扩展

新增策略牌时，应优先考虑是否能够丰富玩家的策略选择，而不是单纯提高数值。

鼓励设计具有不同使用场景的策略牌，使玩家能够根据战斗、探索、天气、事件和副本等不同环境灵活选择，而不是始终依赖少数几张高品质策略牌。

后续所有新增策略牌均应遵循本规范进行设计，以保证整个策略牌系统风格统一、规则一致，并具备良好的可维护性。

六大策略牌类型的具体职责、使用场景和示例将在 [《03-策略牌类型》](03-策略牌类型.md) 中详细说明。
