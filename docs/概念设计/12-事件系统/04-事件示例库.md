# 《开天辟地之大地的裂变》事件示例库

## 1. 普通事件

普通事件是游戏中最常见的随机事件，主要影响当前玩家，一般不会对整个世界造成较大影响。

### 1.1 遗弃营地

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 普通 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 玩家在森林、荒野或山地探索带有营地标记的地块。 |
| 事件选项 | 搜索物资；原地休息。 |
| 事件效果 | 搜索物资：从当前区域普通材料池中随机获得 `2` 份材料。原地休息：恢复 `10` 点当前生命值。 |
| 持续方式 | 即时 |

玩家必须从两个选项中选择一个，不能同时获得材料与治疗。当前生命值已满时仍可选择休息，但超出最大生命值的部分不会保留。

### 1.2 流浪商人

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 普通 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 玩家在白天探索城镇以外的可通行区域。 |
| 事件选项 | 查看商品；直接离开。 |
| 事件效果 | 查看商品：生成包含 `3` 件商品的临时商店，玩家可以按照标示元宝价格完成至多 `1` 次购买。直接离开：事件结束。 |
| 持续方式 | 即时 |

商品应从当前区域允许出现的流浪商人商品池中抽取。临时商店只对事件触发者开放，并在事件结束后立即关闭。

## 2. 命运事件

命运事件通常具有较大的影响力，会改变玩家当前的发展方向，可能带来较高收益，也可能伴随相应风险。

### 2.1 幸运女神

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 稀有 |
| 揭露方式 | 可选择揭露（`OPTIONAL`） |
| 触发场景 | 玩家完成命运判定，且当前未拥有“幸运女神”效果。 |
| 事件效果 | 玩家接下来触发的 `3` 次个人随机事件中，带有正面标签的合法候选事件当前权重变为原来的 `2` 倍。 |
| 重复规则 | 效果存在期间不能再次触发。 |
| 持续方式 | 条件结束，完成 `3` 次个人随机事件揭露并开始结算后结束。 |

该效果只调整合法候选事件的权重，不保证必然抽到正面事件，也不会使不满足触发条件的事件进入候选集合。世界事件与其他玩家触发的事件不计入次数。

### 2.2 恶魔低语

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 史诗 |
| 揭露方式 | 可选择揭露（`OPTIONAL`） |
| 触发场景 | 玩家在夜晚探索诅咒地点，且未拥有“恶魔印记”。 |
| 事件选项 | 接受交易；拒绝交易。 |
| 事件效果 | 接受交易：从当前阶段的稀有装备池中获得 `1` 件装备，同时获得“恶魔印记”，最大生命值 `-5`。拒绝交易：事件结束。 |
| 持续方式 | “恶魔印记”持续至玩家在神殿支付对应服务费用完成净化。 |

“恶魔印记”属于可解除的诅咒状态，不是永久写入角色基础属性的成长结果。玩家获得装备前，应能够看到诅咒效果及解除方式。

## 3. 遭遇事件

遭遇事件会生成新的交互对象，通常与怪物、NPC 或即时战斗有关。

### 3.1 野兽袭击

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 普通 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 玩家在森林、荒野或山地探索，且当前不处于战斗状态。 |
| 事件效果 | 从当前区域野兽遭遇池中生成 `1` 名与游戏阶段匹配的敌人，玩家立即进入战斗。 |
| 成功结果 | 玩家获胜后，按照该敌人的奖励配置获得经验值、元宝或材料。 |
| 失败结果 | 按照战斗系统的失败与撤退规则处理。 |
| 持续方式 | 持续至本次战斗结束。 |

事件系统只负责创建遭遇并进入战斗流程，敌人强度、战斗结算与奖励发放由战斗系统负责。

### 3.2 神秘旅人

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 稀有 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 玩家在道路、营地或城镇边缘探索。 |
| 事件选项 | 交易；购买情报；直接离开。 |
| 事件效果 | 交易：开启一次临时交易。购买情报：支付配置的元宝费用，获得当前区域的 `1` 条有效探索线索。直接离开：事件结束。 |
| 持续方式 | 即时 |

交易商品、情报费用与线索内容由当前区域配置决定。已经失效或无法继续追踪的地点不能作为情报结果。

## 4. 世界事件

世界事件影响所有玩家或多个区域，是整局游戏中的重要公共事件。

### 4.1 丰收时代

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 史诗 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 世界事件阶段，且当前不存在其他“丰收时代”。 |
| 事件效果 | 所有玩家通过地图资源点完成采集时，每次额外获得 `1` 份对应材料。 |
| 重复规则 | 同一时间只能存在一个“丰收时代”，重复触发时忽略新事件。 |
| 持续方式 | 固定回合，持续 `3` 个完整回合。 |

额外产出只作用于地图资源点的正常采集，不影响任务奖励、商店购买、玩家交易或事件直接发放的材料。

### 4.2 世界裂变

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 传说 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 世界裂变值达到对应阶段，且地图中存在合法裂变区域。 |
| 事件效果 | 从合法区域中选择 `1` 个区域并执行一次区域裂变，可以开启新道路、封锁原有路线、改变资源点或生成特殊地点。 |
| 持续方式 | 地图变化按照裂变结果持续，临时变化由各自配置决定结束时间。 |

具体裂变结果由地图裂变系统生成。事件系统只负责发起一次区域裂变，不能自行修改地图连通性，也不能使所有玩家与终局目标之间同时失去合法路径。

---

## 5. 灾难事件

灾难事件通常对地图环境造成负面影响，用于增加探索难度并迫使玩家调整路线。

### 5.1 山体滑坡

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 稀有 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 山地区域存在至少一条可以临时封锁的非关键道路。 |
| 事件效果 | 随机选择 `1` 条合法山路并设置为封锁状态，角色无法通过该道路。 |
| 持续方式 | 固定回合，持续 `2` 个完整回合。 |

不能选择唯一通往出生点、主要城镇或创界山的道路。封锁结束后，道路自动恢复原有通行状态。

### 5.2 暴风雪

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 史诗 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 寒冷或高地区域，且该区域当前不存在暴风雪。 |
| 事件效果 | 指定区域进入暴风雪天气。区域内所有角色的移动力 `-1`、视野 `-1`。 |
| 重复规则 | 同一区域不能同时存在多个暴风雪。 |
| 持续方式 | 固定回合，持续 `3` 个完整回合。 |

移动力与视野修正通过动态偏移量参与计算，并遵循对应属性的最小边界。离开暴风雪区域后，角色不再受到该区域效果影响。

## 6. 奇遇事件

奇遇事件属于较为稀有的正向事件，为玩家提供隐藏奖励或特殊机会。

### 6.1 古代遗迹

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 稀有 |
| 揭露方式 | 可选择揭露（`OPTIONAL`） |
| 触发场景 | 玩家首次探索未被发现的遗迹地点。 |
| 事件选项 | 研究石碑；搜集遗物。 |
| 事件效果 | 研究石碑：从当前阶段图纸池中随机获得 `1` 张未知图纸。搜集遗物：从当前区域稀有材料池中随机获得 `2` 份材料。 |
| 重复规则 | 每处遗迹只能触发一次。 |
| 持续方式 | 即时 |

未知图纸仍需通过鉴定才能揭示具体内容。玩家必须选择一种探索方向，不能同时获得图纸与材料。

### 6.2 神秘传送门

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 史诗 |
| 揭露方式 | 可选择揭露（`OPTIONAL`） |
| 触发场景 | 玩家探索裂缝、遗迹或其他高能量地点。 |
| 事件选项 | 进入传送门；留在原地。 |
| 事件效果 | 进入传送门：选择任意一个已经探索、当前开放且允许进入的重要地点，将角色传送至该地点。留在原地：事件结束。 |
| 持续方式 | 即时 |

传送不能绕过副本准入、地图封锁、任务条件或创界山资格。抵达目标后，正常处理目标地点的进入规则。

## 7. 祝福事件

祝福事件为玩家提供持续性的正面增益效果。

### 7.1 大地祝福

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 稀有 |
| 揭露方式 | 可选择揭露（`OPTIONAL`） |
| 触发场景 | 玩家在祭坛完成祈祷，且未拥有“大地祝福”。 |
| 事件效果 | 玩家的物理防御 `+2`、法术抗性 `+2`。 |
| 重复规则 | 重复获得时刷新持续时间，不叠加数值。 |
| 持续方式 | 固定回合，持续 `3` 个完整回合。 |

该效果通过派生属性动态偏移量实现，不直接修改角色的基础属性。

### 7.2 风神眷顾

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 稀有 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 玩家在高地、风之祭坛或特定天气下完成探索。 |
| 事件效果 | 玩家的移动力 `+1`。 |
| 重复规则 | 重复获得时刷新持续时间，不叠加数值。 |
| 持续方式 | 固定回合，持续 `3` 个完整回合。 |

风神眷顾只增加单次移动距离，不改变移动速度与回合行动顺序。

## 8. 诅咒事件

诅咒事件会给予玩家负面状态，但通常具有明确的持续时间或解除方式。

### 8.1 衰弱诅咒

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 稀有 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 玩家开启被诅咒的容器，或在诅咒地点探索失败。 |
| 事件效果 | 玩家的物理攻击 `-2`、法术攻击 `-2`。 |
| 重复规则 | 重复获得时刷新持续时间，不叠加数值。 |
| 持续方式 | 固定回合，持续 `3` 个完整回合。 |

该效果通过派生属性动态偏移量实现。神殿或明确具有净化能力的效果可以提前移除该诅咒。

### 8.2 迷失方向

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 普通 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 玩家在迷雾、沙漠、密林或幻境中探索失败。 |
| 事件效果 | 玩家下一次主动移动时，由系统从当前位置所有合法相邻地块中随机选择第一个移动目标。完成第一步后，玩家可以正常决定剩余路线。 |
| 持续方式 | 条件结束，完成下一次主动移动的第一步后结束。 |

如果效果结算时不存在合法相邻地块，则玩家本次无法移动，随后移除“迷失方向”。传送与强制位移不消耗该效果。

## 9. 彩蛋事件

彩蛋事件主要用于增加趣味性，并承载《爱情公寓第三季》原作相关内容。此类事件应保持低频、轻量且易于结算，不应成为稳定获取强力收益的途径。

### 9.1 展博的隐藏程序

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 史诗 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 玩家满足隐藏条件并从彩蛋事件池中抽到本事件。 |
| 事件效果 | 从本次触发对应的原事件池中额外抽取 `2` 个不同的合法事件，玩家选择其中 `1` 个进行结算。 |
| 重复规则 | 每名玩家一局最多触发一次。 |
| 持续方式 | 即时 |

额外抽取时排除本事件及已经完成的整局唯一事件。如果合法候选事件不足 `2` 个，则使用全部可用候选；不存在合法候选时，本事件不产生额外效果。额外抽取的事件只展示其卡背，玩家选中其中一个后，仍按照该事件自身的揭露方式继续处理，未选中的事件不公开内容。

### 9.2 胡一菲的弹一闪

| 项目 | 内容 |
| --- | --- |
| 建议稀有度 | 史诗 |
| 揭露方式 | 强制揭露（`FORCED`） |
| 触发场景 | 玩家满足原作彩蛋条件，且当前未拥有“弹一闪”效果。 |
| 事件效果 | 在玩家下一场战斗的首次先手排序中，先手值 `+5`；首次排序完成后立即移除该效果，并播放对应彩蛋提示。 |
| 重复规则 | 效果存在期间不能再次触发。 |
| 持续方式 | 条件结束，下一场战斗完成首次先手排序后结束。 |

“弹一闪”只影响下一场战斗的首次行动顺序，不提供额外攻击、不提高伤害，也不绕过战斗开始阶段的强制效果。

## 10. 说明

本示例库用于展示事件系统的设计方向，不代表最终事件数量或最终平衡数值。

文档中的数值、回合数、稀有度与触发范围均为初始建议，应在完成战斗、地图、天气、NPC 与任务等相关系统后统一进行测试和调整。

为了保持示例易于阅读，本文没有完整列出 `eventId`、事件标签、基础权重、事件池引用与全部配置字段，但保留了直接影响交互流程的揭露方式。事件进入正式资源库前，仍须按照《03-事件设计规范》补齐完整数据并通过配置校验。

示例中的揭露方式均为事件自身配置，不代表同类事件必须采用相同方式。尤其是祝福与诅咒事件，应根据其代表“已经发生的事实”还是“玩家主动探索的未知机会”分别选择强制揭露或可选择揭露。

正式版本中，每种事件类型均可根据游戏内容持续增加新的事件。新增事件应优先体现区域环境、玩家选择与系统联动，而不是只用不同文本重复相同奖励。

随着地图、NPC、副本、装备与世界观不断完善，事件库也将持续扩展，使每一局游戏都具有丰富的随机性、探索差异与故事体验。
