# 《开天辟地之大地的裂变》等级系统

## 1. 系统概述

等级系统用于描述角色在游戏中的成长过程，是角色基础能力提升的重要途径之一。

本游戏采用轻等级成长的设计理念。等级仅作为角色成长的基础框架，不承担身份、转职、技能和装备等其他系统的功能。

玩家真正的成长仍然主要来自：

* 身份与转职
* 装备选择
* 属性分配
* 使命推进
* 地图探索
* 事件与特殊经历

这种设计可以避免形成传统角色扮演游戏中“等级决定一切”的玩法，使等级较低但装备、构筑和策略选择更合理的角色仍然拥有竞争能力。

等级系统遵循以下原则：

* 等级成长简单直观
* 每次升级均具有明确收益
* 不鼓励单纯刷怪升级
* 与其他成长系统保持相互独立
* 等级本身不直接参与具体玩法判定

等级系统的核心定位可以概括为：

**等级提供稳定的基础成长空间，但不直接代表角色的最终强度。**

## 2. 经验值获取

### 2.1 经验值定位

经验值（Experience Point，EXP）是角色用于提升等级的成长资源。

经验值不属于基础属性、派生属性或属性修饰器，也不会直接影响战斗、移动、探索和事件判定。

经验值只用于判断角色是否满足升级条件，并在升级时支付对应消耗。

### 2.2 获取来源

角色可以通过参与游戏中的不同内容获得经验值。

经验值来源不限于战斗，而应覆盖整个游戏过程，鼓励玩家体验不同玩法。

典型来源包括：

* 完成事件
* 完成使命或使命阶段目标
* 取得战斗胜利
* 探索未知区域
* 完成特殊剧情
* 击败首领
* 完成 NPC 委托
* 完成副本或特殊地点挑战

不同内容可以根据规模、难度和稀有程度给予不同数量的经验值，由对应事件、任务、敌人或地点自行配置。

等级系统只负责接收和保存最终经验奖励，不负责判断任务是否完成、战斗是否胜利或区域是否已经探索。

### 2.3 经验奖励原则

经验奖励应遵循以下规则：

* 经验值使用非负整数
* 奖励来源必须明确且可以追踪
* 同一内容是否能够重复获得经验必须由来源配置说明
* 未完成、失败或被取消的内容默认不提供完整经验奖励
* 重复且低风险的行为不应成为最高效率的经验来源
* 高额经验应优先来自阶段目标、首次探索和高难度内容

为了避免玩家通过重复击败低风险敌人或反复触发简单事件刷取等级，可根据具体内容采用：

* 仅首次完成提供经验
* 每轮或每局设置获取次数
* 重复完成时降低经验
* 将经验放在阶段目标而非单个重复行为上

具体限制由奖励来源负责，等级系统不为不同玩法编写特殊判断。

## 3. 升级机制

### 3.1 可升级状态

当角色当前经验值达到该等级所需经验时，不会立即升级，而是进入可升级状态。

可升级状态只表示角色已经满足经验条件，不会自动产生以下变化：

* 不会自动提高等级
* 不会自动扣除经验
* 不会自动分配属性点
* 不会打断正在进行的行动或结算
* 不会自动恢复生命值或灵力值

玩家可以暂时保留可升级状态，并在后续自己的回合中主动完成升级。

### 3.2 升级时机

玩家只能在自己的行动阶段主动选择升级。

升级默认占用一次次要行动，并且必须满足以下条件：

* 当前经验值达到升级需求
* 当前等级尚未达到等级上限
* 本回合尚未完成过升级
* 当前拥有可用的次要行动
* 当前没有禁止升级的特殊状态或规则

每名角色在自己的一个回合内最多提升一级。即使当前经验足以支付多个等级的需求，也不能在同一回合连续升级。

身份、装备或其他效果可以改变行动资源，但不能绕过“每回合最多提升一级”的基础限制，除非规则明确声明为特殊例外。

### 3.3 升级流程

标准升级流程如下：

```text
玩家在自己的行动阶段声明升级
↓
检查等级上限、经验值与本回合升级记录
↓
检查并支付一次次要行动
↓
读取本次升级获得的自由属性点与额外成长
↓
玩家分配自由属性点
↓
确认升级方案
↓
扣除当前等级所需经验
↓
角色等级提升一级
↓
将属性成长写入当前基础属性
↓
保留剩余经验并重新计算派生属性
```

升级确认前，玩家可以调整本次自由属性点的分配方案。

升级确认后，本次经验消耗、等级变化和属性成长作为一次完整操作同时生效。若任意必要数据不合法，则整个升级操作失败，不扣除部分经验，也不写入部分属性。

### 3.4 经验消耗与保留

升级时，角色只消耗当前等级提升至下一级所需的经验值。

例如：

```text
当前等级：Lv3
当前经验：55
Lv3 → Lv4 所需经验：40

升级后等级：Lv4
升级后剩余经验：15
```

剩余经验自动保留，并用于判断角色是否已经满足下一次升级条件。

即使剩余经验已经达到下一等级需求，角色也必须等到后续自己的回合，才能再次主动升级。

达到当前版本等级上限后，角色不再进入可升级状态。满级后的经验奖励是否继续保留或转换为其他资源，不属于当前等级机制的基础规则，由后续版本另行定义。

## 4. 属性成长

### 4.1 自由属性点

角色每次升级后均可获得自由属性点，具体数量随等级阶段逐步提高：

* 前期升级获得 `1` 点
* 中期升级获得 `2` 点
* 后期升级获得 `3` 点

玩家可以根据自身培养方向，将属性点自由分配至五项基础属性：

* 力量
* 体质
* 灵力
* 敏捷
* 悟性

每次升级获得的自由属性点由目标等级配置统一维护，不写入升级算法。若后续数值测试需要调整成长速度或阶段边界，只需修改等级配置，无需改变升级流程。

本次升级获得的自由属性点必须在升级确认前完成分配，不能以未分配状态长期保留。

### 4.2 永久成长

升级属性点属于角色永久成长。

玩家确认分配后，对应数值直接写入角色的当前基础属性，不以 `primaryDynamicOffset` 或其他动态修饰器形式保存。

例如：

```text
升级前力量：7
本次分配力量：+1
升级后力量：8
```

升级后的基础属性变化由《06-数值系统》重新换算为派生属性，并进一步影响角色的实际能力。

角色创建时“初始基础属性总量保持一致”的规则只约束角色创建阶段。游戏开始后的升级、转职、任务和剧情成长可以使角色的基础属性总量超过初始总量 `25`。

### 4.3 身份与转职修正

不同身份或转职可以通过自身特性，对升级收益进行额外修正。

例如：

* 每次升级获得额外自由属性点
* 升级时固定增加某项基础属性
* 达到特定等级时解锁一项身份能力
* 特定等级区间采用不同成长倾向

这些内容属于身份或转职特性，而不是等级系统的通用规则。

额外属性点与固定属性成长同样属于永久成长，必须通过《06-数值系统》规定的方式写入当前基础属性，不能绕过属性系统直接修改最终战斗结果。

身份或转职可以修正单次升级收益，但不应自行改变经验扣除、每回合升级次数和等级上限等基础规则，除非存在明确的特殊机制。

## 5. 等级规划

角色等级采用较低的等级上限，强调每一级成长带来的价值。

当前首版建议等级上限为 `Lv10`。

初步经验规划如下：

| 等级提升 | 所需经验（示例） | 自由属性点 |
| --- | ---: | ---: |
| Lv1 → Lv2 | 20 | 1 |
| Lv2 → Lv3 | 30 | 1 |
| Lv3 → Lv4 | 40 | 1 |
| Lv4 → Lv5 | 50 | 2 |
| Lv5 → Lv6 | 60 | 2 |
| Lv6 → Lv7 | 70 | 2 |
| Lv7 → Lv8 | 80 | 3 |
| Lv8 → Lv9 | 90 | 3 |
| Lv9 → Lv10 | 100 | 3 |

该示例采用简单递增方式：

```text
升至目标等级所需经验 = 目标等级 × 10
```

例如，升至 `Lv6` 需要 `60` 点经验。

该公式只用于描述当前建议曲线。正式数值应由等级配置维护，不写入程序逻辑。

简单递增曲线具有以下优点：

* 玩家容易理解和记忆
* 每级成长节奏清晰
* 方便估算下一次升级距离
* 便于后续进行整体数值调整
* 不需要复杂的指数或幂运算

如果后续版本提高等级上限，可以继续沿用相同增长规律，也可以通过配置调整新增等级的经验需求，无需修改升级机制。

## 6. 系统联动与设计说明

### 6.1 系统职责

等级系统与其他系统保持明确的职责边界：

| 关联系统 | 主要职责 |
| --- | --- |
| 数值系统 | 保存升级后的当前基础属性，并重新计算派生属性。 |
| 回合系统 | 提供升级操作时机、次要行动与每回合升级记录。 |
| 身份与转职系统 | 定义额外升级收益、等级条件和成长倾向。 |
| 使命与任务系统 | 判断目标是否完成，并提供对应经验奖励。 |
| 战斗系统 | 判断战斗结果，并提供配置中的经验奖励。 |
| 地图系统 | 判断探索与特殊地点完成情况，并提供经验来源。 |
| 事件系统 | 根据事件结果发放经验奖励。 |

等级系统只处理：

* 当前等级
* 当前经验值
* 升级所需经验
* 可升级状态
* 单次升级流程
* 每次升级提供的自由属性点

等级系统不负责身份能力、转职路线、任务条件、战斗胜负和地图探索判定。

### 6.2 等级不直接参与玩法判定

等级本身不直接加入攻击、生命、移动、命中、制造或其他派生属性公式。

如果某项玩法需要使用等级，应将等级作为明确的资格条件，例如：

* 达到指定等级后允许转职
* 达到指定等级后可以接受任务
* 达到指定等级后可以使用装备

等级不能作为隐藏系数直接提高所有战斗能力。

### 6.3 等级不等于角色强度

等级越高，意味着角色已经获得更多基础成长空间，但不会直接决定战斗胜负。

角色综合实力仍然受到以下内容共同影响：

* 身份与转职路线
* 基础属性分配
* 装备选择
* 使命完成情况
* 手牌与资源
* 地图和天气环境
* Buff、Debuff 与其他临时状态

因此，等级系统应保持简单、稳定且易于理解，使玩家能够在体验不同玩法的过程中自然成长，而不是为了升级刻意重复某一种行为。
