# 《开天辟地之大地的裂变》地图系统文档索引

## 1. 文档目的

本文用于说明地图系统的文档结构、各章节职责与统一空间术语，帮助后续设计与开发快速定位权威规则。

地图系统已经统一采用平顶六边形地块与立方体坐标。任何新增地图文档都必须遵循本目录中的坐标、方向、距离、环数和地势定义。

## 3. 统一空间标准

地图系统采用以下统一标准：

| 项目 | 当前规则 |
| --- | --- |
| 地块形态 | 平顶六边形 |
| 地图结构 | 第 `0` 环至第 `10` 环 |
| 基础地块总数 | `331` 格 |
| 坐标体系 | 立方体坐标 `(x, y, z)` |
| 坐标约束 | `x + y + z = 0` |
| 普通相邻方向 | 正北、北偏东 `60°`、南偏东 `60°`、正南、南偏西 `60°`、北偏西 `60°` |
| 环数公式 | `max(|x|, |y|, |z|)` |
| 距离公式 | `max(|Δx|, |Δy|, |Δz|)` |
| 正常边界 | 第 `10` 环，共 `60` 格 |
| 地势字段 | `elevation` |

立方体坐标中的`z`是二维六边形位置坐标，不表示高度。任何地势、海拔与高低差规则都必须读取独立的`elevation`。

## 4. 文档职责

### 4.1 01-地图系统总览

定义地图系统的总体定位、六边形结构、基础规格、空间层级、核心对象及与其他系统的关系。

该文档不规定具体地形消耗、事件内容或战斗数值。

### 4.2 02-单元地块设定

定义最小空间单位，包括：

* 地块稳定ID；
* 立方体坐标与环数；
* 独立地势；
* 六方向空间相邻；
* 区域、地形与通行字段；
* 地块与角色、NPC、事件和地点的引用边界。

### 4.3 03-地图规模与坐标

定义完整地图的几何规则，包括：

* 平顶六边形方向；
* 十环与`331`格规模；
* 立方体坐标约束；
* 六方向向量；
* 环数、距离与相邻公式；
* 第十环边界；
* 基础坐标生成与数据校验。

该文档是所有空间计算的权威来源。

### 4.4 04-区域系统

定义连续六边形地块如何组成区域，以及区域名称、类型、环境、事件池、资源与特殊规则。

区域连续性按照六方向相邻关系判断。

### 4.5 05-基础地形

定义平原、森林、山地、沙漠、水域等底层自然地形，以及独立地势`elevation`的作用。

城市、遗迹和副本入口不属于基础地形。

### 4.6 06-地块附属要素

定义覆盖在基础地形上的道路、桥梁、城镇、资源点、祭坛、遗迹与临时标记。

基础地形、附属要素和动态状态相互独立。

### 4.7 07-障碍与通行规则

统一定义地块及地块边之间的阻挡、条件通行和绕过方式，包括水域、山脉、悬崖、结界、桥梁、飞行与临时封锁。

空间相邻不代表实际可以通行。

### 4.8 08-地图边界

定义第十环边界、向外方向、越界处理、边界探索标识及未来地图扩展方式。

普通系统不能生成或进入第十一环地块。

### 4.9 09-出生点与初始布局

定义第八环至第十环出生区域、队伍布局、出生安全性与出生点六边形距离要求。

### 4.10 10-探索与视野

定义“先探索、后视野”的战争迷雾规则、六边形视野距离、立方体视线传播、地势遮挡与玩家可见信息权限。未踏足地块不参与普通视野计算。

### 4.11 11-移动与寻路

定义六方向自由移动、首次探索、移动力消耗、文明区域、特殊道路、方向限制、强制位移、寻路与逐格结算。

回合阶段由回合系统负责，本章只定义移动如何使用地图空间。

### 4.12 V2-特殊地点

定义具有独立交互功能的地点，例如城邦、神殿、副本入口、迷宫、竞技场、传送节点与隐藏地点。

### 4.13 V2-地图裂变机制

定义裂变如何改变地形、地势、道路、区域、地点和通行状态。

普通裂变不改变基础立方体坐标、最大环数与地块总量。

  ▼     ▼          ▼

  │     │          │
  └─────┼──────────┘
        ▼
   障碍与通行
        │
  ┌─────┼──────────┐
  ▼     ▼          ▼
出生   探索视野   移动寻路
        │

坐标和地块属于底层空间能力。区域、地形和地点在其上组织内容，移动、视野与战斗读取统一空间结果。

## 6. 新增地图规则要求

新增地图内容时，应遵循以下要求：

1. 不建立第二套正方形、像素或自定义方向坐标。
2. 不将`z`重新解释为地势高度。
3. 不在业务模块中重复实现六方向与距离公式。
4. 不将空间相邻直接视为必然可通行。
5. 不绕过第十环边界创建普通地图坐标。
6. 不将NPC、事件、任务和怪物对象直接写入静态地块配置。
7. 新区域必须校验六方向连通性。
8. 新道路必须明确起点、终点、方向、消耗和通行条件。
9. 新地图版本必须校验坐标唯一性、环数、总格数与关键区域可达性。
10. 修改空间规则时同步更新地图、移动、视野、战斗和测试文档。
