# 《开天辟地之大地的裂变》移动与寻路

## 1. 文档目的

本文用于定义《开天辟地之大地的裂变》地图系统中的移动（Movement）与寻路（Pathfinding）规则。

本章重点说明：

* 角色默认可以向什么方向移动。
* 移动力如何消耗。
* 首次探索如何结束移动。
* 文明区域、特殊道路与特殊效果如何改变移动规则。
* 系统如何生成合法路线并逐格完成结算。

本章不具体展开以下内容：

* 地图事件的具体内容。
* 战斗中的追击、逃跑与位移技能。
* 各类异常状态的具体数值。
* 飞行、载具与传送网络的完整设计。

---

## 2. 设计目标

移动系统是玩家探索世界、接触事件和完成使命的重要方式。

《开天辟地之大地的裂变》采用环形地图与六方向自由移动相结合的探索方式。玩家可以在规则允许时主动选择任意一个相邻方向，但仍需逐格移动，并受到移动力、首次探索、地形、障碍、道路和地图边界的共同限制。

移动系统遵循以下设计目标：

* 默认规则简单，玩家能够快速理解。
* 探索未知区域需要付出明确的回合成本。
* 特殊移动方式能够改变路线，但不会使基础地图失去意义。
* 玩家可以自由选择探索方向，但不能绕过移动成本、未知区域与通行条件直接抵达目标。
* 地图随着游戏推进逐渐由未知变为已知，形成完整的探索过程。
* 底层通行、移动消耗与逐格结算规则保持统一，避免不同移动来源各自建立独立流程。

移动系统的核心定位可以概括为：

**已知区域用于路线规划，未知区域用于探索决策，特殊移动用于打破既有路线。**

---

## 3. 空间与六方向移动模型

世界地图采用第 `0` 环至第 `10` 环的平顶六边形结构，并使用满足 `x + y + z = 0` 的立方体坐标。

每个普通地块最多拥有六个空间相邻方向：

* 上：正北；
* 右上：北偏东 `60°`；
* 右下：南偏东 `60°`；
* 下：正南；
* 左下：南偏西 `60°`；
* 左上：北偏西 `60°`。

普通移动完全建立在六方向空间相邻关系之上，不建立顺时针、逆时针或固定环向移动状态。

每个普通地块最多拥有六个可选相邻地块。玩家每移动一步，都可以重新从当前地块的合法相邻方向中选择目标。移动后可能进入内环、外环或保持在当前环，这些关系只用于描述位置变化，不用于限制默认移动方向。

底层地图负责描述空间相邻、环数、特殊道路与传送连接；移动规则负责结合通行、消耗、探索状态和特殊效果判断玩家当前可以使用哪些连接。

---

## 4. 默认移动规则

### 4.1 出生位置

游戏开始后，所有玩家均出生于世界外围的聚居区域，通常位于第 `8` 至第 `10` 环。

出生点的具体选择与队伍分布由《09-出生点与初始布局》负责，移动系统只读取角色的初始位置与所在环。

### 4.2 默认移动方向

角色没有固定的默认移动方向。

玩家执行普通移动时，可以选择上、右上、右下、下、左下或左上任意一个合法相邻方向，并在每完成一步结算后重新选择下一步方向。

普通移动允许自然进入相邻的内环、外环或同环地块，但不能：

* 进入不相邻的普通地块。
* 穿过不可通行的地块或边障碍。
* 为缩短距离而使用尚未开放的隐藏道路或特殊连接。
* 移动至基础地图边界之外。

如果某一方向无法通行，玩家可以选择其他合法方向，或者主动结束本次移动。

### 4.3 基础移动力

移动力（Movement Range）表示角色在当前移动阶段内可以用于地图移动的数值。

普通角色在没有任何额外修正时，建议拥有 `3` 点可用移动力。因此，玩家一个回合通常可以主动选择：

* 停留原地，即移动 `0` 格。
* 前进 `1` 格。
* 前进 `2` 格。
* 前进 `3` 格。

角色本回合的实际可用移动力，以数值系统计算得到的最终移动力为准。装备、状态、天气和事件可以增加或降低该数值，因此特殊情况下可以低于或高于 `3`。

移动阶段开始时读取一次当前移动力，并记录为本回合可用移动力。移动过程中获得的临时修正是否立即生效，由对应效果明确说明；没有特殊说明时，从下一次移动阶段开始生效。

### 4.4 主动停止

玩家可以在任意一次合法移动完成后主动停止，无需耗尽全部移动力。

主动停止后，本次移动阶段结束，未使用的移动力不会保留至下一回合。

选择停留原地不属于“进入地块”，不会重复触发当前地块的进入事件、到达效果或首次探索效果。

## 5. 首次探索机制

### 5.1 首次探索的判断

当玩家准备进入一个自己从未踏足过的地块时，本次进入视为首次探索。

首次踏足记录是普通视野计算的前置条件：

* 玩家必须实际进入地块，才能将其记录为自己的已踏足地块。
* 未踏足地块不能通过普通视野提前揭示地形、单位、资源或事件。
* 地块完成首次踏足记录后，才会参与该玩家后续的视野计算。
* 前端显示的未知格遮罩不代表该地块已经进入玩家视野。

首次踏足记录默认由每名玩家分别维护。队伍共享地图情报不会自动替代个人的首次探索记录，除非特殊规则明确说明共享探索成果。

### 5.2 首次探索流程

首次探索按照以下流程处理：

```text
玩家尝试进入未踏足地块
          │
          ▼
检查方向、连接与通行条件
          │
          ▼
检查剩余移动力能否支付进入消耗
          │
          ▼
扣除本次进入所需移动力
          │
          ▼
角色进入目标地块并记录首次踏足
          │
          ▼
重新计算已探索区域内的当前视野
          │
          ▼
将本回合剩余移动力降为 0
          │
          ▼
结算地形、区域、事件与到达效果
          │
          ▼
本次主动移动结束
```

首次探索消耗全部剩余移动力，但不会绕过目标地块本身的进入消耗。角色剩余移动力不足以支付正常进入消耗时，不能进入该未知地块。

### 5.3 探索限制

由于首次探索会结束本次主动移动，玩家不能在同一个移动阶段内通过普通移动连续踏足多个未知地块。

自动寻路也必须遵守该限制。推荐路线最多只能将第一个未踏足地块作为本次移动的终点，不得规划穿过未知地块后的路线。

事件、传送或强制位移使角色进入未踏足地块时，该地块仍会被记录为已经踏足。如果这一情况发生在角色的主动移动过程中，本次主动移动立即结束。

## 6. 移动消耗与通行

### 6.1 基础移动消耗

角色通过普通连接进入一个相邻地块时，基础移动消耗为：

**基础移动消耗 = `1`**

每一步的总移动消耗由以下内容组成：

```text
总移动消耗
=
基础移动消耗
+ 地形附加消耗
+ 上坡附加消耗
+ 其他移动修正
```

所有结果使用整数，并遵循数值系统的边界与取整规则。单次普通移动的最终消耗最低为 `1`，除非特殊规则明确将该次移动定义为不消耗移动力。

### 6.2 地形附加消耗

普通地形不产生额外移动消耗。

泥泞、沼泽、积水道路等困难地形可以增加移动消耗，建议附加消耗控制在 `+1` 至 `+2`：

| 地形状态 | 基础消耗 | 附加消耗 | 总消耗 |
| --- | ---: | ---: | ---: |
| 普通地形 | `1` | `0` | `1` |
| 轻度泥泞 | `1` | `1` | `2` |
| 重度泥泞 | `1` | `2` | `3` |

具体数值由地形配置统一维护。

### 6.3 地势附加消耗

地势使用地块的独立 `elevation` 字段，不使用立方体坐标中的 `z`。`z` 只表示六边形位置。

向相同高度或更低高度移动时，不产生地势附加消耗。下坡不会降低基础移动消耗。

向更高地势移动时，使用以下公式：

```text
上坡附加消耗 = 2 × 地势差 - 1

地势差 = 目标地势 - 当前地势
```

该公式只在地势差大于 `0` 时生效。

| 当前地势 | 目标地势 | 地势差 | 上坡附加消耗 | 不含地形修正的总消耗 |
| ---: | ---: | ---: | ---: | ---: |
| `1` | `2` | `1` | `1` | `2` |
| `1` | `3` | `2` | `3` | `4` |
| `2` | `3` | `1` | `1` | `2` |

移动消耗增加不代表角色一定能够跨越任意地势差。悬崖、深渊和超出攀爬能力的高度差仍可能完全禁止通行。

### 6.4 通行判定

角色进入下一地块前，应依次确认：

1. 目标地块位于地图边界内。
2. 当前移动规则允许使用这条连接。
3. 目标地块本身允许进入。
4. 连接与目标地块未被障碍阻断。
5. 角色满足区域、道路或特殊地点的进入条件。
6. 角色拥有足够的剩余移动力。

通行合法性由《07-障碍与通行规则》统一判断，本章只负责提供当前允许使用的移动连接并计算移动消耗。

## 7. 特殊移动

事件、装备、能力、状态与特殊区域可以改变玩家的移动方式，但仍应尽量复用统一的连接、通行与位置更新流程。

### 7.1 文明区域移动

城镇、村庄、学院、神殿和港口等相互连接的有人烟地块，可以共同组成文明区域。

玩家位于文明区域内部时，仍然按照六方向普通移动规则逐格行动，同时可以使用该区域额外开放的道路与交通设施，包括：

* 在区域内部选择六方向空间相邻地块。
* 使用区域内已经开放的特殊道路与交通设施。

文明区域不提供额外的六方向自由权限，因为所有普通区域默认都允许选择合法相邻方向。其主要价值在于提供更稳定的道路、服务设施、传送节点和区域交互。

文明区域内的每一步仍需检查通行、地形消耗与首次探索，不代表玩家可以直接跳转至区域内任意地块。

### 7.2 方向限制效果

部分事件、状态、能力或特殊地形可以临时限制角色能够选择的移动方向。

方向限制必须明确：

* 允许或禁止哪些六方向。
* 持续指定回合。
* 持续至角色离开指定区域。
* 是否影响特殊道路和强制位移。

方向限制结束后，角色重新恢复六方向自由选择。单向道路的配置方向不受角色方向限制效果反转。

### 7.3 环数变化与特殊跨越

环数只用于描述地块距离地图中心的层级，不构成默认移动障碍。

如果一个六方向相邻地块位于不同环，并且通行条件合法，玩家可以通过普通移动直接进入该地块，无需额外的跨环权限。

以下来源可以提供跨越非相邻地块或多个环的特殊连接：

* 文明区域内部道路。
* 特殊事件。
* 特殊道具或装备。
* 地图机关。
* 传送装置。
* 剧情与副本入口。
* 特殊能力。

特殊连接完成后，玩家从目标地块继续按照六方向普通移动规则行动。

### 7.4 强制位移

强制位移是由外部效果直接改变角色位置的移动，例如：

* 狂风吹飞。
* 山体滑坡。
* 洪水冲走。
* 空间裂缝。
* 魔法传送。

强制位移本身不消耗角色当前移动力，也不受普通移动方向选择限制。

强制位移必须明确：

* 目标位置或目标选择方式。
* 是否逐格经过中间地块。
* 是否允许跨越多个环。
* 是否忽略障碍与占用。
* 抵达后是否触发地形、区域与进入事件。

没有特殊说明时，路径型强制位移逐格处理，传送型位移只处理目标地块。任何强制位移都不能将角色放置在地图边界外或无法合法停留的位置。

### 7.5 移动限制

冰冻、石化、束缚、击倒和沉睡等状态可以限制角色移动。

限制效果必须明确说明其具体结果，例如：

* 本次移动阶段无法主动移动。
* 本次移动力固定为 `1`。
* 只能向指定的一个或多个方向移动。
* 不能使用特殊道路或非相邻连接。
* 只能使用强制位移或传送。

不能仅使用“移动受到限制”等无法直接结算的描述。

## 8. 特殊道路

特殊道路用于改变普通六方向连接方式，并为探索提供新的交通选择。

### 8.1 单向道路

单向道路只能按照配置方向通过。

角色通过单向道路后，继续按照普通六方向移动规则行动。角色受到方向限制效果时，不会反转单向道路自身配置的通行方向。

### 8.2 隐藏道路

隐藏道路在被发现前不会参与玩家寻路，也不会向尚未获得该情报的玩家显示。

道路被发现后，可以根据道路配置向发现者、队伍或所有玩家公开。已经公开的隐藏道路按照普通道路参与后续通行与寻路。

### 8.3 传送道路

传送道路连接地图中距离较远的位置。

角色进入传送入口后，按照入口规则移动至目标地点。传送不处理起点与终点之间的普通地块，但必须处理目标地块的合法停留、首次踏足与到达效果。

### 8.4 特殊地形道路

特殊地形道路包括但不限于：

* 山路。
* 河流航道。
* 地下洞穴。
* 栈桥。
* 缆车。

特殊道路可以配置方向、进入条件、移动消耗、开放状态与目标连接，但不能绕过统一的通行校验。

## 9. 路径与寻路

### 9.1 路径定义

路径由一组连续且合法的地图连接组成。

一条有效路径必须满足：

* 每一步都使用六方向相邻连接或明确配置的特殊连接。
* 每一步都属于当前状态允许使用的六方向或特殊连接。
* 所有目标地块均允许进入。
* 路径没有穿过不可通行障碍。
* 角色满足道路与区域的特殊条件。
* 已知部分的总移动消耗不超过角色当前可用移动力。
* 第一个未踏足地块只能作为本次主动移动的终点。

### 9.2 默认六方向寻路

角色位于普通区域时，自动寻路以所有已知且合法的六方向相邻连接生成候选路线。

寻路可以经过同环、内环和外环地块，但不能使用尚未发现的道路、穿过未知地块继续规划，或绕过地形、障碍、区域与方向限制。

### 9.3 特殊连接寻路

角色拥有可用的道路、传送、地图机关或其他特殊连接时，寻路可以将这些连接加入候选网络。

系统应按照以下顺序比较路线：

1. 路线是否合法。
2. 是否会在首次探索处结束。
3. 路线总移动消耗。
4. 路线经过的地块数量。
5. 已经公开的风险与特殊效果。

最短路线不一定是最优路线。较短路线可能穿过泥泞高地、危险区域或事件地块，而较长路线可能拥有更低消耗与更少风险。

寻路算法可以使用六边形距离作为启发值：

```text
heuristic = max(|Δx|, |Δy|, |Δz|)
```

该启发值只估算不存在障碍时的最低步数。实际路径成本仍由移动连接、地形、`elevation`、障碍与状态共同决定。

### 9.4 路线展示

玩家选择目标后，系统可以显示：

* 预计经过的地块。
* 每一步的移动消耗。
* 路径总消耗与预计剩余移动力。
* 首次探索将在哪个地块结束移动。
* 已经公开的地形、区域、道路与风险。

系统不能通过路线预览泄露战争迷雾中的未知地块、隐藏道路或未发现障碍。

## 10. 移动结算顺序

角色移动必须逐格执行，而不是直接从起点跳转至普通移动的终点。

每进入一个地块，按照以下顺序结算：

```text
声明下一步移动
      │
      ▼
检查目标、连接、通行与移动消耗
      │
      ▼
执行基础移动并扣除移动力
      │
      ▼
更新位置、视野与首次踏足记录
      │
      ▼
结算地形效果
      │
      ▼
结算区域与道路效果
      │
      ▼
结算事件、遭遇与到达效果
      │
      ▼
结算由上述内容产生的强制位移
      │
      ▼
确认最终位置与移动是否继续
```

如果本次进入属于首次探索，应在角色进入后立即将剩余移动力降为 `0`，但当前地块的地形、区域、事件与到达效果仍需完整结算。

如果事件或区域效果产生新的强制位移，应完成该位移及其目标位置结算后，再确定角色的最终位置。强制位移不能通过循环触发无限延长移动流程。

---

## 11. 移动中断与动态寻路

角色移动可能因以下情况提前结束：

* 玩家主动停止。
* 剩余移动力不足。
* 完成一次首次探索。
* 下一地块或道路被动态障碍阻断。
* 触发要求停止的事件、战斗、陷阱或机关。
* 受到无法继续移动的状态。
* 地图裂变改变了后续路线。

移动中断后，角色停留在最后一个完成全部位置结算的合法地块。已经消耗的移动力不会自动返还，除非具体效果明确说明。

地图状态可能在移动过程中发生变化，例如道路被封锁、桥梁损坏、天气改变地形消耗或裂变生成新连接。因此，系统执行每一步前都必须重新确认下一步是否合法。

原路线失效时，系统可以根据当前状态重新计算剩余合法路线，并由玩家确认是否继续。系统不得自动使用玩家尚未发现的道路替换路线。

## 12. 骰子与移动

默认移动规则使用角色当前可用移动力，不要求玩家每回合通过骰子决定移动格数。

为了保留原作中的骰子棋盘元素，事件、区域、装备或可选规则可以要求进行移动骰判定。骰子结果可以：

* 临时增加或降低本次可用移动力。
* 决定特殊道路的出口。
* 决定强制位移的距离。
* 触发骰点对应的地图效果。

骰点只负责生成对应规则需要的结果，不会绕过以下基础限制：

* 六方向相邻与地图边界。
* 道路连接与通行条件。
* 首次探索结束移动。
* 地形与地势消耗。
* 逐格结算与移动中断。

除非具体效果明确声明为传送或强制位移，否则骰子不能使角色直接跳过中间地块。

## 13. 系统职责

移动与寻路系统只负责空间移动，不重复实现其他系统的业务逻辑。

| 系统 | 主要职责 |
| --- | --- |
| 数值系统 | 计算角色最终移动力、移动速度与相关动态修饰。 |
| 地图系统 | 提供坐标、环数、连接、地形、地势和区域信息。 |
| 通行系统 | 判断地块、道路、障碍与特殊条件是否允许通过。 |
| 探索与视野系统 | 更新战争迷雾、可见信息与地图情报。 |
| 移动与寻路系统 | 筛选当前可用连接、计算消耗、生成路线并逐格更新位置。 |
| 事件系统 | 判断移动后是否触发事件并完成事件流程。 |
| 战斗系统 | 处理遭遇战、追击、逃跑与战斗内位移。 |
| 回合系统 | 决定何时进入移动阶段，以及移动结束后进入哪个阶段。 |

## 14. 设计原则

移动与寻路系统遵循以下原则：

六方向自由原则

玩家可以在每一步从六个空间相邻方向中选择合法目标，环数变化本身不需要额外权限。

探索付费原则

首次踏足未知地块会消耗本回合全部剩余移动力，使探索本身成为需要规划的回合投入。

自由不等于免费原则

六方向自由选择不代表免费移动，所有普通移动仍需逐格执行并支付正常消耗。

逐格结算原则

普通移动必须逐格处理位置、视野、地形、区域、事件和中断，不能直接跳至终点。

统一通行原则

普通移动、自动寻路、AI 移动和大部分特殊移动共享相同的地图边界、连接与合法停留规则。

信息一致原则

寻路只能使用玩家已经掌握的地图与道路信息，不能通过系统推荐泄露未知内容。

特殊来源明确原则

方向限制、非相邻连接、传送、强制位移和移动限制都必须说明来源、持续时间、目标与结束条件。

## 15. 设计说明

移动系统的核心目标不是单纯提高玩家的移动效率，而是塑造世界探索的节奏。

玩家可以在已经踏足的区域中自由选择六方向路线，面对未知地块时则需要投入本回合剩余移动力完成探索。城镇、村庄等文明区域继续承担交通枢纽职责，为玩家提供服务设施和特殊连接；事件、装备、能力和特殊道路进一步提供临时捷径与非常规位移。

这种设计使外围、中层与核心区域在整局游戏中都具有路线价值。玩家需要判断向哪个方向探索、是否绕开高消耗或危险地块，以及是否值得为了未知地点提前结束本回合移动。

通过“底层网格统一、六方向自由、探索成本约束、特殊连接扩展”的结构，地图能够保留开放世界逐步揭露的探索感。玩家虽然可以主动向地图中心移动，但仍需逐格支付移动成本，并会在每次首次探索后结束本次移动，因此无法无条件直线冲向创界山。
