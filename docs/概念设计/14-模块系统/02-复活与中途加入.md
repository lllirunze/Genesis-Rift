# 《开天辟地之大地的裂变》复活与中途加入

## 1. 系统定位

《开天辟地之大地的裂变》允许角色死亡，但不应让玩家因为一次死亡而永久退出本局游戏。

复活与中途加入系统主要解决以下问题：

* 为死亡角色提供重新进入游戏的机会。
* 支持游戏开始后其他玩家中途加入。
* 保留原作中“投掷二十面骰，掷出 `6` 才能加入”的经典规则。
* 允许玩家与主持人“上帝”进行具有原作风格的公开互动。
* 使死亡具有明确代价，同时避免玩家长时间无法参与游戏。
* 为濒死、救援、死亡、灵魂状态与重新入场建立统一流程。

本系统将角色重新进入世界的过程统称为“轮回”。死亡角色复活和新玩家中途加入，均使用同一套轮回判定与安全入场规则。

```text
死亡角色                      中途加入者
    │                              │
    ▼                              ▼
灵魂状态与等待                 完成角色创建
    │                              │
    └──────────┬───────────────────┘
               ▼
          轮回判定入口
               │
               ▼
         安全区域重新入场
```

轮回只负责让玩家重新获得可行动角色，不会重置玩家已经取得的永久成长，也不会直接推进使命或改变胜利条件。

## 2. 濒死与死亡

### 2.1 濒死状态

当角色当前生命值降低至 `0` 时，角色不会立即正式死亡，而是进入“濒死”状态。

角色进入濒死状态时：

* 当前生命值固定为 `0`，不能继续降低为负数。
* 角色单位仍然保留在当前地图位置。
* 中断当前正在执行的攻击、移动或其他主动行为。
* 开始记录濒死回合数。
* 向允许参与救援的玩家开放治疗、求救与自救响应。

濒死状态下，角色遵循以下行动限制：

* 自己的回合最多移动 `1` 格。
* 只能进入相邻、已探索、当前可通行且移动消耗不高于 `1` 的地块。
* 不能主动攻击或发动敌对效果。
* 不能制造、鉴定、交易或调整装备。
* 不能主动触发普通地图探索与地图事件。
* 可以使用规则明确允许的求救、治疗或自救手段。
* 其他玩家、NPC、装备或事件可以对其进行救援。

冰冻、束缚等其他移动限制仍然正常生效。濒死状态提供的 `1` 格移动能力只是上限，不会绕过障碍、地形、状态或区域进入条件。

除非技能、事件或规则明确具有“处决”效果，濒死角色再次受到普通伤害不会立即正式死亡，也不会使当前生命值低于 `0`。

### 2.2 濒死回合计数

默认濒死期限为 `3` 个该角色自己的回合。

角色进入濒死状态的当前结算不立即计为一个完整濒死回合。从该角色下一次回合开始计算，并在每次回合结束时增加 `1` 点濒死回合数。

即使角色因濒死或其他状态无法执行正常行动，其对应回合仍会经过开始与结束步骤，并正常增加濒死回合数。

```text
进入濒死状态
      │
      ▼
第 1 个濒死回合结束：1 / 3
      │
      ▼
第 2 个濒死回合结束：2 / 3
      │
      ▼
第 3 个濒死回合结束：3 / 3
      │
      ▼
执行最后救援检查
      │
      ▼
仍未恢复生命值则正式死亡
```

部分身份、转职、装备、天气或事件可以修改濒死期限，但通常不得低于 `2` 回合，也不得高于 `5` 回合。

濒死期限发生变化时，已经累计的濒死回合数保持不变。若新的期限不高于当前累计值，应在当前完整结算结束后执行最后救援检查，而不是在效果尚未结算时立即死亡。

### 2.3 救援成功

濒死角色通过合法治疗恢复至少 `1` 点当前生命值时，立即退出濒死状态。

救援成功后：

* 清除本次濒死回合计数。
* 保留角色当前地图位置。
* 保留未被治疗或救援效果移除的其他状态。
* 不触发正式死亡代价。
* 不进入灵魂状态与轮回流程。

如果同一次结算中同时存在治疗与致死效果，应按照对应战斗、事件或响应顺序完成全部结算，再根据最终当前生命值判断角色是否仍处于濒死状态。

### 2.4 正式死亡

角色达到濒死期限，且最后救援检查结束后仍未恢复生命值时，进入正式死亡状态。

角色正式死亡后：

* 从地图上移除角色单位。
* 从当前战斗的参与者列表中移除。
* 中止该角色尚未完成的个人行动与交互。
* 按照本章第六节结算死亡代价。
* 玩家进入灵魂状态。
* 开始记录本次死亡对应的轮回等待与失败次数。

角色退出战斗不代表整个战斗必然结束。仍有其他合法参与者时，战斗继续；没有任何合法参与者时，由战斗系统按照脱离或失败规则结束战斗。

个人普通任务是否失败，由任务自身的死亡处理规则决定。团队任务、世界任务和其他玩家的任务不会因为该角色死亡而自动结束。

角色的以下核心信息不会因死亡重置：

* 身份与转职。
* 种族与性别标签。
* 隐藏信仰。
* 等级、经验值与基础属性成长。
* 已完成使命、未完成使命及其合法进度。
* 已学习图纸与永久能力。
* 永久契约及其效果。

## 3. 灵魂状态与轮回申请

### 3.1 灵魂状态

灵魂状态表示玩家仍然属于本局游戏，但当前没有能够在地图上行动的角色单位。

灵魂状态下，玩家可以：

* 查看自己的角色信息。
* 查看自己的使命与合法公开信息。
* 查看本次轮回的等待时间、失败次数与保底状态。
* 在轮回结算节点满足条件后申请轮回。
* 参与不影响游戏状态的公开讨论。

灵魂状态下，玩家不能：

* 移动、攻击、交易、制造或使用普通物品。
* 触发地图、NPC、任务或事件交互。
* 使用策略牌干涉其他玩家的结算。
* 操纵中立单位或代替其他玩家行动。
* 查看自己在死亡前尚未获得的隐藏地图信息。

死亡不会暂停使命记录。若某项使命明确允许通过公共世界结果被动推进，系统仍可按照使命自身规则更新进度；灵魂玩家不能主动执行行为推进使命。

### 3.2 轮回结算节点

死亡玩家进入灵魂状态后，仍然保留原有行动顺序中的位置。

当流程推进至该玩家原本应该开始回合的位置时，不创建普通玩家回合，而是创建一次“灵魂回合”。灵魂回合只处理：

1. 轮回等待时间。
2. 轮回申请与保底状态。
3. 允许在灵魂状态下结算的公开持续效果。
4. 灵魂回合结束。

每个灵魂回合最多进行一次免费轮回申请。点卡扩展提供的额外投掷不占用免费申请次数。

尚未进入行动顺序的中途加入者没有原有玩家位置。系统为所有待加入者设置统一的加入结算节点：每当全部在场玩家各完成一次正常或灵魂回合后，按照申请顺序依次处理每名待加入者的一次加入申请。

### 3.3 免费轮回等待

角色正式死亡后，需要先经历默认 `3` 个灵魂回合的等待时间。

进入灵魂状态的当前结算不计入等待时间。每次灵魂回合结束时，等待计数增加 `1`。完成第三个等待回合后，从下一次灵魂回合开始可以进行免费轮回判定。

等待期间，玩家仍可查看轮回信息，但不能提前进行免费轮回投掷。规则明确提供“立即获得一次轮回投掷”的世界事件或可选点卡互动除外。

### 3.4 免费轮回判定

等待结束后，玩家每个灵魂回合可以进行一次免费轮回判定。

轮回判定使用一枚二十面骰：

```text
投掷 D20
    │
    ├── 结果为 6：轮回成功
    │
    └── 其他结果：轮回失败
```

失败不会产生额外资源惩罚。玩家保留灵魂状态，并可以在下一次灵魂回合继续申请。

该规则直接保留原作中“二十面骰投出 `6` 才能加入”的经典设定。数字 `6` 属于轮回系统的固定成功结果，不受幸运值、装备、身份或其他普通概率修正影响。

所有 D20 结果均通过《01-随机系统》的轮回随机流生成并记录。客户端骰子动画只表现服务器已经确认的结果，不能自行决定点数。

### 3.5 轮回保底

单次投出 `6` 的概率较低。为了避免玩家因连续失败而长时间无法参与游戏，系统记录每次轮回期间的连续失败次数，并提供轮回保底。

默认保底规则如下：

| 连续失败次数 | 下一次轮回申请 |
| --- | --- |
| `0–2` 次 | 投掷一枚 D20，只有结果为 `6` 时成功。 |
| 已连续失败 `3` 次 | 下一次投掷两枚 D20，任意一枚为 `6` 即成功。 |
| 已连续失败 `4` 次 | 下一次恢复为一枚 D20，只有结果为 `6` 时成功。 |
| 已连续失败 `5` 次 | 下一次轮回不再投骰，直接成功。 |

一次同时投掷两枚 D20 的强化判定只算一次轮回申请。两枚均未出现 `6` 时，连续失败次数增加 `1`，而不是增加 `2`。

点卡扩展提供的额外 D20 属于一次独立轮回判定。若额外投掷仍然失败，连续失败次数正常增加 `1`；若成功，则立即结束本次轮回的失败记录。

轮回成功后，本次死亡对应的失败次数清零。角色下一次死亡时重新开始计算，不能保留上一次轮回的保底进度。

保底用于减少离场时间，不改变普通轮回申请中“投出 `6` 才能成功”的核心表现。直接保底成功时，上帝可以将结果公开描述为“世界裂缝主动接纳了该灵魂”。

## 4. 点卡与上帝互动

### 4.1 点卡定位

点卡是对《爱情公寓第三季》原作内容的还原和彩蛋，不属于游戏中的正式经济货币。

游戏内交易、制造、鉴定和其他经济行为仍然统一使用元宝。点卡：

* 不进入角色背包。
* 不与元宝互相兑换。
* 不参与玩家之间的交易。
* 不影响角色属性与长期成长。
* 不由游戏系统记录数量或真实价值。

在朋友间实际游玩时，点卡可以被理解为一种玩笑式场外互动，例如请上帝喝一瓶饮料。该行为必须建立在全体玩家开局前同意、自愿且不涉及强制消费的基础上。

### 4.2 点卡效果

点卡扩展启用时，处于灵魂状态的玩家可以向上帝申请一次额外 D20 轮回判定。

推荐默认效果如下：

* 本灵魂回合获得一次额外的 D20 轮回判定。
* 即使本回合已经使用免费轮回申请，仍可进行额外投掷。
* 额外投掷仍然只有结果为 `6` 时成功。
* 每名玩家在每次死亡对应的轮回期间最多使用一次。
* 额外投掷失败时正常计入连续失败次数。

中途加入者也可以在自己的加入结算节点使用同样的额外投掷机会。

点卡不能用于：

* 直接轮回成功。
* 购买游戏胜利。
* 修改、完成或重塑使命。
* 恢复全部资源或取消死亡代价。
* 修改骰子结果或成功数字。
* 干涉其他玩家的行动和随机结果。

### 4.3 上帝的处理权限

上帝负责确认本局是否启用点卡扩展，以及场外互动是否符合开局约定。

点卡互动成立后，上帝只负责公开发起一次额外轮回投掷。骰子结果仍由统一随机系统生成；上帝不能暗中修改点数，也不能因为玩家关系不同而给予不同成功概率。

点卡不需要在游戏代码中建立账户、充值、库存或交易功能。如果本局决定不使用点卡彩蛋，则直接关闭对应场外扩展，不影响免费轮回、保底与中途加入流程。

## 5. 轮回后的角色处理

### 5.1 重新进入位置

轮回成功后，角色不会直接在原死亡位置复活，而是在安全区域重新进入世界。

系统按照以下优先级筛选出生位置：

1. 位于第 `8` 至第 `10` 环内的城镇、村落、营地等有人烟区域。
2. 与当前在场玩家距离适中，不会立即脱离主要游戏范围。
3. 当前没有敌对单位占据或正在进行战斗。
4. 不处于极端天气核心区、首领战场、灾难中心或地图边界外。
5. 地块与所在区域允许角色正常进入。

如果存在多个同优先级位置，地图系统先提供合法候选集合，再由轮回随机流选择一个位置。

如果没有完全满足条件的位置，系统按照优先级逐项放宽非安全性条件，并选择距离最近的合理格子。仍然无法确定时，由上帝公开选择一个合法位置并说明原因，不能将角色放入已知必死或不可行动的地块。

这种处理使轮回表现为“重新降临”，而不是简单原地起身，也可以避免角色刚刚返回便立即再次死亡。

### 5.2 状态恢复

轮回成功后，死亡角色按照以下默认状态返回：

| 项目 | 默认处理 |
| --- | --- |
| 当前生命值 | 恢复至最大生命值的 `50%`。 |
| 当前灵力或其他身份资源 | 恢复至对应最大值的 `30%`。 |
| 普通临时增益与减益 | 清除。 |
| 死亡后持续状态 | 按状态标签保留。 |
| 身份、转职、等级与信仰 | 保留。 |
| 使命及其合法进度 | 保留。 |
| 永久契约与永久效果 | 保留。 |
| 已学习图纸与永久能力 | 保留。 |
| 轮回保护 | 获得 `1` 个自身回合。 |

百分比恢复按照《06-数值系统/06-整数与边界规则》完成整数处理。恢复后的当前生命值至少为 `1`，且不能超过最大生命值；其他资源可以恢复为 `0`，但不能超过自身上限。

普通临时效果默认清除，但明确标记为“死亡后持续”“契约效果”或“轮回后结算”的状态不会被移除。这样可以避免玩家通过故意死亡稳定清除必须承担的长期代价。

### 5.3 轮回保护

轮回保护从角色重新进入地图时开始，持续至该角色下一次正常回合结束。

保护期间：

* 角色不能主动发起攻击、偷窃或其他敌对效果。
* 其他玩家与敌对 NPC 不能主动将其选为攻击或敌对效果目标。
* 角色可以移动、接受治疗、整理允许调整的资源并进行非敌对交互。
* 公开世界效果、地形效果与不指定目标的环境结算仍然可以影响角色。

角色主动声明攻击、偷窃或其他敌对行为时，轮回保护在该行为结算前立即结束，随后正常判断目标与效果是否合法。

轮回保护不能叠加或延长。角色在保护期间再次获得同名效果时，持续时间保持不变。

### 5.4 入场时机

轮回成功后，应先完成当前轮回判定与出生处理，再将角色加入地图。

角色不会因为轮回成功立即获得一个额外完整回合。其下一次正常行动按照原行动顺序进行；中途加入者被加入行动顺序末位，并从下一轮公开行动开始获得正常回合。

## 6. 死亡代价

轮回不能完全消除死亡带来的损失，否则玩家可能利用死亡快速移动、清除负面状态或规避任务代价。

角色正式死亡时，默认承担以下代价：

| 项目 | 处理规则 |
| --- | --- |
| 元宝 | 损失当前持有元宝的 `20%`。 |
| 已穿戴装备 | 保留。 |
| 背包道具 | 从符合条件的普通消耗品中随机损失 `1` 件。 |
| 普通进行中任务 | 按任务自身死亡规则失败、中止或保留。 |
| 使命 | 内容、完成状态与合法进度保留。 |
| 等级与经验 | 全部保留。 |
| 图纸与永久能力 | 全部保留。 |
| 身份、转职与种族 | 全部保留。 |
| 隐藏信仰 | 保留并继续隐藏。 |
| 永久契约 | 全部保留。 |
| 普通临时效果 | 通常清除。 |
| 死亡后持续效果 | 按状态规则保留。 |

元宝损失按照数值系统的整数规则向下取整，最低为 `0`，不能使玩家元宝变为负数。

随机损失普通消耗品时，只能从死亡规则明确允许损失的物品中建立候选池，并通过掉落或轮回随机服务选择。背包中没有合法候选物品时，本项损失跳过，不能改为随机摧毁装备、图纸、任务物品或其他核心资源。

候选物品的持有关系、物品类型与实际移除操作由背包与物品系统负责。复活系统只声明本次死亡需要损失的物品范围，不直接修改背包数据。

### 6.1 遗物处理

损失的元宝与普通消耗品可以根据死亡场景生成“遗物”并留在原位置，也可以由系统直接回收。

具体方式由死亡来源、战斗规则和地图事件共同决定，并在死亡结算前明确：

* 生成遗物时，应记录归属、内容、可拾取时间与消失条件。
* 系统回收时，其他玩家不能再次获得对应资源。
* 同一份资源不能同时生成遗物并被系统回收。
* 死亡角色轮回后不自动重新获得已经损失的资源。

### 6.2 代价结算顺序

正式死亡按照以下顺序处理：

```text
确认正式死亡
      │
      ▼
锁定死亡前角色与背包状态
      │
      ▼
计算元宝与普通消耗品损失
      │
      ▼
处理任务、战斗与地图遗物
      │
      ▼
清除或保留对应状态
      │
      ▼
从地图移除角色单位
      │
      ▼
进入灵魂状态
```

死亡代价应遵循“造成损失但不摧毁长期成长”的原则。默认不随机掉落核心装备，不降低等级，不清空经验，也不重置使命、信仰或永久契约。

## 7. 中途加入

游戏开始后新加入的玩家，也通过轮回系统进入世界。

### 7.1 加入准备

新玩家申请加入时，按照以下流程完成准备：

1. 由上帝或角色创建系统建立玩家席位。
2. 完成种族、基础身份与性别标签选择。
3. 生成隐藏信仰。
4. 按照当前世界状态生成五个隐藏使命。
5. 建立该玩家的轮回随机子流与加入失败计数。
6. 等待下一次统一加入结算节点。

中途加入角色使用正常初始角色配置，不继承其他死亡角色的等级、物品、任务、使命、地图信息或随机流状态。

新玩家可以获得当前所有玩家都能查看的公开世界信息，但其个人探索记录从初始状态开始。

### 7.2 加入判定

中途加入者不需要经历濒死、正式死亡和 `3` 个灵魂回合的等待时间。

在加入结算节点，玩家进行一次 D20 轮回判定：

* 结果为 `6` 时加入成功。
* 其他结果均为失败。
* 失败后保留待加入状态，在下一次加入结算节点重新申请。
* 中途加入同样适用连续失败保底。
* 点卡扩展启用时，同样可以申请一次额外 D20 投掷。

加入失败不会重新创建角色，也不会重新生成信仰或使命。已经生成的角色信息保持不变，直至成功加入或玩家主动取消加入申请。

### 7.3 加入成功

中途加入成功后，角色按照正常初始角色状态进入游戏，不使用死亡角色的部分恢复比例，也不承担死亡代价。

其入场位置使用本章安全区域筛选规则，并获得 `1` 个自身回合的轮回保护。

中途加入者被加入当前行动顺序末位，从下一轮公开行动开始获得正常回合，不能在加入成功的当前结算中立即执行主要行动。

## 8. 上帝特殊干预

上帝可以通过公开的世界事件临时改变轮回规则，但不能私下调整某个玩家的随机结果。

例如：

| 世界事件 | 轮回效果 |
| --- | --- |
| 世界裂缝扩大 | 所有灵魂玩家立即获得一次额外轮回投掷。 |
| 六道共鸣 | 本次事件持续期间，D20 掷出 `6` 或 `16` 均可成功。 |
| 灵魂潮汐 | 本次事件持续期间，普通轮回判定同时投掷两枚 D20。 |
| 创界山召唤 | 当前连续失败次数最多的灵魂玩家直接轮回。 |
| 裂变封锁 | 本次事件持续期间，所有轮回与加入申请暂停。 |

任何轮回规则变化都必须：

* 通过公开事件或公开模式规则生效。
* 向所有玩家说明作用对象、开始时机与持续时间。
* 对满足相同条件的玩家使用相同规则。
* 通过统一随机系统执行仍然需要随机的判定。
* 在事件结束后恢复默认轮回规则。

“裂变封锁”等暂停效果只暂停投掷与直接轮回申请，不会重置已经累计的等待时间或连续失败次数。事件是否允许等待计数继续增加，必须在事件效果中明确；未说明时默认继续增加。

上帝的职责是维护游戏节奏、公开规则并执行已经确定的结果，而不是随意决定谁能够复活或加入。

## 9. 推荐默认流程

### 9.1 死亡与轮回

角色的完整死亡与轮回流程如下：

```text
当前生命值降至 0
        │
        ▼
进入濒死状态
        │
        ▼
等待其他玩家救援
        │
        ▼
3 个濒死回合后仍未恢复生命值
        │
        ▼
角色正式死亡并结算死亡代价
        │
        ▼
进入灵魂状态
        │
        ▼
等待 3 个灵魂回合
        │
        ▼
每个灵魂回合进行一次 D20 判定
        │
        ▼
投出 6 或触发轮回保底
        │
        ▼
在安全区域重新进入世界
        │
        ▼
恢复部分生命值与身份资源
        │
        ▼
获得 1 个自身回合的轮回保护
```

### 9.2 中途加入

新玩家中途加入时，直接从角色创建与 D20 判定阶段开始：

```text
提交中途加入申请
        │
        ▼
完成角色、信仰与使命生成
        │
        ▼
等待统一加入结算节点
        │
        ▼
投掷 D20
        │
        ├── 结果为 6：加入成功
        │
        └── 其他结果：等待下一次申请
        │
        ▼
触发保底或成功投出 6
        │
        ▼
以正常初始配置进入安全区域
```

中途加入者不经历濒死、死亡、死亡代价与免费轮回等待，但使用相同的 D20、失败保底、安全出生和轮回保护规则。

## 10. 设计原则

复活与中途加入系统遵循以下原则：

原作还原原则

轮回以“D20 投出 `6`”作为核心随机规则，保留原作最具辨识度的加入方式。

有限死亡原则

死亡必须产生等待、资源损失与路线中断，但不能摧毁角色已经取得的长期成长。

参与保护原则

玩家不应因为连续随机失败而长时间退出游戏，轮回保底必须为所有玩家提供明确上限。

统一入口原则

死亡角色复活与新玩家中途加入共用轮回判定、安全出生和保护规则，减少重复机制。

场外点卡原则

点卡只作为开局共同同意的可选彩蛋，不进入正式经济、角色背包或充值系统。

公开干预原则

上帝可以通过公开世界事件调节轮回节奏，但不能私下修改骰子或针对个别玩家改变概率。

长期成长保护原则

死亡不降低等级，不重置信仰、使命、永久契约、图纸和核心装备。

反利用原则

玩家不能通过故意死亡稳定获得传送、资源刷新、使命调整或负面状态清除收益。死亡后持续状态、资源损失与安全出生规则应共同限制此类行为。

随机统一原则

所有 D20、随机物品损失与随机出生选择均通过统一随机系统执行，并支持日志、存档与回放。

通过濒死救援、有限死亡代价、D20 轮回与失败保底，本系统能够在尊重原作规则的同时减少玩家长时间离场，使死亡保持威胁，也让朋友中途加入时拥有清晰、公平且富有仪式感的入口。
