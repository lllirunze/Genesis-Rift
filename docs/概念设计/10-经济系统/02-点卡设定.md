# 《开天辟地之大地的裂变》点卡设定

## 1. 设定来源

点卡（Point Card）来源于《爱情公寓第三季》中《开天辟地之大地的裂变》的原作设定。

剧中，玩家可以通过支付点卡向“上帝”申请部分特殊权限，例如中途加入已经开始的游戏、使用特殊骰子加快复活流程等。这些内容具有浓厚的桌游娱乐氛围，也是原作中较有辨识度的一项设定。

为了尊重原作，本项目保留点卡这一名称与概念，但仅将其作为原作彩蛋和场外可选规则进行记录。

点卡不属于游戏核心机制，也不需要在游戏代码层级进行实现。

---

## 2. 游戏中的定位

点卡不属于游戏世界中的货币，也不参与正常经济系统。

玩家之间的交易、商店购买、装备制造、图纸鉴定及其他经济行为均使用元宝完成。点卡不会与元宝互相兑换，也不会影响角色属性、角色成长、资源获取或游戏内经济平衡。

默认规则下，玩家无需持有或使用点卡，即可完整体验全部游戏内容。系统不会记录点卡数量，也不会提供点卡获取、消耗、交易、商店或结算功能。

点卡与元宝的职责区别如下：

| 项目 | 元宝 | 点卡 |
| --- | --- | --- |
| 定位 | 游戏内唯一通用货币 | 场外可选彩蛋 |
| 是否属于核心规则 | 是 | 否 |
| 是否由游戏系统记录 | 是 | 否 |
| 是否参与经济结算 | 是 | 否 |
| 是否影响角色成长 | 间接参与成长循环 | 不参与 |
| 是否默认启用 | 是 | 否 |

---

## 3. 可选规则

若玩家希望更加贴近《爱情公寓第三季》中的桌游氛围，可在开局前由全体玩家共同决定是否启用点卡规则。

启用后，点卡可用于向本局主持人“上帝”申请少量特殊规则，例如：

* 中途加入已经开始的游戏。
* 使用特殊骰子加快复活流程。
* 申请部分娱乐性的临时规则。

上述内容均属于玩家之间的场外互动，不属于游戏核心机制。其具体形式、使用次数与接受范围，可以由本局玩家根据实际情况共同约定。

任何点卡规则均应满足以下条件：

* 必须在开局前获得全体玩家同意。
* 不得直接改变胜负结果。
* 不得提供永久属性、装备、元宝或其他成长资源。
* 不得剥夺其他玩家的正常行动权与游戏体验。
* 产生争议时，应立即取消对应规则并恢复默认流程。

未启用点卡规则时，任何玩家均不能在游戏过程中临时要求使用点卡获得特殊权限。

---

## 4. 设计说明

点卡的存在主要用于保留《爱情公寓第三季》中的经典设定，增强游戏的还原度与聚会娱乐性。

在现实桌游中，点卡更适合作为朋友聚会时的趣味互动。例如，经全体玩家同意后，请主持人“上帝”喝一瓶饮料或买一杯奶茶，可以象征性地申请一项不影响公平性的娱乐规则。

此类互动必须建立在自愿、轻松且无压力的前提下，不构成真实充值、强制消费或商业交易，也不能因参与者是否付费而影响其正常游戏权利。

因此，点卡属于可选的场外扩展内容，而非游戏默认规则。项目仅保留其概念与使用边界，不为其设计程序功能、数值配置或游戏内资源接口，以保证游戏整体的公平性与完整性。
