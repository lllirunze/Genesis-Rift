# 《开天辟地之大地的裂变》昼夜与气候系统

## 1. 系统定位

昼夜与气候系统用于表现《开天辟地之大地的裂变》中世界环境随时间发生的变化，并为探索、移动、战斗、资源收集、NPC 交互和特殊事件提供环境条件。

本系统由三个相互独立但可以叠加的部分组成：

| 环境层 | 主要职责 | 变化方式 |
| --- | --- | --- |
| 昼夜 | 提供稳定、公开且可预测的时间节奏。 | 每 `5` 个完整轮次固定切换。 |
| 天气 | 提供短期环境描述、条件标签和少量规则变化。 | 每 `2` 个完整轮次抽取天气牌。 |
| 气候灾害 | 提供具有预警、灾害和灾后阶段的长期环境挑战。 | 由大小王或公开世界事件触发。 |

昼夜不会因普通天气改变，天气也不会打乱正常昼夜顺序。玩家可以根据昼夜进行长期规划，并根据天气与气候灾害临时调整行动。

本系统遵循以下设计原则：

* 昼夜变化稳定、公开且可以预测。
* 大部分天气只提供环境描述与条件标签，不直接修改数值。
* 少量极端天气只产生有限、明确且短暂的规则影响。
* `A` 牌用于触发具有独立机制的特殊天气。
* 大小王用于触发持续时间较长的重大气候灾害。
* 天气与灾害应提供新的行动选择，而不是只惩罚玩家。
* 所有重大灾害都必须提供合理预警和至少一种规避手段。
* 所有牌组抽取、随机区域与随机目标均由统一随机系统处理。

本系统只负责管理时间状态、天气状态、气候灾害阶段及其标准环境效果，不负责替代地图、战斗、事件、NPC 或任务系统执行具体业务结果。

## 2. 昼夜系统

### 2.1 完整轮次

昼夜与天气使用“完整轮次”作为统一时间单位。

一个完整轮次是指当前所有在场玩家分别完成一次正常玩家回合或灵魂回合，并完成本轮区域与世界结算。

中途加入者在轮次进行中成功进入游戏时，从下一轮开始计入完整轮次的玩家集合，不会延长当前正在结算的轮次。

### 2.2 昼夜交替规则

每个昼夜阶段持续 `5` 个完整轮次：

```text
第 1–5 轮：白天
第 6–10 轮：黑夜
第 11–15 轮：白天
第 16–20 轮：黑夜
……
```

昼夜只在完整轮次边界切换，不会在某名玩家的个人回合、战斗、事件或响应链中途改变。

当前昼夜可以根据轮次编号确定：

```text
昼夜阶段编号 = 向下取整((当前轮次 - 1) ÷ 5)

阶段编号为偶数：白天
阶段编号为奇数：黑夜
```

普通天气、特殊天气和重大气候灾害原则上都不会暂停、重置或改变昼夜计数。只有明确标注为独立模式规则的效果，才可以临时改变昼夜表现；即使表现改变，基础昼夜计数仍然继续推进。

### 2.3 白天

白天是较为稳定的活动阶段，适合探索、交易、制造和普通 NPC 交互。

白天可以作为以下内容的条件标签：

* 普通商店、铁匠铺和鉴定处正常开放。
* 部分日间 NPC 出现。
* 部分任务、装备或道具只能在白天使用。
* 部分夜行怪物减少或停止出现。
* 与阳光、温度和视野相关的能力可以生效。

白天本身原则上不直接增加攻击、防御、移动或其他角色数值。具体效果由地点、身份、装备、任务或事件读取“白天”标签后自行决定。

### 2.4 黑夜

黑夜是信息受限但特殊内容更加丰富的活动阶段。

黑夜可以作为以下内容的条件标签：

* 普通 NPC 减少，夜间 NPC 或神秘 NPC 出现。
* 酒馆、黑市和部分特殊地点开放。
* 夜行怪物或特殊敌人更容易出现。
* 潜行、伏击和夜间能力可以生效。
* 部分任务只能在黑夜推进。
* 回合结构进入黑夜与秘密行动阶段。

黑夜不固定降低所有角色的攻击、移动或防御能力。对普通角色而言，黑夜主要改变可见内容、NPC 分布、秘密行动和事件条件，而不是形成全面数值惩罚。

默认黑夜视野规则如下：

```text
无有效照明时：最终视野 -1
最低视野：1 格
```

城镇灯光、火把、提灯、篝火、照明能力和特殊装备可以抵消该影响。黑夜、天气与其他视野修正可以叠加，但最终结果仍须遵循数值系统的整数与边界规则。

### 2.5 昼夜公开信息

所有玩家均可查看：

* 当前处于白天或黑夜。
* 当前昼夜阶段已经持续的轮数。
* 距离下一次昼夜切换的剩余轮数。
* 当前昼夜提供的公开标签。
* 因昼夜开放或关闭的公共系统与地点。

系统不能在玩家完成行动后，才补充公布本轮昼夜状态。

## 3. 天气抽取规则

### 3.1 独立天气牌组

天气系统使用一副独立的 `54` 张天气扑克牌，包括四种花色的 `A–K` 与大小王。

天气牌组不属于玩家手牌牌库、普通扑克牌小游戏牌组或世界事件牌组。天气抽取不会改变任何玩家的手牌和牌序。

游戏开始时，服务器通过天气随机流对天气牌组进行一次确定性洗牌。牌组抽完前不会重新洗牌；牌组耗尽后，将天气弃牌堆重新洗牌并形成新的天气牌组。

存档与回放必须记录天气牌组版本、剩余顺序、弃牌内容和当前天气状态。

### 3.2 抽取周期

游戏每经过 `2` 个完整轮次抽取一次天气牌。

默认在以下轮次开始时抽取：

```text
第 1 轮、第 3 轮、第 5 轮、第 7 轮、第 9 轮……
```

普通天气与极端天气默认持续当前抽取轮和下一轮，共 `2` 个完整轮次，并在下一次天气抽取前结束。

例如：

```text
第 5 轮开始：抽到小雨，当前为白天
第 6 轮开始：进入黑夜，小雨继续存在
第 7 轮开始：小雨结束，抽取新的天气
```

第 `6` 轮的完整世界环境为“黑夜 + 小雨”，即“雨夜”。

### 3.3 天气公开

所有天气牌抽取后立即公开。

界面至少显示：

* 当前天气名称与牌面。
* 天气类别与公开标签。
* 天气剩余轮数。
* 是否存在数值或规则影响。
* 受影响的区域与目标。
* 可用的规避、抵消或利用方式。
* 当前是否存在可共存天气。

重大气候灾害还应显示预警阶段、灾害阶段、灾后阶段与安全地点信息。

天气效果不能仅隐藏在描述文本中。任何影响玩家决策的规则都必须在玩家行动前明确展示。

### 3.4 天气覆盖与共存

正常情况下，新抽取的天气直接覆盖旧的普通、极端或特殊天气：

```text
旧天气结束
    │
    ▼
新天气公开并生效
    │
    ▼
默认持续 2 轮
```

只有明确标注为“可共存”的局部天气、追踪天气或事件天气，才可以与当前全域天气同时存在。

同一作用范围内存在多个天气时，按照以下顺序处理：

1. 重大气候灾害规则。
2. 区域或目标专属天气规则。
3. 当前全域天气规则。
4. 昼夜规则。
5. 装备、状态与地点提供的抵消规则。
6. 数值系统边界限制。

同名效果默认不重复叠加，不同来源的不同效果可以叠加。天气配置必须明确其效果是叠加、覆盖还是互斥。

抽到大小王时，当前普通天气立即结束，并进入重大气候灾害流程。

### 3.5 事件改变天气

公开世界事件可以生成、延长、缩短或替换天气，但必须通过昼夜与气候系统创建标准天气状态。

事件生成的天气可以拥有不同于牌面天气的持续时间与作用范围。例如，事件系统生成的区域暴风雪可以持续 `3` 轮，而天气牌抽取产生的普通暴风雪默认持续 `2` 轮。

强制天气不会倒退天气牌组。事件结束后，系统按照效果说明恢复被覆盖天气，或等待下一次正常天气抽取。

## 4. 天气等级

天气按照影响程度分为四个等级：

| 天气等级 | 主要来源 | 默认持续时间 | 数值影响 |
| --- | --- | --- | --- |
| 常态天气 | 大部分数字牌及部分人头牌 | `2` 轮 | 通常无直接影响。 |
| 极端天气 | 部分高点数牌及人头牌 | `2` 轮 | 只产生有限影响。 |
| 特殊天气 | 四张 `A` | `2` 轮 | 使用独立机制。 |
| 重大气候灾害 | 大小王 | `5–10` 轮 | 分阶段产生显著影响。 |

花色与点数用于组织天气内容，但最终等级由天气配置决定，不能只根据牌面大小临时推断。

### 4.1 常态天气

常态天气构成天气牌组的大多数。

其主要作用包括：

* 提供场景氛围。
* 作为任务、技能、装备和道具的条件标签。
* 作为后续事件的前置天气。
* 提高世界环境的变化感。
* 让天气牌组保留足够的安全结果。

常态天气默认不直接修改：

* 生命值。
* 攻击与防御。
* 移动力与移动速度。
* 命中与暴击。
* 商店价格。
* 资源产量。
* 装备耐久。

常态天气可以包括：

* 晴朗。
* 多云。
* 阴天。
* 微风。
* 暖阳。
* 晚霞。
* 毛毛雨。
* 小雨。
* 薄雾。
* 凉爽。
* 轻霜。
* 远雷。
* 星空。
* 月色朦胧。

其他系统可以读取常态天气标签，例如：

```text
任务：收集雨水
条件：当前天气包含“降水”标签

能力：夜观星象
条件：当前为黑夜，且天气不包含“降水”或“浓雾”标签

道具：晾衣架
条件：当前天气包含“晴朗”或“微风”标签
```

### 4.2 极端天气

极端天气是少量会直接影响规则的短期天气，默认持续 `2` 轮。

每种极端天气通常只影响一至两个系统，避免产生过多结算内容。

| 天气 | 建议效果方向 |
| --- | --- |
| 酷热 | 户外连续行动可能积累炎热状态。 |
| 大雨 | 泥泞地形移动消耗增加 `1` 点。 |
| 暴雨 | 泥泞移动消耗增加，普通远程攻击受到轻度影响。 |
| 冰雹 | 无掩体区域的角色在轮末进行轻度后果判定。 |
| 浓雾 | 视野减少 `1` 格，最低为 `1` 格。 |
| 沙尘暴 | 视野减少，普通远程攻击距离受到限制。 |
| 寒潮 | 未处于建筑或火源附近的角色积累寒冷状态。 |
| 暴风雪 | 普通地形移动消耗增加，高地通行更加困难。 |
| 雷暴 | 部分户外金属设备或特殊装置暂时受限。 |
| 台风前兆 | 轻度影响移动，并可以作为台风灾害的剧情前置。 |

极端天气不应直接造成无法规避的高额伤害。真正具有长期生存压力的环境变化由重大气候灾害负责。

### 4.3 特殊天气

四张 `A` 触发特殊天气。

特殊天气不依靠简单提高数值表现强度，而是创建新的条件组合、重投机会、昼夜差异或跟随目标等独立机制。

特殊天气默认持续 `2` 轮，具体规则由本章第八节定义。

### 4.4 重大气候灾害

大小王触发重大气候灾害。

重大气候灾害持续 `5–10` 轮，并使用预警、灾害与灾后三个阶段。灾害期间暂停普通天气牌抽取，但昼夜仍按照固定规则推进。

重大灾害的目标不是让玩家停止游戏，而是暂时改变路线、资源价值和行动重点。

## 5. 扑克牌花色

天气牌花色用于表示天气的主要类型，不直接表示危险程度。

| 花色 | 天气类型 | 常见内容 |
| --- | --- | --- |
| `♥` 红桃 | 温暖与晴朗 | 晴天、暖风、晚霞、彩虹、酷热。 |
| `♦` 方块 | 云层与降水 | 多云、阴天、小雨、暴雨、冰雹。 |
| `♣` 梅花 | 环境与能见度 | 薄雾、浓雾、寒潮、浮尘、沙尘。 |
| `♠` 黑桃 | 风暴与危险气象 | 强风、雷暴、暴雪、台风前兆。 |

花色只决定天气主题，不自动决定数值效果。

例如，黑桃低点数可以只是“远雷”或“阵风”，不产生负面数值；红桃高点数也可能形成“酷热”或“干旱”等极端天气。

天气牌中的黑桃不再决定当前昼夜。无论抽到何种花色，昼夜始终按照每 `5` 轮固定交替。

## 6. 点数分布

### 6.1 数字牌 `2–7`

数字牌 `2–7` 主要对应常态天气，通常只提供环境描述与标签。

| 牌面 | 天气 | 牌面 | 天气 |
| --- | --- | --- | --- |
| `♥2` | 微风 | `♦2` | 多云 |
| `♥3` | 晴朗 | `♦3` | 阴天 |
| `♥4` | 暖阳 | `♦4` | 毛毛雨 |
| `♥5` | 晚霞 | `♦5` | 小雨 |
| `♥6` | 彩虹 | `♦6` | 阵雨 |
| `♥7` | 干燥 | `♦7` | 连阴 |
| `♣2` | 薄雾 | `♠2` | 远雷 |
| `♣3` | 凉爽 | `♠3` | 阵风 |
| `♣4` | 闷热 | `♠4` | 乌云压境 |
| `♣5` | 露水 | `♠5` | 强风 |
| `♣6` | 轻霜 | `♠6` | 雷阵雨 |
| `♣7` | 浮尘 | `♠7` | 寒风 |

具体牌面与天气名称由天气配置表维护，可以在不改变抽取机制的情况下进行调整。

### 6.2 数字牌 `8–10`

数字牌 `8–10` 主要对应短期极端天气或轻度条件天气。

| 牌面 | 天气 | 效果方向 |
| --- | --- | --- |
| `♥8` | 酷热 | 炎热状态积累。 |
| `♥9` | 烈日 | 无遮蔽区域受到轻度影响。 |
| `♥10` | 干旱 | 水类资源暂时停止刷新。 |
| `♦8` | 大雨 | 泥泞地形移动消耗增加。 |
| `♦9` | 暴雨 | 移动与普通远程攻击受到轻度影响。 |
| `♦10` | 冰雹 | 无掩体区域进行轻度后果判定。 |
| `♣8` | 浓雾 | 视野减少。 |
| `♣9` | 沙尘暴 | 视野与普通远程距离受到影响。 |
| `♣10` | 寒潮 | 户外角色积累寒冷状态。 |
| `♠8` | 强雷暴 | 部分户外设备受限。 |
| `♠9` | 暴风雪 | 移动消耗提高。 |
| `♠10` | 台风前兆 | 提供灾害预警并轻度影响移动。 |

上述内容属于初始映射示例。为了满足大部分天气无数值影响的牌组比例，可以将其中部分牌面调整为只提供条件标签的轻度天气。

### 6.3 点数与强度边界

点数可以用于组织内容，但不能直接代替天气效果配置。

同一点数在不同花色中可以产生不同形式的天气；高点数也不代表必须造成伤害。所有数值、标签、作用范围与规避方式均以具体天气配置为准。

## 7. 人头牌

`J`、`Q`、`K` 用于表示天气的作用形式，而不是简单提高天气强度。

人头牌可以是无数值常态天气、轻度条件天气或极端天气。是否产生数值影响，由具体牌面配置决定。

### 7.1 `J`：局部天气

`J` 表示只发生在部分地图区域的天气。

例如：

```text
♦J：局部暴雨

随机选择一个合法连续区域。
该区域未来 2 轮视为暴雨天气。
其他区域仅视为阴天。
```

局部天气可以根据配置使用以下区域选择策略：

* 随机象限。
* 随机区域类型。
* 随机城镇周边。
* 随机高地或低地。
* 当前玩家较为集中的合法区域。
* 桌游模式中由上帝公开指定的合理区域。

随机区域必须从地图系统提供的合法候选集合中选择，不能覆盖不存在的区域或使所有关键道路同时失效。

### 7.2 `Q`：复合天气

`Q` 表示两种天气特征同时存在的异常天气。

例如：

```text
♣Q：冻雾

同时具有“浓雾”和“寒冷”标签。
视野减少 1 格。
连续在户外停留的角色可能积累寒冷状态。
```

其他示例包括：

* `♥Q`：海市蜃楼。
* `♦Q`：太阳雨。
* `♠Q`：雷雪。

复合天气应突出条件组合，不应简单叠加两个天气的全部惩罚。原则上只保留一项核心数值影响，其余内容使用标签和事件条件体现。

### 7.3 `K`：全域天气

`K` 表示覆盖全部户外区域的天气。

例如：

```text
♠K：全域雷暴

所有户外区域受到雷暴影响。
建筑、洞穴和地下区域可以规避。
持续 2 轮。
```

`K` 牌可以影响全图，但仍然必须提供明确的安全地点、装备抵消或行动选择，不能让全部玩家只能跳过回合。

---

## 8. `A` 牌特殊天气

`A` 牌不固定解释为“反转”，而是用于触发无法通过普通强度表示的异常天象。

每张 `A` 拥有独立规则，默认持续 `2` 轮。

### 8.1 `♥A`：天降祥云

天空出现异常祥云，世界进入短暂的幸运气候。

建议效果：

* 持续 `2` 轮。
* 每名玩家在天气持续期间第一次进行符合条件的个人随机判定时，可以选择重投一次。
* 重投会推进对应业务随机流，重投后的结果必须接受。
* 未使用的重投机会在天气结束时失效。

可以重投的内容必须由业务规则标记为“允许天气重投”。世界事件、天气抽取、地图生成、牌组洗牌、其他玩家的判定和已经完成结算的结果不能重投。

该效果不直接增加幸运值，也不修改任何基础或派生属性。

天气公告示例：

```text
特殊天气：天降祥云
上帝确认天空中出现了祥云。
是否真的会有好事发生，上帝暂不保证。
```

### 8.2 `♦A`：太阳雨

太阳雨同时具有晴朗和降水特征。

建议效果：

* 持续 `2` 轮。
* 同时视为“晴朗”和“降水”天气。
* 普通降雨产生的数值惩罚不生效。
* 依赖晴天或雨天的任务、道具和能力均可触发。

太阳雨的核心价值是创造特殊条件组合，而不是惩罚玩家。

### 8.3 `♣A`：昼夜温差

昼夜温差不会改变当前昼夜状态，只根据当前时间提供不同天气标签。

建议效果：

* 持续 `2` 轮。
* 当前为白天时，天气视为异常酷热。
* 当前为黑夜时，天气视为异常寒冷。
* 昼夜在天气持续期间切换时，天气效果同步切换。

该天气可以影响状态积累、消耗品使用与特定任务，但不直接造成高额生命损失。

### 8.4 `♠A`：雷云追踪

天气生效时，从当前拥有地图角色单位的玩家中随机选择一名角色作为雷云目标。

建议效果：

* 持续 `2` 轮。
* 雷云跟随目标角色所在区域移动。
* 目标每轮结束时仍处于户外，其所在格或相邻格进行一次轻度雷击判定。
* 进入建筑、洞穴、地下区域或其他安全地点可以规避判定。

灵魂玩家与尚未成功进入游戏的中途加入者不进入目标候选集合。没有合法目标时，天气保留“雷暴”标签，但不创建追踪目标。

天气公告示例：

```text
特殊天气：雷云追踪
上帝随机选择了一名玩家。
声明：这不是私人恩怨。
```

---

## 9. 大小王重大气候灾害

大小王不遵循普通天气持续 `2` 轮的规则，而是触发持续 `5–10` 轮的重大气候灾害。

重大气候灾害将暂时覆盖普通天气系统。

灾害期间：

1. 当前普通、极端或特殊天气立即结束。
2. 普通天气牌抽取暂停。
3. 昼夜继续按照每 `5` 轮正常交替。
4. 灾害按照预警、灾害与灾后阶段结算。
5. 灾害结束后的下一轮开始时，立即恢复一项非大小王天气。
6. 后续天气抽取重新回到奇数轮的正常周期。

灾害结束后的恢复抽取不会触发另一张大小王。如果天气牌组中下一张牌仍是大小王，系统从剩余非大小王牌中确定恢复天气，并保留该大小王在后续正常抽取中的出现机会。

重大灾害通常分为三个阶段：

```text
预警阶段
    │
    ▼
灾害阶段
    │
    ▼
灾后阶段
```

### 9.1 灾害预警

重大灾害必须给予玩家明确反应时间。

统一建议如下：

* 小王灾害至少提前 `1` 轮预警。
* 大王灾害至少提前 `2` 轮预警。
* 预警期间不产生严重伤害。
* 所有玩家可以调整路线、购买物资或寻找避难点。
* 灾害路径、主要影响区域和避难方式必须公开。

### 9.2 避难地点

玩家可以通过进入安全地点规避或减轻灾害。

安全地点包括但不限于：

* 城镇。
* 村落。
* 旅店。
* 坚固建筑。
* 洞穴。
* 地下设施。
* 地牢入口。
* 驿站。
* 特殊营地。
* 具有防灾能力的特殊地点。

部分灾害拥有专属避难条件。例如，洪水更适合前往高地，极寒更适合前往建筑或火源附近。

安全地点由地图系统根据地点、地形和当前状态进行判断，天气系统不能仅根据地点名称直接认定安全。

### 9.3 野外自救

无法及时到达避难地点的玩家，可以消耗资源或使用能力减轻灾害影响。

可用内容包括：

* 帐篷。
* 绳索。
* 食物。
* 药剂。
* 保暖装备。
* 防水装备。
* 护盾。
* 传送卷轴。
* 特殊载具。

灾害不应使远离城镇的玩家必然死亡。每种灾害必须提供至少一种地图避难方式和一种野外补救方式。

### 9.4 灾害效果执行

灾害只描述需要产生的环境后果，具体结果由对应系统执行：

| 灾害内容 | 负责系统 |
| --- | --- |
| 地块泥泞、冻结、淹没与道路封锁 | 地图系统 |
| 环境伤害与状态积累 | 战斗与状态系统 |
| 元宝、材料与装备耐久损失 | 经济、背包与装备系统 |
| 强制位移 | 地图与移动系统 |
| 灾后任务和特殊 NPC | 任务、事件与 NPC 系统 |
| 灾害随机后果 | 随机系统 |

所有业务结果完成后，昼夜与气候系统只记录灾害阶段、持续时间与公开环境状态。

## 10. 小王灾害

小王建议触发地区性重大灾害，默认持续 `5` 轮。

小王灾害通常只覆盖部分区域，或只对特定地形产生严重影响。

### 10.1 台风登陆

台风登陆持续 `5` 轮。

| 阶段 | 轮次 | 主要内容 |
| --- | --- | --- |
| 预警阶段 | 第 `1` 轮 | 公布台风路径，不造成严重伤害，玩家可以撤离。 |
| 灾害阶段 | 第 `2–4` 轮 | 户外角色每轮进行一次台风后果判定。 |
| 衰退阶段 | 第 `5` 轮 | 直接伤害停止，生成临时地图影响与灾后内容。 |

台风后果可以包括：

* 受到环境伤害。
* 丢失少量普通材料。
* 损失少量元宝。
* 被吹向相邻可通行格。
* 下一轮移动力受到限制。
* 装备耐久轻度下降。

每次结算只触发一种主要后果，避免多项惩罚同时发生。

衰退阶段可以产生：

* 部分地块变为泥泞。
* 个别非关键道路暂时受阻。
* 出现漂流物资。
* 开放灾后救援任务。

### 10.2 区域洪水

区域洪水持续 `5` 轮。

可能效果包括：

* 低地和水域附近逐步被淹没。
* 低地移动消耗增加。
* 部分非关键道路暂时无法通行。
* 高地和符合条件的城镇成为安全区域。
* 水上、攀爬与救援类道具价值提高。
* 灾害结束后出现漂流资源。

洪水不能封锁全部出生区域、主要城镇和创界山路线。地图系统必须在应用淹没与封路前检查关键连通性。

### 10.3 极寒风暴

极寒风暴持续 `5` 轮。

角色可以通过以下内容规避寒冷：

* 城镇或建筑。
* 篝火附近。
* 特殊温暖地形。
* 具有保暖能力的装备或道具。

未避难角色每轮积累寒冷状态。只有寒冷达到配置层数后，才开始产生生命损失或行动限制，避免灾害开始后立即造成过重惩罚。

---

## 11. 大王灾害

大王建议触发全地图极端气候，默认持续 `8–10` 轮。

大王灾害会暂时改变所有玩家的行动重点，但不应完全禁止探索、交易、任务与成长行为。

### 11.1 超级台风

超级台风建议持续 `8` 轮。

| 阶段 | 轮次 | 主要内容 |
| --- | --- | --- |
| 预警阶段 | 第 `1–2` 轮 | 公布路径和安全地点，允许玩家储备物资与撤离。 |
| 灾害阶段 | 第 `3–6` 轮 | 未处于安全地点的角色每轮进行一次灾害判定。 |
| 灾后阶段 | 第 `7–8` 轮 | 直接伤害停止，生成道路、商店、物资与救援内容。 |

灾害阶段可能产生：

| 后果类型 | 说明 |
| --- | --- |
| 生命损失 | 受到有限环境伤害。 |
| 经济损失 | 损失少量元宝。 |
| 物资损失 | 随机失去普通材料。 |
| 强制位移 | 被吹向相邻可通行格。 |
| 行动受限 | 下一轮移动力降低。 |
| 装备损伤 | 装备耐久轻度下降。 |

处于安全地点的玩家仍然可以执行与地点相符的活动，例如休整、交易、打造、鉴定、接取救灾任务、参与城镇防御和帮助 NPC 撤离。

灾后阶段可以产生：

* 泥泞区域增加。
* 部分商店价格临时变化。
* 道路或桥梁暂时受阻。
* 稀有漂流物资刷新。
* 救援与重建任务开放。

### 11.2 永冻纪元

永冻纪元建议持续 `10` 轮。

其主要特点包括：

* 昼夜正常交替。
* 所有阶段均处于极寒气候。
* 水域逐步冻结。
* 部分冻结水域可以临时通行。
* 野外恢复受到限制。
* 火源与保暖资源价值提高。

灾害结束时，冻结水域应分阶段恢复。仍停留在冰面上的角色必须获得至少一个完整轮次的公开撤离时间，不能在没有预警的情况下直接落入不可通行水域。

### 11.3 天地昏暗

天地昏暗建议持续 `8` 轮。

其主要特点包括：

* 白天仍然视为白天，黑夜仍然视为黑夜。
* 太阳与月亮均被异常云层遮蔽。
* 白天视野轻度降低。
* 黑夜照明资源消耗增加。
* 部分夜行生物可以在白天出现。
* 城镇灯光与建筑照明正常工作。
* 部分神秘地点暂时开放。

天地昏暗以长期环境变化为主，不持续造成生命伤害。

## 12. 灾害平衡规则

### 12.1 灾害后果递增

重大灾害不应在第一轮就造成最大惩罚。

推荐使用递进式结算：

| 连续未避难次数 | 建议后果 |
| --- | --- |
| 第一次 | 公开警告或轻度损失。 |
| 第二次 | 中度损失或短期行动限制。 |
| 第三次及以后 | 较严重但仍可恢复的损失。 |

进入合法避难状态后，连续未避难次数清零或按照灾害配置降低。具体规则必须在灾害开始时公开。

### 12.2 避难不等于停止游戏

玩家进入安全地点后，不应只能跳过回合。

避难期间仍可以进行与地点相符的活动，例如：

* 交易。
* 制造。
* 鉴定。
* 休整。
* 使用道具。
* 与 NPC 互动。
* 接受救灾任务。
* 调整装备。
* 与同一地点的玩家交易或合作。

### 12.3 灾害同时带来机会

重大灾害结束后，应产生一定的正向内容，避免灾害只有负面体验。

例如：

* 灾后稀有材料。
* 漂流物资。
* 救援任务。
* 城镇重建奖励。
* 临时开放的道路。
* 冻结后可通行的水域。
* 特殊 NPC。
* 气候限定装备图纸。

灾害收益不能稳定高于玩家主动触发灾害或故意留在危险区域所承担的成本，避免形成利用灾害刷取资源的固定路线。

### 12.4 重大灾害频率

天气牌组在耗尽前不会重新洗牌，因此同一张大小王不会重复出现。

重大灾害持续期间暂停普通抽牌，且灾害结束后的恢复天气不会立即触发另一张大小王。系统还可以配置灾害冷却，避免两次重大灾害之间没有正常天气阶段。

## 13. 天气牌数量建议

在一副 `54` 张扑克牌中，推荐采用以下完整分布：

| 类型 | 建议数量 | 主要作用 |
| --- | ---: | --- |
| 无数值常态天气 | `32` 张 | 环境描述与天气标签。 |
| 轻度条件天气 | `6` 张 | 提供特殊触发条件或单一轻度影响。 |
| 极端天气 | `10` 张 | 持续 `2` 轮的有限规则变化。 |
| `A` 牌特殊天气 | `4` 张 | 四项独立天气机制。 |
| 大小王重大灾害 | `2` 张 | 持续 `5–10` 轮的气候危机。 |
| **总计** | **`54` 张** | 完整天气牌组。 |

其中：

* `A` 牌与大小王的数量固定。
* 数字牌 `2–7` 原则上全部属于无数值常态天气。
* 数字牌 `8–10` 与人头牌根据最终效果分配至常态、轻度或极端天气。
* J/Q/K 只规定局部、复合和全域形式，不强制其拥有数值惩罚。

这样可以保证超过半数牌面不直接修改数值，同时保留足够的极端天气、特殊机制与重大灾害。

具体牌面映射由配置资源维护。修改映射时，必须继续满足总数 `54` 与各类别数量约束。

## 14. 结算顺序

每个完整轮次开始时，世界环境按照以下顺序结算：

1. 确认当前轮次编号与本轮玩家集合。
2. 根据轮次编号检查昼夜是否切换。
3. 推进重大气候灾害阶段。
4. 检查本轮是否需要恢复或抽取天气。
5. 当前不存在重大灾害时，抽取并公布天气牌。
6. 公布昼夜、天气、灾害、作用区域与规避方式。
7. 处理轮次开始时的环境效果。
8. 进入黑夜秘密行动或其他回合阶段。
9. 玩家依次执行行动，并处理个人回合结束时的环境效果。
10. 所有玩家行动结束后，处理轮末天气与灾害效果。
11. 减少天气剩余时间，并完成本轮环境日志。

```text
轮次开始
    │
    ▼
昼夜检查
    │
    ▼
灾害阶段推进
    │
    ▼
天气抽取或恢复
    │
    ▼
公开世界环境
    │
    ▼
秘密行动与玩家行动
    │
    ▼
个人轮末环境结算
    │
    ▼
世界轮末环境结算
    │
    ▼
持续时间与日志更新
```

当前存在大小王灾害时，跳过普通天气抽取步骤。昼夜检查始终执行。

环境效果使角色当前生命值降至 `0` 时，按照《16-模块系统/02-复活与中途加入》的击倒规则处理，不能由天气系统直接将角色标记为正式死亡。

## 15. 数据结构建议

天气、特殊天气和重大灾害均采用资源配置管理。

### 15.1 天气配置

每张天气牌至少包含以下字段：

```json
{
  "cardId": "SPADE_A",
  "name": "雷云追踪",
  "category": "SPECIAL_WEATHER",
  "suit": "SPADE",
  "rank": "A",
  "durationRounds": 2,
  "scope": "TARGET_REGION",
  "tags": [
    "雷暴",
    "追踪",
    "户外危险"
  ],
  "hasNumericEffect": true,
  "description": "随机选择一名角色，雷云在未来两轮跟随其所在区域。",
  "avoidanceTypes": [
    "城镇",
    "建筑",
    "洞穴",
    "地下区域"
  ],
  "effectIds": [
    "WEATHER_THUNDER_CLOUD_TRACKING"
  ]
}
```

建议基础字段如下：

| 字段 | 说明 |
| --- | --- |
| `cardId` | 全局唯一牌面标识。 |
| `name` | 向玩家展示的天气名称。 |
| `category` | 常态、轻度、极端、特殊或灾害。 |
| `suit` | 红桃、方块、梅花或黑桃；大小王可为空。 |
| `rank` | `2–10`、`J`、`Q`、`K`、`A` 或 Joker。 |
| `durationRounds` | 默认持续完整轮数。 |
| `scope` | 全域、区域、地形或目标。 |
| `tags` | 供任务、能力、事件与界面读取的标准标签。 |
| `hasNumericEffect` | 是否直接产生数值修正。 |
| `avoidanceTypes` | 可以规避或抵消天气的方式。 |
| `effectIds` | 需要执行的标准环境效果。 |

### 15.2 灾害配置

重大气候灾害额外包含：

```json
{
  "warningRounds": 2,
  "disasterRounds": 4,
  "recoveryRounds": 2,
  "shelterTypes": [
    "城镇",
    "坚固建筑",
    "地下设施"
  ],
  "wildernessCountermeasureIds": [
    "TENT",
    "WATERPROOF_GEAR",
    "TELEPORT_SCROLL"
  ],
  "postDisasterEventPoolId": "TYPHOON_RECOVERY_EVENTS"
}
```

灾害配置必须明确：

* 各阶段持续时间。
* 作用区域与地图筛选规则。
* 预警信息。
* 避难地点与野外补救方式。
* 每阶段效果与结算时机。
* 灾后地图、任务和事件内容。

### 15.3 配置校验

配置加载时应检查：

* `cardId` 全局唯一。
* 天气牌总数等于 `54`。
* 四种花色各拥有完整的 `A–K`。
* 大小王各有且只有一张。
* 各天气类别数量符合牌组分布。
* 持续时间为正整数。
* 数值效果拥有对应的标准效果标识。
* 极端天气至少提供一种规避方式。
* 重大灾害至少提供一种地图避难和一种野外补救方式。
* 局部天气不能选择不存在或不合法的地图区域。
* 天气标签、地点类型和效果标识属于统一枚举。

天气描述、效果、牌面映射与灾害阶段应尽量通过配置维护，不应为每张天气牌编写专属的流程分支。

## 16. 系统总结

昼夜与气候系统的核心规则如下：

昼夜每 `5` 个完整轮次规律交替，并始终保持稳定运行。游戏每 `2` 个完整轮次从独立天气牌组中抽取一张牌，大部分天气只提供环境描述与条件标签，不直接改变数值。少量极端天气持续 `2` 轮，并对视野、移动、资源或环境规则产生有限影响。

四张 `A` 分别触发具有独立机制的特殊天气。大小王代表持续 `5–10` 轮的重大气候灾害，通过预警、避难、物资消耗、阶段结算与灾后事件形成长期环境挑战。

该系统应保证玩家在大部分时间能够按照正常规则行动，同时通过少量特殊天气和重大灾害制造变化，使世界既拥有可以规划的稳定节奏，也能偶尔出现符合《开天辟地之大地的裂变》风格的突发状况。
