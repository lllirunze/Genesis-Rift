# 《开天辟地之大地的裂变》使命与胜利条件

## 1. 设计目标

使命（Mission）是角色在一局游戏中的个人最终目标，也是玩家获得游戏胜利的主要方式。

本系统参考《爱情公寓第三季》中陆展博提出的设计理念，使每位玩家拥有不同的隐藏目标。玩家不需要单纯依靠击败所有敌人获得胜利，而是在成长、探索、交互与选择中逐步完成属于自己的使命。

使命系统与身份、信仰、角色成长、地图和世界事件等模块共同组成玩家的发展方向，使不同玩家拥有不同的行为倾向，提高游戏的策略深度、隐藏博弈与重复游玩价值。

使命系统遵循以下设计原则：

* 每位玩家拥有独立且隐藏的个人胜利目标。
* 玩家可以通过多种发展路线完成使命。
* 不强制玩家体验一局游戏中的全部内容。
* 不同身份与信仰拥有不同的发展倾向。
* 世界变化可以影响玩家的发展方向，但不能使玩家永久失去获胜机会。
* 使命应引导玩家作出选择，而不是要求玩家机械重复同一种行为。

使命系统的核心定位可以概括为：

**其他玩家能够观察你的行动，却不能直接知道你为何这样行动。**

---

## 2. 使命组成

每位玩家在游戏开始时固定获得 `5` 个隐藏使命。

五个使命分别来源于不同系统，每种使命负责引导玩家体验一类玩法：

| 使命类型 | 主要来源 | 主要作用 |
| --- | --- | --- |
| 身份使命 | 开局基础身份 | 体现角色的身份特色与主要玩法定位。 |
| 信仰使命 | 隐藏信仰 | 体现不同信仰的价值取向与发展方向。 |
| 成长使命 | 角色成长 | 鼓励等级、装备、属性分配与养成选择。 |
| 世界使命 | 地图与世界事件 | 推动玩家参与地图探索和世界变化。 |
| 自由使命 | 通用随机使命池 | 增加每局游戏的变化性与不可预测性。 |

本项目统一使用“身份使命”描述由法师、游侠、盗贼等开局身份产生的目标，不再额外使用“职业使命”建立重复概念。

五个使命相互独立，但共同组成玩家本局游戏的发展目标。使命生成时应尽量避免：

* 两个使命拥有完全相同的完成条件。
* 两个使命只能通过同一次唯一内容完成。
* 使命之间存在无法同时满足的直接冲突。
* 多个使命强制玩家采用同一条发展路线。
* 使命依赖当前对局中不存在的系统、区域或资源。

身份使命最初根据玩家的开局基础身份生成。角色后续完成转职时，已经完成的身份使命保持不变，尚未完成的身份使命按照转职路线升级为对应的新使命，具体规则由《02-使命生成系统》统一定义。

使命的具体生成、去重与冲突检查将在《02-使命生成系统》中说明。

## 3. 胜利条件

玩家不需要完成全部使命。

当玩家累计完成 `5` 个使命中的任意 `3` 个时，即满足个人胜利条件。

```text
每位玩家拥有 5 个隐藏使命
              │
              ▼
      完成其中任意 3 个
              │
              ▼
        满足个人胜利条件
```

剩余未完成的使命不会影响玩家最终获胜，只作为不同局势下的备用发展路线。

### 3.1 胜利确认时机

玩家完成第三个使命时，不会立即打断正在进行的行动、战斗、事件或响应链，而是进入“待确认胜利”状态。

系统应在当前完整结算结束后进行胜利检查：

```text
使命完成
    │
    ▼
记录使命状态与完成数量
    │
    ▼
完成当前行动、战斗、事件及响应结算
    │
    ▼
检查是否完成至少 3 个使命
    │
    ▼
宣布胜利并结束本局游戏
```

“当前完整结算”是指触发第三个使命完成的直接流程及其响应内容已经全部结束，不包括之后尚未开始的其他玩家行动。

### 3.2 同时满足胜利条件

世界事件或公共结算可能使多名玩家在同一个结算节点同时完成第三个使命。

若多名玩家在同一完整结算中满足个人胜利条件，则这些玩家共同获胜。系统不能根据座次、客户端回报顺序或内部处理顺序任意指定唯一胜者。

若玩家在不同结算节点先后满足条件，则以最早完成并进入胜利检查的玩家为胜者，后续尚未开始的行动不再继续。

### 3.3 创界山与胜利

创界山仍然是世界中心、重要探索目标与原作辨识度最高的终局内容之一，可以参与世界使命、特殊事件与高价值挑战。

但是在默认使命模式中，登上创界山不会绕过“完成任意 `3` 个使命”的个人胜利规则。创界山可以成为玩家完成某项世界使命的方式，但不是所有玩家必须选择的唯一获胜路线。

如果后续模式希望恢复“率先登上创界山直接获胜”的原作规则，必须作为明确的独立胜利模式启用，不能与默认使命模式同时产生含糊判定。

## 4. 使命基本规则

### 4.1 隐藏信息

使命属于玩家个人隐藏信息。

除玩家本人外，其他玩家默认无法查看：

* 具体使命内容。
* 使命完成条件。
* 当前使命进度。
* 已经完成的使命数量。

玩家只能通过其他角色的移动、战斗、交易、装备、事件选择与资源倾向，推测其可能拥有的发展目标。

部分使命完成后可能产生公开的世界变化，但系统仍不会因此直接公开该玩家完成了哪项使命。若使命文本明确要求完成时公开，则以使命自身规则为准。

### 4.2 永久记录

使命一旦完成，即永久记录并计入玩家的胜利条件。

已完成使命不会因为以下变化而失效：

* 身份状态发生变化。
* 角色完成转职。
* 地图发生裂变。
* 世界事件改变区域状态。
* 玩家失去完成使命时持有的装备或资源。

系统判断使命完成时，应保存完成时间、完成来源与对应结算记录，不能在后续只根据角色当前状态重新推导是否仍然完成。

### 4.3 独立计算

每个使命均拥有独立的完成条件与进度记录。

同一次行动可以同时推进或完成多个使命，但每个使命仍按照自身条件分别进行判断。

例如：

* 击败精英怪可以推进身份使命。
* 获得传说装备可以推进成长使命。
* 首次进入创界山可以推进世界使命。

如果同一次结算使玩家从完成 `1` 个使命直接增加至完成 `3` 个使命，系统仍应在该结算结束后正常确认胜利。

不同使命不能因为监听到同一行为便自动视为重复。只要生成阶段已经确认其目标与玩法侧重点不同，同一次行动可以合法推进多个使命。

### 4.4 使命进度

部分使命拥有阶段性目标，系统自动记录当前进度，并且默认仅玩家本人可见。

例如：

```text
探索未踏足区域
当前进度：2 / 5

完成史诗装备打造
当前进度：1 / 3
```

使命进度使用非负整数。进度达到目标值时使命完成，超出目标值的部分不产生额外使命完成次数。

并非所有使命都需要累计进度。部分使命只需完成一次特定事件、选择或世界行为即可完成。

使命进度必须来源于对应系统已经确认的结果。例如，装备制造使命只能在制造系统确认装备成功产出后增加进度，不能在玩家仅准备好材料时提前记录。

### 4.5 不可主动放弃

玩家不能直接删除、放弃或重新抽取已有使命。

若玩家希望重新规划自己的发展路线，必须通过《03-使命重塑系统》规定的流程完成调整。

已经完成的使命不能被重塑，也不能通过任何方式改回未完成状态。

### 4.6 使命与任务的区别

使命与普通任务属于不同概念：

| 概念 | 主要职责 |
| --- | --- |
| 使命 | 构成玩家个人胜利条件，数量固定且默认隐藏。 |
| 任务 | 提供阶段目标、剧情、奖励或系统引导，可以公开并在一局中反复获得。 |

任务可以推进使命，但完成任务不代表必然完成使命。使命也不应绕过任务系统，直接将尚未满足条件的任务标记为完成。

## 5. 世界变化与使命保护

随着游戏进行，世界可能发生不可逆变化，例如：

* 地图发生裂变。
* 特殊区域永久消失。
* 重要 NPC 永久死亡。
* 唯一道具被其他规则销毁。
* 世界剧情进入新的阶段。

如果某个未完成使命因世界变化而客观无法完成，系统应自动将其转换为一个同类型的新使命。

自动转换遵循以下规则：

* 不消耗元宝或其他资源。
* 不占用玩家主动重塑次数。
* 不改变玩家已经完成的使命数量。
* 新使命与原使命属于相同类型。
* 新使命的预计剩余难度不得明显高于原使命失效前的剩余难度。
* 新使命必须重新通过重复、冲突与可完成性检查。

使命“难以完成”“当前收益较低”或“玩家不愿继续”不属于客观无法完成，不能触发免费自动转换。

当系统无法立即判断使命是否客观失效时，应继续保留原使命，直至对应系统确认目标已经永久不可达。玩家不能通过主动制造短期障碍要求免费更换使命。

进度是否能够继承取决于新旧使命是否使用相同的进度口径。可以根据历史记录重新计算的进度应正常保留；无法等价转换的进度不直接复制，具体规则将在《02-使命生成系统》中说明。

## 6. 游戏结束后的公开规则

为了保证游戏过程中的推理性与隐藏信息，所有使命默认仅玩家本人可见。

当游戏结束后，系统统一公开所有玩家的相关信息，包括：

* 五个使命的完整内容。
* 已完成使命及完成时间。
* 未完成使命及最终进度。
* 发生过的自动转换与主动重塑。
* 隐藏信仰。
* 神鬼契约（若存在）。
* 最终获胜原因与对应结算记录。

赛后公开只用于复盘，不会追溯修改已经确认的胜利结果。

玩家可以通过复盘了解每名角色的发展路线，观察不同使命之间形成的合作、误导、竞争与故事。

## 7. 系统职责

使命与胜利条件系统负责管理个人目标和最终胜利判断，不重复实现其他系统的业务逻辑。

| 相关系统 | 主要职责 |
| --- | --- |
| 身份系统 | 提供生成身份使命所需的开局基础身份。 |
| 信仰系统 | 提供生成信仰使命所需的隐藏信仰。 |
| 角色与装备系统 | 提供等级、成长、制造与装备结果。 |
| 地图与事件系统 | 提供探索、区域、世界事件与裂变结果。 |
| 经济系统 | 提供使命重塑需要的元宝支付结果。 |
| 任务系统 | 管理普通任务，并向使命系统报告已经确认的任务结果。 |
| 使命系统 | 生成五项使命、维护进度、记录完成状态并处理使命转换。 |
| 回合系统 | 在当前完整结算结束后触发胜利检查。 |
| 胜利系统 | 判断是否完成任意三项使命，并宣布胜者或共同胜者。 |

使命系统只能读取其他系统已经确认的事实，不能为了推进使命而直接修改战斗、装备、地图、经济或任务结果。

## 8. 设计原则总结

使命与胜利条件系统遵循以下原则：

五选三原则

每名玩家拥有五个隐藏使命，完成任意三个即可满足默认个人胜利条件。

多路线原则

五项使命来源不同，玩家不需要体验所有玩法，也不应被迫沿唯一发展路线前进。

隐藏推理原则

使命内容、进度与完成数量默认保密，其他玩家通过可观察行为推测其发展方向。

完成永久原则

使命完成后永久计入胜利条件，不因后续世界或角色状态变化失效。

结算完整原则

第三项使命完成后，必须等待当前行动、战斗、事件与响应全部结算完毕，再统一判断胜利。

获胜机会保护原则

世界发生不可逆变化时，客观无法完成的使命自动转换为同类型、难度合理的新使命。

职责分离原则

使命系统记录目标与进度，其他系统负责产生真实游戏结果，胜利系统只在合法结算节点判断最终结果。
