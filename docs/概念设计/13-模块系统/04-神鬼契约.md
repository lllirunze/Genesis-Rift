# 《开天辟地之大地的裂变》神鬼契约系统

## 1. 系统定位

神鬼契约是《开天辟地之大地的裂变》中的特殊隐藏机制。

玩家满足特定条件后，可能获得一次与“上帝”进行秘密交易的机会。玩家可以签署契约，立即获得一项永久正面效果，但在若干自身回合后，也会永久承受对应的负面效果。

神鬼契约不属于普通任务、装备、技能或临时增益，而是一种对玩家本局后续玩法产生长期影响的不可逆规则。

其核心体验可以概括为：

**玩家提前获得超出正常成长节奏的力量，并在未来承担无法解除的永久代价。**

神鬼契约具有以下特点：

* 触发机会稀少。
* 签署过程完全保密。
* 签署前可以自由拒绝。
* 签署后不可撤销。
* 正面效果立即永久生效。
* 负面效果延迟永久生效。
* 不存在履约与违约机制。
* 其他玩家在对局过程中无法确认契约是否存在。

本章节中的“永久”是指持续至本局游戏结束，不代表跨对局继承，也不修改玩家在其他对局中的角色数据。

---

## 2. 基础规则

### 2.1 签署次数

每名玩家在一局游戏中最多只能签署一份神鬼契约。

玩家一旦签署契约，本局内永久失去再次签署其他神鬼契约的资格。即使负面效果已经生效，或者玩家通过死亡、轮回、转职等方式改变当前状态，也不能重新签署契约。

签署资格属于玩家本局私有状态，不因以下内容重置：

* 角色濒死或正式死亡。
* 角色进入灵魂状态或完成轮回。
* 身份发生转职。
* 装备、属性或地图位置变化。
* 世界阶段推进或地图裂变。
* 契约正面或负面效果已经生效。

拒绝契约不等同于已经签署。玩家以后仍可能通过其他合法来源获得新的契约机会，但同一次机会不能反复查看、拒绝后恢复或刷新内容。

### 2.2 自愿签署

玩家获得契约机会后，可以在私有界面中查看该契约的完整内容，包括：

* 契约名称与描述。
* 立即生效的永久正面效果。
* 延迟生效的永久负面效果。
* 负面效果的触发方式与最晚生效时间。
* 契约不可撤销、不可解除的规则。

玩家可以选择签署或拒绝。

拒绝不会产生任何惩罚，包括但不限于：

* 不扣除生命值、灵力或其他身份资源。
* 不扣除元宝或物品。
* 不降低基础属性或派生属性。
* 不影响隐藏信仰与使命。
* 不产生隐藏诅咒或临时状态。
* 不降低未来触发其他事件或契约机会的概率。

玩家拒绝后，本次契约机会立即结束。系统不能在拒绝后提供同一机会中的第二份契约，也不能允许玩家返回重新签署刚刚拒绝的内容。

私有选择超时且玩家没有确认签署时，默认视为拒绝，不产生惩罚。

### 2.3 不可撤销

契约一旦签署便立即成立。

成立后的契约：

* 不能主动取消。
* 不能更换或重新选择效果。
* 不能转让给其他玩家。
* 不能通过药剂、装备、能力或策略牌解除。
* 不能通过净化、死亡、轮回或转职解除。
* 不能通过普通 NPC 服务解除。
* 不能通过使命重塑间接移除。
* 不能再次签署其他神鬼契约。

契约不会因为地图裂变、世界事件、角色濒死、角色轮回或游戏阶段变化而失效。

签署过程必须采用完整事务：签署状态、正面效果、负面效果计时和私有日志应同时成功写入。任意步骤失败时，整次签署取消，不能出现已经锁定签署资格但没有获得正面效果的情况。

### 2.4 不存在违约

神鬼契约不是任务型协议，因此不设置履约目标，也不存在违约状态。

玩家签署后：

* 不需要完成额外任务。
* 不需要定期支付元宝、生命值或其他资源。
* 不需要保持某种行为或阵营立场。
* 不会因为某次选择而进入违约状态。
* 不能通过主动违约提前结算或解除负面效果。

系统不需要为神鬼契约设计：

* 履约进度。
* 违约判断。
* 违约惩罚。
* 契约任务。
* 契约解除条件。
* 契约转移机制。

契约交易在签署时已经完成。玩家获得永久恩赐，同时接受未来必然生效的永久代价。

### 2.5 与普通契约的区别

游戏中仍可以存在贷款、交易协议、任务誓约或其他普通契约，但它们不属于神鬼契约。

| 对比项 | 神鬼契约 | 普通契约或协议 |
| --- | --- | --- |
| 是否隐藏 | 全程私有 | 由具体规则决定。 |
| 是否存在履约 | 不存在 | 可以存在。 |
| 是否存在违约 | 不存在 | 可以存在。 |
| 是否定期支付 | 不需要 | 可以需要。 |
| 是否可以解除 | 本局不可解除 | 由具体规则决定。 |
| 核心结构 | 立即永久恩赐 + 延迟永久代价 | 由任务、经济或交互系统定义。 |

其他文档出现“契约费用”“契约利息”或“违反契约”时，默认只指普通经济协议或任务协议，不适用于神鬼契约。

## 3. 契约触发机制

神鬼契约不能由玩家随时主动申请，只能在特殊场景、特殊事件或特殊状态下触发。

玩家获得的不是契约道具，而是一次短暂、私密且不可刷新的签署机会。

### 3.1 特殊地点触发

契约入口可以隐藏在已有地点的普通交互中，例如：

* 神殿祈福。
* 遗迹探索。
* 城镇旅店休息。
* 裂变空间搜索。
* 创界山特殊房间。
* 黑夜进入无人区域。
* 与特定 NPC 交互。
* 探索地图边界事件。

这些地点不能公开标注为“神鬼契约地点”。同一地点应具备正常功能，使其他玩家不能只根据玩家进入某个地点，判断其是否获得契约邀请。

例如，玩家进入神殿后，对外只表现为普通祈福、恢复或休息。系统可以在玩家私有界面中额外检查契约机会，但其他玩家看不到该检查结果。

### 3.2 特殊事件触发

少量命运事件、彩蛋事件和特殊剧情可以隐藏契约入口。

玩家正常获得公开事件结果后，只有本人可能额外看到契约邀请。公开事件描述、选项与结算日志不能直接出现契约内容。

事件系统只负责提供契约触发来源，契约候选筛选、内容生成、签署和效果状态均由神鬼契约系统负责。

### 3.3 特殊状态触发

契约可以在玩家处于特殊状态时进入候选，例如：

* 第一次进入濒死状态。
* 连续多次战斗失败。
* 元宝长期处于较低水平。
* 某项属性达到极端值。
* 首次进入创界山区域。
* 第一次接触地图边界。
* 长时间未完成任何使命。
* 处于规则定义的明显弱势状态。
* 持有指定未知物品。

这些条件只决定玩家是否有机会接触契约，不会强制玩家签署，也不会直接决定最终契约内容。

用于判断“弱势”“长期”或“极端”的条件必须配置为明确、可验证的数据规则，不能由上帝根据主观印象临时判断。

### 3.4 候选筛选与抽取

触发来源成立后，系统先筛选当前合法契约。

契约进入候选集合时必须满足：

* 玩家本局尚未签署神鬼契约。
* 契约依赖的模块已经启用。
* 正面效果能够对该玩家产生实际作用。
* 负面效果能够形成真实且可预期的代价。
* 契约不会与玩家已有永久规则产生无法结算的冲突。
* 契约允许在当前世界阶段与触发场景出现。
* 身份、转职、种族或信仰限制已经满足。

系统从合法候选集合中按权重生成一份契约，并将完整内容私下展示给玩家。一次机会只提供一份契约，玩家不能刷新、重抽或比较多个结果。

没有合法候选契约时，本次隐藏检查不产生邀请，也不向玩家显示失败提示。

所有随机触发和契约抽取均使用《01-随机系统》的契约随机流。幸运值不影响神鬼契约的触发概率、候选权重和契约内容。

### 3.5 隐藏触发原则

其他玩家不能通过以下内容确认契约机会已经发生：

* 契约专属公开动画或音效。
* 契约地点标记。
* 公开的私人事件提示。
* “正在签署契约”等等待状态。
* 不同于普通交互的公开回合停顿。
* 契约相关公开日志。

契约选择应嵌入玩家正常操作流程，并使用已有私有信息界面。共享回合不能因为契约选择无限暂停；数字版可以在普通交互时限内异步展示，桌游模式则由上帝在正常私密信息阶段完成处理。

无论玩家是否获得邀请、签署或拒绝，其他玩家看到的公开流程应保持一致。

### 3.6 上帝权限

上帝负责维护契约流程与私密信息，但不能随意创造结果。

上帝可以：

* 在合法触发来源成立后启动契约检查。
* 在桌游模式中私下向玩家展示已经确定的契约。
* 处理超时、掉线和规则异常。
* 在赛后复盘阶段公开契约记录。

上帝不能：

* 绕过触发条件指定某名玩家获得契约。
* 因玩家关系改变契约权重或内容。
* 隐瞒负面效果后诱导玩家签署。
* 在签署后修改正面效果、负面效果或延迟时间。
* 向其他玩家泄露契约存在与内容。

## 4. 契约效果结构

每份神鬼契约由两部分组成：

1. 签署后立即生效的永久正面效果。
2. 延迟若干自身回合或阶段后生效的永久负面效果。

负面效果生效后，正面效果不会消失。玩家同时保留正面效果与负面效果，直至本局结束。

```text
获得契约机会
      │
      ▼
私下查看完整内容
      │
      ├── 拒绝：本次机会结束
      │
      └── 签署
            │
            ▼
永久正面效果立即生效
            │
            ▼
经过指定自身回合或进入指定阶段
            │
            ▼
永久负面效果生效
            │
            ▼
正面与负面效果同时持续至本局结束
```

### 4.1 永久正面效果

契约正面效果应具有足够吸引力，能够明显改变玩家后续玩法。

正面效果可以涉及：

* 属性强化。
* 移动规则强化。
* 地形适应强化。
* 视野强化。
* 战斗机制强化。
* 装备规则强化。
* 经济规则强化。
* 制造规则强化。
* 升级成长强化。
* 使命完成路线强化。

使命相关契约只能提供新的完成手段、降低特定路线成本或强化相关行动，不能在签署时直接增加使命完成数量或无条件写入使命进度。

不适合作为核心契约正面效果的内容包括：

* 下一次攻击必定暴击。
* 立即恢复一次生命值。
* 获得一次额外回合。
* 下一次购买免费。
* 持续三回合提高攻击。
* 只免疫一次伤害。

这些内容属于一次性或短期效果，更适合作为事件、道具、能力或策略牌。

### 4.2 延迟负面效果

契约负面效果不会在签署时立即生效，而是在预设时间或阶段后自动生效。

负面效果一旦生效，同样永久持续至本局结束。它不需要玩家完成任何条件，也不能通过规避行为阻止生效。

推荐以玩家自己的回合数作为延迟计时标准：

```text
签署后的第 N 个自身回合开始时
→ 契约永久负面效果生效
```

按照契约强度，可以采用以下延迟范围：

| 契约强度 | 建议生效时间 |
| --- | --- |
| 较弱契约 | `3–5` 个自身回合后。 |
| 普通契约 | `5–8` 个自身回合后。 |
| 强力契约 | `8–12` 个自身回合后。 |
| 极强契约 | `10–15` 个自身回合后。 |

也可以使用阶段型触发，例如：

* 第一次进入创界山后。
* 游戏进入最终阶段后。
* 第二次大型地图裂变后。
* 玩家达到指定等级后。

阶段型契约必须设置最晚生效时间，防止玩家通过拒绝进入区域、延迟升级或其他方式永久规避代价。

例如：

```text
签署满 5 个自身回合后，首次进入创界山时生效；
若始终未进入，则在第 12 个自身回合开始时自动生效。
```

### 4.3 自身回合计时

契约延迟使用玩家个人回合计数，不使用现实时间或其他玩家行动次数。

以下情况均会正常推进契约计时：

* 正常玩家回合。
* 因控制、昏迷或其他效果被跳过的自身回合。
* 死亡后的灵魂回合。
* 托管状态下正常经过的自身回合。

完整额外回合会推进契约计时；仅插入一次行动、响应或额外移动不会视为完整自身回合。

契约在某个自身回合中途签署时，当前回合不计入延迟。计时从下一次自身回合开始。

玩家死亡、断线或进入灵魂状态不能暂停、重置或倒退负面效果计时。

### 4.4 生效顺序

玩家回合开始时，神鬼契约按照以下顺序处理：

1. 增加并记录本次自身回合计数。
2. 检查时间型负面效果是否达到生效回合。
3. 检查阶段型负面效果是否满足触发条件或最晚时间。
4. 尚未生效且条件成立时，原子写入永久负面效果。
5. 使用新的最终规则继续处理本回合其他状态与行动。

负面效果只生效一次。读取存档、断线重连或回放不能重复添加相同效果。

## 5. 效果设计规范

### 5.1 正负效果尽量跨系统设计

契约的正面效果与负面效果不必作用于同一属性或系统。

应避免简单数值抵消，例如：

```text
物理攻击永久 +10
8 回合后物理攻击永久 -8
```

这种设计只是延迟计算最终数值，不能形成真正的策略变化。

更合理的设计是让正负效果跨系统交换，例如：

```text
物理攻击能力永久提高
8 回合后，所有治疗效果永久降低
```

或者：

```text
地图视野永久提高
8 回合后，普通地形移动能力永久降低
```

跨系统交换会迫使玩家重新调整装备、路线、资源与行动方式。

### 5.2 机制型效果优先

契约不应全部设计为基础属性或派生属性的加减。

推荐契约库整体采用以下比例：

| 效果类型 | 建议占比 |
| --- | ---: |
| 规则与机制变化 | `40%` |
| 地图、移动与视野变化 | `20%` |
| 经济、装备与制造变化 | `20%` |
| 直接数值变化 | `20%` |

机制型效果可以包括：

* 无视部分身份或转职装备限制。
* 改变部分地形移动消耗。
* 改变商店购买或出售价格。
* 改变装备耐久消耗。
* 改变升级经验或元宝成本。
* 改变治疗方式。
* 改变视野规则。
* 改变装备栏功能。
* 改变城镇或野外服务效果。

### 5.3 契约不能直接保证胜利

契约可以显著提高玩家某一方面的能力，但不能直接完成胜利条件。

契约不得提供：

* 自动完成一项或全部使命。
* 直接获得游戏胜利。
* 自动击败最终首领。
* 永久无敌。
* 无限元宝或其他资源。
* 无限行动。
* 无条件淘汰其他玩家。
* 无法限制的连续额外回合。

契约可以改变玩家的获胜路线和策略倾向，但玩家仍须通过正常行动满足使命与胜利规则。

### 5.4 契约必须形成真实代价

永久负面效果必须足以影响玩家后续决策，不能成为几乎不会生效的象征性代价。

例如，攻击型契约的负面效果不能只降低极少量无关能力，也不能限制正常流程中几乎不会使用的功能。

签署时应让玩家产生明确犹豫：

**永久收益足够强大，但未来代价会迫使我改变原有计划。**

候选筛选应结合玩家当前规则判断代价是否真实。如果玩家已经永久无法使用治疗药剂，则“未来禁止主动使用治疗药剂”不能作为该玩家的新契约代价。

### 5.5 不允许形成无限循环

契约效果不能与装备、身份、事件或其他契约外规则形成无限收益、无限响应或递归触发。

任何触发型契约都必须明确：

* 每次完整结算的触发次数上限。
* 是否能够由自身效果再次触发。
* 与同类效果叠加时的处理方式。
* 目标不存在或资源不足时的失败规则。

契约效果不能绕过随机系统、数值边界与正常响应顺序。

---

## 6. 完全保密规则

神鬼契约的存在、签署过程、效果来源与生效时间，在对局进行过程中必须对其他玩家完全保密。

### 6.1 不显示契约状态

其他玩家不能查看：

* 玩家是否获得过契约邀请。
* 玩家是否已经签署契约。
* 玩家何时签署契约。
* 契约名称与描述。
* 契约正面与负面效果。
* 负面效果何时生效。
* 当前契约处于哪个阶段。

公开玩家信息中不能出现：

```text
已签署神鬼契约
契约持有者
神鬼契约生效中
契约代价已到来
```

签署玩家可以在自己的私有界面查看完整契约、剩余计时与已生效状态。

### 6.2 不显示契约来源

契约效果应注入现有计算和规则系统。

例如，契约增加玩家最大生命值时，其他玩家只能看到规则允许公开的最终生命值，不能看到“神鬼契约：最大生命值增加”这一来源。

其他玩家可查看的属性详情中，不显示契约名称、契约图标或契约来源。签署玩家自己的私有详情可以显示完整来源，便于理解与核对。

### 6.3 不显示负面效果生效提示

负面效果生效时，系统不能向其他玩家显示契约相关文字或暗示性描述。

系统只更新对应计算结果，例如：

* 治疗效率降低后，按照新的规则计算治疗量。
* 商店价格上涨后，向该玩家显示新的实际价格。
* 移动能力下降后，显示新的可移动范围。
* 视野降低后，展示缩小后的可见区域。
* 装备耐久消耗加快后，按照新规则扣除耐久。

签署玩家应在私有界面收到代价已经生效的明确说明，不能为了对其他玩家保密而让本人无法理解数值变化。

### 6.4 不使用公开专属表现

神鬼契约不能提供公开可见的专属表现，包括：

* 契约图标、称号或边框。
* 契约粒子特效。
* 契约专属角色外观。
* 契约专属攻击动画或音效。
* 契约专属装备外观。
* 对局中的契约公开成就。

即使契约效果较强，也应尽量通过已有普通规则表现。其他玩家可以根据行为变化进行推测，但系统不能为其提供可以确认契约存在的证据。

### 6.5 日志与观战

契约日志按照权限分为：

| 日志类型 | 可见内容 |
| --- | --- |
| 公共日志 | 不显示邀请、签署、拒绝与生效信息。 |
| 玩家私有日志 | 显示本人契约内容、签署时间与效果状态。 |
| 权威审计日志 | 保存完整过程，仅供异常处理与赛后复盘。 |

普通观战者、其他玩家客户端和公开回放不能读取契约私有状态。上帝或服务器拥有审计权限时，也必须在对局过程中保密。

### 6.6 赛后公开

当本局游戏结束后，系统按照《12-获胜条件/01-使命与胜利条件》的赛后公开规则，统一展示神鬼契约信息。

赛后可以公开：

* 是否获得过契约邀请。
* 最终签署或拒绝结果。
* 契约名称与完整效果。
* 正面与负面效果的生效时间。
* 契约对最终发展路线产生的影响。

赛后公开只用于复盘，不追溯修改已经确认的游戏结果。

## 7. 契约示例

以下示例用于展示神鬼契约的设计方向，具体数值与强度需要在相关系统完成后统一测试。

| 契约名称 | 立即生效的永久正面效果 | 延迟生效的永久负面效果 |
| --- | --- | --- |
| 钢铁之躯 | 最大生命值与护甲永久提高。 | `8` 个自身回合后，所有治疗效果永久降低。 |
| 无尽行路者 | 基础移动力永久增加。 | `6` 个自身回合后，上坡与泥泞的额外移动消耗永久增加。 |
| 第三只眼 | 视野范围永久增加。 | `8` 个自身回合后，无法再获得其他视野增益。 |
| 染血之刃 | 物理攻击永久提高，击败敌人时恢复少量生命值。 | `7` 个自身回合后，永久无法主动使用治疗药剂。 |
| 灵力泉眼 | 最大灵力值与灵力恢复永久提高。 | `8` 个自身回合后，护甲类装备提供的效果永久降低。 |
| 黄金之手 | 商店购买价格永久降低，出售价格永久提高。 | `6` 个自身回合后，每次升级需要额外支付元宝。 |
| 无底行囊 | 负重上限永久提高，并增加一个物品携带位置。 | `7` 个自身回合后，高品质物品无法主动丢弃。 |

| 命运偏爱者 | 幸运值永久提高。 | `8` 个自身回合后，个人随机收益失败造成的损失永久提高。 |
| 静默猎手 | 黑夜中的命中、闪避与视野能力永久提高。 | `6` 个自身回合后，白天的行动优先级永久降低。 |
| 不死者之血 | 普通持续伤害无法将当前生命值降低至 `1` 以下。 | `10` 个自身回合后，直接治疗效果永久大幅降低。 |
| 空间旅人 | 使用传送、桥梁与特殊通道时的费用永久降低。 | `7` 个自身回合后，普通地块的连续移动能力永久降低。 |
| 知识之果 | 每次升级时获得额外属性调整机会。 | `8` 个自身回合后，后续升级所需经验永久增加。 |
| 神兵共鸣 | 装备提供的主要属性效果永久提高。 | `9` 个自身回合后，装备耐久消耗永久加快。 |
| 荒野之子 | 野外基础地形不再增加普通移动消耗。 | `8` 个自身回合后，城镇休息与恢复效果永久降低。 |
| 百无禁忌 | 永久无视部分身份与转职装备限制。 | `7` 个自身回合后，装备套装效果永久失效。 |
| 山巅来客 | 高地与创界山区域的判定永久获得优势。 | `10` 个自身回合后，城镇服务费用永久提高。 |

所有示例仍须遵循：

* 正面效果不能直接完成使命或保证胜利。
* 负面效果必须对当前玩家构成真实代价。
* 数值效果遵循数值系统统一计算与边界规则。
* 随机效果遵循随机系统，不创建契约专属随机算法。
* 同一效果在一次完整结算中不能无限触发。

## 8. 数据与程序设计

神鬼契约属于玩家私有权威数据。

公开玩家对象中不能保存可被其他玩家客户端直接读取的完整契约状态。服务器可以在玩家私有状态中维护：

```text
DivineContractState
├── signedContractId
├── hasSigned
├── signedAtWorldRound
├── signedAtPersonalTurn
├── personalTurnsElapsed
├── debuffTriggerType
├── debuffTriggerValue
├── debuffLatestPersonalTurn
├── buffActive
├── debuffActive
├── offerHistory
└── stateVersion
```

字段职责如下：

| 字段 | 说明 |
| --- | --- |
| `signedContractId` | 已签署契约资源标识；未签署时为空。 |
| `hasSigned` | 本局是否已经签署神鬼契约。 |
| `signedAtWorldRound` | 签署时的完整轮次。 |
| `signedAtPersonalTurn` | 签署时的玩家个人回合计数。 |
| `personalTurnsElapsed` | 签署后已经经过的有效自身回合数。 |
| `debuffTriggerType` | 时间型、阶段型或复合型触发。 |
| `debuffTriggerValue` | 负面效果主要触发条件。 |
| `debuffLatestPersonalTurn` | 阶段型效果最晚生效回合，可选。 |
| `buffActive` | 永久正面效果是否已经生效。 |
| `debuffActive` | 永久负面效果是否已经生效。 |
| `offerHistory` | 已经展示或拒绝过的契约机会记录。 |
| `stateVersion` | 用于幂等更新、存档恢复与冲突检查。 |

签署成功后的基础状态为：

```text
hasSigned = true
buffActive = true
debuffActive = false
personalTurnsElapsed = 0
```

到达负面效果触发条件后：

```text
debuffActive = true
buffActive 保持 true
```

### 8.1 效果注入

契约不单独建立一套公开计算系统，而是将效果注入已有业务模块：

| 契约效果 | 接入系统 |
| --- | --- |
| 基础属性与派生属性变化 | 属性修饰器与数值系统。 |
| 战斗规则变化 | 战斗计算与结算系统。 |
| 移动与地形变化 | 地图、移动与寻路系统。 |
| 视野变化 | 探索与视野系统。 |
| 装备限制与装备效果 | 装备系统。 |
| 商店价格与交易变化 | 经济系统。 |
| 制造材料与制造限制 | 图纸与制造系统。 |
| 升级经验与成长变化 | 等级系统。 |
| 使命路线变化 | 使命系统。 |

数值型契约效果作为本局永久的私有修饰来源参与统一计算，不能直接覆盖最终属性值。机制型效果通过对应系统的标准规则扩展点执行，不能在契约模块中复制业务逻辑。

### 8.2 私有同步

服务器只向签署玩家同步完整契约内容和计时状态。

向其他玩家同步的数据只能包含游戏规则本就允许公开的最终结果，不能包含：

* 契约资源标识。
* 契约效果标识。
* 私有修饰器来源。
* 负面效果倒计时。
* 签署与拒绝记录。

存档恢复时必须恢复契约状态、个人计时与已经注入的效果，并通过 `stateVersion` 防止正面或负面效果被重复添加。

## 9. 契约资源配置

每份神鬼契约通过资源文件进行配置。

示例结构如下：

```json
{
  "id": "contract_blood_blade",
  "name": "染血之刃",
  "description": "你的攻击将从鲜血中获得力量，但治愈之物终将拒绝你。",
  "buff": {
    "type": "combat_modifier",
    "effectId": "physical_attack_bonus",
    "value": 15
  },
  "debuff": {
    "type": "rule_restriction",
    "effectId": "disable_active_healing_item"
  },
  "debuffDelay": {
    "type": "personal_turn",
    "value": 7
  },
  "strength": "STRONG",
  "baseWeight": 10,
  "allowedWorldStages": [
    "RIFT_STAGE",
    "CREATION_STAGE"
  ],
  "triggerTags": [
    "NIGHT_EVENT",
    "RUIN_EXPLORATION"
  ]
}
```

每份契约至少包含：

* 契约唯一标识。
* 契约名称与私有描述。
* 永久正面效果。
* 永久负面效果。
* 负面效果触发方式与最晚生效时间。
* 契约强度与基础权重。
* 允许出现的世界阶段。
* 允许触发的场景与标签。
* 身份、转职、种族或信仰限制。
* 依赖模块与冲突标签。

契约名称、描述和效果详情只允许签署玩家、权威服务器与必要审计角色查看，不能同步给其他玩家。

### 9.1 配置校验

契约资源加载时应检查：

* 契约标识全局唯一。
* 正面与负面效果均存在且能够由对应系统执行。
* 延迟回合为正整数，并符合契约强度建议范围。
* 阶段型触发拥有最晚生效时间。
* 基础权重不小于 `0`。
* 模块、身份、种族和信仰引用合法。
* 正面效果不会直接完成使命或产生胜利。
* 负面效果不会被正面效果自动抵消。
* 正负效果不会形成无限循环。
* 公开数据结构不会包含私有契约字段。
* 至少存在一个触发来源可以合法提供该契约。

### 9.2 新增契约流程

新增契约时，应按照以下流程设计：

```text
确定核心交易主题
      │
      ▼
设计永久正面效果
      │
      ▼
设计跨系统永久代价
      │
      ▼
确定延迟与最晚生效时间
      │
      ▼
配置触发场景与候选限制
      │
      ▼
检查胜利、循环与保密边界
      │
      ▼
完成数值测试与组合测试
```

新增契约原则上只增加资源配置和已有标准效果组合，不为单份契约编写只能使用一次的专属流程。

## 10. 设计总结

神鬼契约是一种低频、隐藏、不可逆的长期交易机制。

其最终规则为：

1. 每名玩家每局最多签署一份神鬼契约。
2. 契约只能通过特殊场景、事件或状态触发。
3. 签署前可以拒绝，拒绝不产生任何惩罚。
4. 同一次机会只能查看一份契约，不能刷新或重抽。
5. 签署后不可撤销、替换、解除、转让或再次签署。
6. 神鬼契约不存在履约、违约与周期支付机制。
7. 永久正面效果在签署后立即生效。
8. 永久负面效果在若干自身回合或指定阶段后自动生效。
9. 阶段型负面效果必须设置最晚生效时间。
10. 死亡、轮回、转职和断线不能暂停或重置契约。
11. 负面效果生效后，正面效果继续保留。
12. 正面与负面效果共同持续至本局结束。
13. 契约存在、签署过程、效果来源和生效时间在对局中完全保密。
14. 契约应以规则与机制变化为主，避免全部设计为简单数值增减。
15. 契约可以改变玩家的获胜路线，但不能直接保证胜利。

神鬼契约的核心不是完成任务，也不是承担违约风险，而是：

**玩家在签署的一刻便已经接受全部结果。力量立即到来，代价只是尚未到来。**
