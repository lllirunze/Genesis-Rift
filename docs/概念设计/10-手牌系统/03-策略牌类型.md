# 《开天辟地之大地的裂变》策略牌类型

## 1. 概述

为了便于管理与扩展，游戏中的策略牌按照其主要用途划分为不同类型。

每种类型对应不同的使用场景，但所有策略牌均遵循统一的使用规则：除策略牌自身存在特殊说明外，玩家可以在满足使用条件时，于对应行动或效果最终结算前的响应窗口中使用策略牌。

不同类型之间不存在绝对的强弱关系，而是侧重于解决不同问题。玩家可以根据自身玩法、当前手牌和局势变化，灵活选择保留与使用。

当前策略牌分为六种类型：

| 类型 | 英文名 | 主要用途 |
| --- | --- | --- |
| 战斗策略牌 | Combat | 干预攻击、防御、恢复、控制及其他战斗结算。 |
| 行动策略牌 | Action | 影响地图移动、主动探索和地图交互。 |
| 事件策略牌 | Event | 干预事件、命运及其他系统判定结果。 |
| 干扰策略牌 | Trick | 阻碍其他玩家或临时改变公共环境。 |
| 生存策略牌 | Survival | 应对天气、危险地形和环境灾害。 |
| 传说策略牌 | Legend | 承载极其稀有、足以改变重要局势的特殊效果。 |

### 1.1 类型与品质的区别

类型用于说明策略牌主要解决什么问题，品质用于说明策略牌的稀有程度、获取难度和整体价值。

通常情况下，两者相互独立。

例如：

* 战斗策略牌可以是普通、优秀、稀有或史诗品质
* 行动策略牌可以是普通、优秀、稀有或史诗品质
* 同一类型内部可以存在不同品质和不同强度的策略牌

传说策略牌属于特殊情况。

为了避免“传说品质”与“传说类型”产生两套互相冲突的含义，本项目采用以下统一规则：

* 所有传说品质策略牌统一归入传说类型
* 传说类型策略牌的品质必须为传说
* 传说策略牌不再同时登记为战斗、行动、事件、干扰或生存类型
* 传说策略牌适用的具体场景通过使用条件和响应对象表达

因此，一张用于战斗的传说策略牌，其类型仍然是“传说”，但应在使用条件和响应对象中明确其战斗场景。

### 1.2 类型判定原则

普通至史诗品质策略牌应根据核心效果判定所属类型。

当一张策略牌似乎同时符合多个类型时，应判断其主要解决的问题：

```text
是否为传说品质？
├── 是：传说策略牌
└── 否：继续判断核心用途
    ├── 干预战斗结算：战斗策略牌
    ├── 主动移动或探索：行动策略牌
    ├── 干预事件或命运：事件策略牌
    ├── 阻碍玩家或公共环境：干扰策略牌
    └── 应对环境危险：生存策略牌
```

类型由核心效果决定，不根据名称、获取地点或牌面插图临时判断。

## 2. 战斗策略牌（Combat）

战斗策略牌主要用于战斗过程中，可以强化自身、保护目标、削弱敌人或改变当前战斗局势。

此类策略牌通常围绕以下内容展开：

* 攻击与伤害
* 命中与闪避
* 暴击与穿透
* 物理防御与法术抗性
* 生命与灵力恢复
* 护盾
* 控制与状态
* 攻击目标或伤害类型变化

### 2.1 使用场景

战斗策略牌通常响应：

* 一次攻击声明
* 一次命中判定
* 一次伤害结算
* 一次治疗或恢复
* 一个战斗状态
* 一项战斗技能
* 另一张战斗相关策略牌

少量战斗策略牌可以在使用者自己的行动阶段主动使用，但必须在牌面中明确说明。

### 2.2 设计边界

战斗策略牌用于提供临时战术选择，不应成为角色稳定输出与生存能力的主要来源。

战斗策略牌原则上不得：

* 永久提高攻击、防御或生命属性
* 无条件消灭完整状态的玩家或 Boss
* 绕过命中、伤害和状态系统直接书写最终结果
* 形成无法结束的反击或连击循环
* 在没有明确响应对象时随意使用

### 2.3 示例策略牌

| 名称 | 设计方向 |
| --- | --- |
| 精准一击 | 提高一次攻击的命中稳定性。 |
| 铁壁 | 强化一次防御或降低一次伤害。 |
| 急救包 | 在合法时机恢复一定生命值。 |
| 连击 | 满足条件后追加一次有限的战斗效果。 |
| 破甲弹 | 临时提高一次攻击的护甲穿透能力。 |

示例只用于说明类型方向，不代表具体牌面数值已经确定。

## 3. 行动策略牌（Action）

行动策略牌主要影响玩家在地图上的移动、主动探索和地图交互能力。

此类策略牌能够帮助玩家：

* 提高一次移动效率
* 跨越特殊地形
* 返回已开放地点
* 发现隐藏区域
* 提高视野或感知
* 使用特殊地图工具
* 改变一次探索方式

### 3.1 使用场景

行动策略牌通常在以下时机使用：

* 自己的移动开始前
* 确定移动路径时
* 支付地形移动消耗前
* 进行探索判定前
* 与地图机关或特殊地点交互时
* 进入或离开指定区域时

行动策略牌可以是主动使用，也可以响应一次尚未完成的移动或探索效果，具体方式由牌面说明。

### 3.2 设计边界

行动策略牌强调主动规划与探索效率，不负责长期抵抗环境伤害。

行动策略牌原则上不得：

* 永久提高移动力、移动速度、视野或感知
* 无视所有地图边界和通行规则
* 未经地图系统校验直接传送至任意地块
* 自动完成整个区域的探索内容
* 直接揭示所有隐藏地点或任务答案

### 3.3 示例策略牌

| 名称 | 设计方向 |
| --- | --- |
| 疾跑 | 临时提高一次移动能力。 |
| 回城卷轴 | 返回一个满足条件的已开放地点。 |
| 登山索 | 帮助跨越指定高差或山地障碍。 |
| 火把 | 在有限时间内改善黑暗环境中的探索能力。 |
| 寻宝罗盘 | 协助发现附近的宝箱或探索目标。 |

---

## 4. 事件策略牌（Event）

事件策略牌主要用于影响随机事件、命运事件或其他特殊机制的结算结果。

此类策略牌通常不会直接提高战斗能力，而是帮助玩家：

* 降低事件带来的风险
* 重新进行一次事件判定
* 调整一个尚未结算的事件选项
* 提高事件奖励
* 避免或替换部分事件惩罚
* 干预命运相关结果

### 4.1 使用场景

事件策略牌通常响应：

* 事件被触发
* 事件选项被确认
* 随机结果生成前
* 随机结果公开后、最终结算前
* 命运判定
* 事件奖励或惩罚结算

每张事件策略牌必须明确其使用时机位于随机结果生成前还是结果公开后，不能在看到结果后使用一张只允许提前使用的策略牌。

### 4.2 设计边界

事件策略牌用于干预已有事件，不自行创建一套独立事件系统。

事件策略牌原则上不得：

* 在事件结算完成后追溯修改结果
* 无条件将所有失败结果改为最高奖励
* 永久提高幸运值或其他角色属性
* 使用未公开权重的随机效果
* 绕过任务系统直接完成任务

### 4.3 示例策略牌

| 名称 | 设计方向 |
| --- | --- |
| 命运逆转 | 重新处理一次尚未完成的命运判定。 |
| 好运降临 | 改善一次事件奖励或结果倾向。 |
| 避祸符 | 降低一次事件惩罚。 |
| 双倍奖励 | 在满足条件时提高一次事件奖励。 |
| 幸运骰子 | 允许重新进行一次指定的随机判定。 |

---

## 5. 干扰策略牌（Trick）

干扰策略牌主要作用于其他玩家或公共环境，用于制造一定程度的阻碍、误导或临时变化。

此类策略牌应以增加玩家之间的博弈性为目的，而不是直接淘汰玩家。

常见设计方向包括：

* 降低其他玩家一次行动的效率
* 临时限制一条路径
* 干扰视野或信息获取
* 转移少量资源
* 改变一次目标选择
* 制造能够被解除的公共障碍
* 触发娱乐性恶作剧

### 5.1 使用场景

干扰策略牌通常响应：

* 其他玩家开始移动或行动
* 其他玩家获得资源
* 其他玩家进行探索或交易
* 一个公共地图效果即将结算
* 其他玩家使用策略牌

部分干扰策略牌可以在自己的行动阶段主动使用，但必须提供明确目标和持续时间。

### 5.2 设计边界

干扰策略牌的效果应控制在合理范围内，为受影响玩家保留反制、恢复或继续参与游戏的机会。

干扰策略牌原则上不得：

* 直接淘汰玩家
* 长期剥夺玩家的完整回合
* 永久夺取身份、转职、基础属性或任务进度
* 未经规则允许夺取已穿戴装备
* 无限封锁唯一通路或关键任务地点
* 通过连续控制使同一玩家长期无法行动

### 5.3 示例策略牌

| 名称 | 设计方向 |
| --- | --- |
| 绊脚石 | 降低目标一次移动的效率。 |
| 烟雾弹 | 临时影响指定区域的视野或命中。 |
| 偷窃 | 在明确范围内转移少量可被偷取的资源。 |
| 封路 | 临时限制一条合法路径。 |
| 恶作剧 | 产生轻度、可恢复的娱乐性干扰。 |

---

## 6. 生存策略牌（Survival）

生存策略牌主要用于应对天气、环境和地图中的危险情况。

随着游戏推进，玩家可能遭遇极端天气、危险地形、特殊区域或世界灾害。此类策略牌能够帮助玩家降低环境带来的负面影响，提高生存能力。

常见设计方向包括：

* 抵抗寒冷、高温或暴雨
* 降低毒雾、污染或异常环境影响
* 应对水域、风暴或危险地形
* 提供临时休整与庇护
* 避免一次环境伤害
* 延缓环境状态的恶化

### 6.1 使用场景

生存策略牌通常响应：

* 天气效果即将生效
* 玩家进入危险地形或区域
* 环境伤害即将结算
* 环境状态即将被施加
* 休整或露营行为
* 地图灾害或裂变环境效果

### 6.2 与行动策略牌的区别

行动策略牌主要帮助玩家主动移动、探索和发现内容；生存策略牌主要帮助玩家承受或规避环境风险。

例如：

| 效果 | 所属类型 |
| --- | --- |
| 跨越一处山地障碍 | 行动策略牌 |
| 降低雪山区域造成的寒冷影响 | 生存策略牌 |
| 发现隐藏水道入口 | 行动策略牌 |
| 避免一次溺水伤害 | 生存策略牌 |

### 6.3 设计边界

生存策略牌原则上不得：

* 永久免疫所有天气或环境效果
* 同时解决移动、战斗、探索和环境中的全部问题
* 取代护甲、鞋子和特殊装备的长期环境适应价值
* 无条件取消全局裂变或世界灾害

### 6.4 示例策略牌

| 名称 | 设计方向 |
| --- | --- |
| 帐篷 | 提供一次有限的休整或临时庇护。 |
| 雨衣 | 降低暴雨带来的部分负面影响。 |
| 防毒面具 | 抵抗一次毒雾或污染环境效果。 |
| 保温毯 | 缓解寒冷环境造成的影响。 |
| 救生圈 | 应对一次水域相关危险。 |

## 7. 传说策略牌（Legend）

传说策略牌属于极其稀有的特殊策略牌，通常只能通过高难度挑战、世界事件、隐藏内容或特殊奖励获得。

此类策略牌拥有远高于普通策略牌的战略价值，能够在关键时刻改变重要局势，但获取数量十分有限，不应成为玩家稳定依赖的资源。

传说策略牌可以涉及战斗、行动、事件、干扰或生存场景，但统一归入传说类型，并通过使用条件和响应对象说明具体场景。

### 7.1 获取方式

传说策略牌可以来自：

* 高难度 Boss 或副本
* 世界级事件
* 隐藏任务与隐藏区域
* 创界山相关内容
* 裂变阶段的特殊奖励
* 极少数身份、使命或上帝事件

传说策略牌不进入普通商店和常规奖励牌池，也不应通过稳定循环重复获得。

### 7.2 设计要求

传说策略牌应当：

* 拥有明确且独特的战略用途
* 能够影响重要局势，但仍保留合法响应空间
* 具有严格的使用条件或时机
* 使用后默认进入弃牌堆
* 遵守已有系统的最终边界
* 保持极低且可控的获取数量

传说策略牌的强度不能来自含糊文本、无条件胜利或不可响应。

### 7.3 设计边界

传说策略牌原则上不得：

* 直接宣布使用者获得最终胜利
* 永久删除其他玩家的角色成长
* 无条件取消所有世界规则
* 在结算完成后无限追溯游戏状态
* 绕过上帝裁定、终局规则和系统边界
* 通过稳定来源反复获得

### 7.4 示例策略牌

| 名称 | 设计方向 |
| --- | --- |
| 神迹 | 在严格条件下扭转一次重大危机。 |
| 创世之门 | 在世界规则允许的范围内开启一次特殊通路。 |
| 裂变干涉 | 干预一次尚未完成的裂变效果。 |
| 凤凰之羽 | 在明确限制下提供一次重要的生存机会。 |
| 时光回溯 | 在严格响应时机内，将一个尚未完成的行动重置至其声明阶段。 |

以上名称和设计方向只用于说明传说策略牌的定位，不代表其具体效果已经确定。

## 8. 类型边界总结

五种功能类型之间容易出现部分效果重叠，最终分类应以核心用途为准。

| 容易混淆的类型 | 判定方式 |
| --- | --- |
| 战斗与干扰 | 主要干预战斗结算时属于战斗；主要阻碍玩家非战斗行动时属于干扰。 |
| 行动与生存 | 主动提高移动或探索效率时属于行动；应对环境危险时属于生存。 |
| 事件与干扰 | 修改系统事件或命运结果时属于事件；直接阻碍玩家或公共环境时属于干扰。 |
| 事件与生存 | 干预事件选项或奖励时属于事件；抵抗事件产生的环境危险时属于生存。 |
| 功能类型与传说 | 传说品质统一归入传说类型，具体功能通过使用条件与响应对象表达。 |

一张策略牌只能拥有一个主类型。

如果效果确实跨越多个场景，应选择对其核心效果最重要的类型，并通过使用条件与响应对象补充其他合法场景，而不是同时登记多个类型。

## 9. 后续扩展

以上六类策略牌构成游戏手牌系统的基础分类框架。

随着游戏内容不断完善，可以在保持现有分类体系不变的前提下，为各类型持续补充新的策略牌，使手牌系统保持丰富性与可扩展性，而无需频繁新增策略牌分类。

新增策略牌时，应先按照 [《02-策略牌设计规范》](02-策略牌设计规范.md) 完成模板、品质、数值、命名和关键字设计，再根据本章节的类型判定规则确定唯一主类型。

只有当一种新机制无法被任何现有类型合理表达，并且会被大量策略牌长期重复使用时，才应考虑扩展类型枚举。单张特殊策略牌不能成为新增类型的理由。
