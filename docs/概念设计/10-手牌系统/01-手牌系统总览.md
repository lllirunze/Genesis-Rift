# 《开天辟地之大地的裂变》手牌系统总览

## 1. 系统定位

手牌系统是《开天辟地之大地的裂变》中的辅助策略系统，用于丰富玩家在战斗、探索和事件中的临场决策能力。

与角色等级、身份、转职和装备等长期成长系统不同，手牌属于玩家在游戏过程中获得的一次性策略资源。玩家需要根据当前局势合理保留和使用手牌，以获得额外的战术优势，但手牌不会替代角色本身的成长。

整个游戏仍然以角色培养、地图探索、装备收集和任务推进作为主要玩法，手牌系统则作为其中的重要补充，提高游戏的策略性与趣味性。

手牌系统的核心定位可以概括为：

**为玩家提供稀缺且能够改变局势的临场选择，而不是建立持续抽牌与出牌的主循环。**

本项目统一将玩家可以获得、持有并在合法时机使用的此类牌称为“手牌”。

手牌根据当前所在区域进行管理：

| 概念 | 说明 |
| --- | --- |
| 牌库 | 所有玩家共用的待抽取手牌集合。 |
| 玩家手中 | 玩家当前持有、尚未使用的手牌区域，其中的牌占用手牌数量上限。 |
| 弃牌堆 | 所有玩家共用的已使用或主动弃置手牌集合。 |

世界牌、身份牌、种族牌、血牌及其他角色信息牌不属于手牌，不进入手牌牌库，也不占用手牌数量上限。

---

## 2. 设计理念

《开天辟地之大地的裂变》的手牌系统不同于传统卡牌游戏。

玩家不会在每个回合固定抽取手牌，手牌也不是一种稳定且持续产出的资源。相反，手牌更像是在冒险旅途中获得的特殊奖励，通常只能通过宝箱、事件、命运、NPC 奖励、副本、Boss、商店和特殊地点等特定方式获得。

正因如此，手牌具有一定的稀缺性。玩家需要认真权衡每一张手牌的使用时机，而不是为了维持资源循环而频繁消耗。

这一设计旨在弱化传统卡牌游戏“抽牌—出牌”的核心循环，使玩家的成长始终围绕角色、装备、等级和探索展开，而手牌仅作为关键时刻改变局势的重要辅助手段。

为了尊重原剧中存在初始手牌的候选规则，玩家可以在对局开始时获得一组初始手牌。初始手牌属于开局资源，不代表后续每回合都会固定补充。

每位玩家在对局开始时获得 `2` 张初始手牌。初始手牌统一从共享牌库中抽取，不代表后续每回合都会固定补充。

## 3. 基本规则

### 3.1 手牌持有

玩家获得手牌后，该牌进入玩家手中。

玩家手中的牌属于玩家的私有信息。除非牌面、技能、事件或其他规则明确要求公开，其他玩家只能看到该玩家当前的手牌数量，不能查看具体内容。

玩家使用或弃置手牌时，该牌离开玩家手中，并按照结算规则进入共享弃牌堆；少量特殊手牌可以在结算后返回原使用者手中。

### 3.2 手牌数量上限

玩家的手牌受到手牌数量上限限制。

当前建议默认手牌上限为 `6` 张，并允许身份、装备、状态或特殊规则进行调整。

当一次获取使玩家的手牌超过上限时，应先完成本次获取，再由玩家立即弃置多余手牌，直至手牌数量不超过当前上限。

被弃置的手牌进入弃牌堆。玩家不能通过暂缓选择、拆分获取或将结算停留在中间状态长期持有超出上限的手牌。

### 3.3 使用时机

手牌的使用时机统一分为主动使用（`active`）和响应使用（`response`）两种。

主动手牌由玩家在满足条件的合法行动阶段主动声明，不要求当前存在等待结算的响应对象。主动手牌声明后，仍需按照回合系统规则开放响应窗口，不能直接跳过其他玩家的响应。

响应手牌只能在某个行动或效果最终结算前的响应窗口中使用，不受当前是否为自己回合限制。

手牌必须明确其响应对象，例如：

* 一次攻击
* 一次技能
* 一次移动
* 一次探索
* 一次交易
* 一个事件结果
* 一个天气或地图效果
* 另一张手牌

不存在合法响应对象时，不能使用响应手牌，也不能仅为了清空手牌而打出该牌。

如果某张主动手牌只能在回合开始、回合结束或其他具体阶段使用，应通过使用条件进行限制，不再使用含义模糊的特殊时机类型。

### 3.4 响应与结算

手牌使用遵循《03-回合结构》中定义的响应窗口和响应链规则。

基本流程如下：

```text
行动或效果被声明
↓
系统检查是否开启响应窗口
↓
符合条件的玩家依次选择响应或放弃
↓
如有玩家使用手牌，则继续处理新的响应
↓
所有玩家连续放弃响应
↓
关闭响应窗口
↓
按照响应链顺序完成最终结算
```

当任意玩家使用新的手牌或发动其他响应效果时，本次响应链继续进行，其他符合条件的玩家重新获得响应机会。

当所有符合条件的玩家连续放弃响应后，响应窗口立即关闭并开始最终结算。窗口关闭后，不得再针对同一结算补打手牌。

手牌不能通过无限互相响应拖延结算。响应深度、重复状态和超时处理统一由回合系统管理。

### 3.5 使用与弃置

手牌通常为一次性消耗品。

手牌被合法使用并进入响应链后，无论其效果最终生效、被抵消或被其他规则改变，结算完成后均进入共享弃牌堆，除非该牌自身明确说明返回原使用者手中。

如果手牌在使用合法性检查阶段即被判定为无法使用，则本次使用不成立，该牌仍然保留在玩家手牌中。

只有极少数特殊手牌可以拥有额外去向规则，并且必须在牌面文本中明确说明。

### 3.6 共享牌库与弃牌堆

牌库与弃牌堆均为所有玩家共用的公共区域，不属于任何单独玩家。

牌库中的所有手牌共用一套从 `1` 开始的全局数字编号，每张牌只拥有一个唯一编号。

牌库中可以存在多张名称与功能完全相同的手牌。例如三张 `sprint` 可以依次使用编号 `1`、`2`、`3`；后续新增三张 `berserk` 时，编号继续顺延为 `4`、`5`、`6`。功能相同的手牌直接复制名称、描述、品质、类型、使用规则和效果配置，不再额外划分功能定义编号与运行时实例编号。

手牌配置中的名称统一使用英文小驼峰命名法（camelCase），用于程序检索、日志和调试。玩家看到的中文名称直接绘制在牌面资源图片中，不写入 `name` 字段。

手牌编号一旦进入正式配置便保持稳定。新增手牌只能从当前最大编号继续递增，不复用已经删除或停用的历史编号。

牌库在对局开始前统一洗牌。玩家通过初始发牌、奖励或其他合法效果获得手牌时，均从共享牌库中抽取对应实体牌。

执行单张抽取时，若牌库已经耗尽，则将共享弃牌堆中的全部手牌重新洗牌并放回牌库，然后继续抽取。

执行一次抽取多张手牌的效果时，系统应在抽取前检查当前牌库余量。若剩余手牌少于本次需要抽取的数量，则先将共享弃牌堆重新洗牌，并将洗牌后的手牌追加至当前牌库底部，最后再统一执行本次抽取。当前牌库中尚未抽取的手牌保持原有顺序并优先被抽取，不会与弃牌堆重新混合。

若牌库与弃牌堆中的手牌总数仍然少于本次需要抽取的数量，则玩家获得全部可用手牌，未满足的数量不再补发。若两个区域同时为空，则本次抽取无法获得手牌。

洗牌必须由统一随机系统中的独立牌库随机流执行，不允许手牌系统自行创建随机对象。相同主随机种子与相同牌库状态应产生可复现的洗牌结果，以支持联机同步、回放与问题定位。

## 4. 品质与获取

### 4.1 品质体系

手牌按照稀有程度划分为五个品质等级：

| 品质 | 特点 |
| --- | --- |
| 普通 | 最常见，获取相对容易，提供基础的策略效果。 |
| 优秀 | 相较普通拥有更高的战术价值，获取方式较为稳定。 |
| 稀有 | 获取难度较高，通常拥有较强的功能性或特殊机制。 |
| 史诗 | 能够明显改变局部局势，多作为高级奖励出现。 |
| 传说 | 极其稀有，通常拥有能够影响整场游戏的重要能力。 |

品质主要表示手牌的稀有程度、机制影响范围和获取难度，不代表高品质手牌可以无视响应、使用条件或系统边界。

即使是传说品质手牌，也必须拥有明确的使用时机、作用目标和结算方式。

通用品质体系中预留“神话”层级，但该品质仅作为未来扩展项存在。当前版本不定义神话手牌的颜色、获取方式与效果规则，也不允许将其加入任何牌库；传说仍然是当前手牌体系中的最高品质。

### 4.2 获取方式

手牌不会通过固定回合抽取获得，而是主要来源于探索和游戏事件中的奖励。

常见获取方式包括：

* 对局开始时获得初始手牌
* 开启宝箱
* 完成事件或命运判定
* 完成任务
* 探索特殊地点
* 通关副本
* 击败 Boss 或稀有敌人
* 获得 NPC 奖励
* 在商店中购买
* 与其他玩家交易
* 通过技能、装备或特殊规则获得

所有玩家与获取来源共用同一个牌库。不同奖励来源可以通过抽取条件、候选类型或其他配置影响本次可获得的手牌，但不会为玩家建立私有牌库。

例如：

* 遗迹宝箱更容易出现探索与知识类手牌
* Boss 奖励更容易出现战斗与逆转类手牌
* 商店提供相对稳定但价格明确的常规手牌
* 裂变区域可能出现效果强大但使用条件特殊的手牌

所有“从牌库抽取手牌”的效果都必须拥有明确来源。此类抽取属于一次具体奖励或效果，不构成每回合自动执行的固定摸牌规则。

## 5. 系统联动

作为游戏中的辅助策略系统，手牌可以与多个模块产生联动。

| 关联系统 | 联动内容 |
| --- | --- |
| 回合系统 | 管理手牌的使用时机、响应顺序、响应链和最终结算。 |
| 战斗系统 | 提供攻击、防御、伤害、状态和目标变化等响应场景。 |
| 地图系统 | 提供宝箱、特殊地点、探索奖励和地图效果响应。 |
| 天气与昼夜系统 | 提供限定使用条件、环境效果和临时策略机会。 |
| 事件与命运系统 | 提供手牌来源，以及可被干预的事件结果。 |
| 装备系统 | 提供手牌上限、手牌获取或特定类型联动效果。 |
| 背包与物品系统 | 不管理玩家手中的牌；只有明确转化为普通物品的特殊内容才进入背包。 |
| NPC 系统 | 提供手牌奖励、商店、交换和特殊抽取条件。 |
| 经济系统 | 管理手牌价格、购买、出售和玩家交易。 |
| 任务系统 | 提供手牌奖励、使用目标或任务条件。 |

不同类型的手牌能够在不同场景下发挥作用，使玩家面对同一局势时拥有更多解决方案，也让每一次探索具有更多未知与惊喜。

手牌系统只负责手牌的持有、使用、弃置和基础规则，不重复实现战斗、地图、天气、经济或事件系统的具体业务逻辑。

## 6. 设计原则

手牌系统遵循以下原则：

### 6.1 辅助定位原则

手牌用于补充角色在特定局势下的选择，不替代角色、装备、等级和任务形成的长期成长。

### 6.2 非固定产出原则

玩家每回合不会自动获得手牌。所有新增手牌都必须来自明确的初始配置、奖励、交易或特殊效果。

### 6.3 稀缺决策原则

手牌应保持一定稀缺性，使保留、使用和交易每张手牌都具有决策价值。

### 6.4 响应统一原则

手牌统一进入回合系统的响应窗口和响应链，不为单张牌创建独立的即时结算流程。

### 6.5 文本明确原则

每张手牌必须明确使用时机、使用条件、作用目标、具体效果和结算去向。

### 6.6 一次消耗原则

手牌默认在使用后进入共享弃牌堆，结算后返回原使用者手中必须作为少量特殊规则明确配置。

### 6.7 系统联动原则

手牌应优先调用已有系统产生效果，不为单张牌重复实现战斗、地图、经济或状态规则。

## 7. 后续实现事项

当前版本已经确定手牌、共享牌库与共享弃牌堆的基础职责，以下内容留待后续结合其他系统继续实现：

* 建立统一的手牌效果执行器，并校验 `effectId` 对应效果是否存在
* 结合回合结构与响应窗口，共同确定手牌使用条件的判断方式
* 当后续玩法确有需要时，再评估移出游戏或放回牌库等新结算去向

上述事项属于后续实现范围，不改变本章节已经确定的共享牌库、共享弃牌堆、全局数字编号和初始手牌规则。
