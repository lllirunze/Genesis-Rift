# 《开天辟地之大地的裂变》手牌系统总览

## 1. 系统定位

手牌系统是《开天辟地之大地的裂变》中的辅助策略系统，用于丰富玩家在战斗、探索和事件中的临场决策能力。

与角色等级、身份、转职和装备等长期成长系统不同，策略牌属于玩家在游戏过程中获得的一次性策略资源。玩家需要根据当前局势合理保留和使用策略牌，以获得额外的战术优势，但策略牌不会替代角色本身的成长。

整个游戏仍然以角色培养、地图探索、装备收集和任务推进作为主要玩法，手牌系统则作为其中的重要补充，提高游戏的策略性与趣味性。

手牌系统的核心定位可以概括为：

**为玩家提供稀缺且能够改变局势的临场选择，而不是建立持续抽牌与出牌的主循环。**

本系统中的“手牌”与“策略牌”含义不同：

| 概念 | 说明 |
| --- | --- |
| 手牌 | 玩家当前持有、尚未使用的策略牌集合。 |
| 策略牌 | 可以进入手牌，并在满足条件时使用的一次性策略资源。 |

世界牌、身份牌、种族牌、血牌及其他角色信息牌不属于策略牌，也不占用策略牌的手牌上限。

---

## 2. 设计理念

《开天辟地之大地的裂变》的手牌系统不同于传统卡牌游戏。

玩家不会在每个回合固定抽取策略牌，策略牌也不是一种稳定且持续产出的资源。相反，策略牌更像是在冒险旅途中获得的特殊奖励，通常只能通过宝箱、事件、命运、NPC 奖励、副本、Boss、商店和特殊地点等特定方式获得。

正因如此，策略牌具有一定的稀缺性。玩家需要认真权衡每一张策略牌的使用时机，而不是为了维持资源循环而频繁消耗。

这一设计旨在弱化传统卡牌游戏“抽牌—出牌”的核心循环，使玩家的成长始终围绕角色、装备、等级和探索展开，而策略牌仅作为关键时刻改变局势的重要辅助手段。

为了尊重原剧中存在初始手牌的候选规则，玩家可以在对局开始时获得一组初始策略牌。初始手牌属于开局资源，不代表后续每回合都会固定补充。

当前建议初始手牌数量为 `6` 张，并作为可配置参数保留。具体初始牌池和发放方式将在后续策略牌配置中确定。

---

## 3. 基本规则

### 3.1 手牌持有

策略牌默认存在于玩家的手牌中。

手牌属于玩家的私有信息。除非策略牌、技能、事件或其他规则明确要求公开，其他玩家只能看到该玩家当前的手牌数量，不能查看具体内容。

玩家获得策略牌时，该牌进入其手牌；玩家使用或弃置策略牌时，该牌离开其手牌。

### 3.2 手牌数量上限

玩家的策略牌受到手牌数量上限限制。

当前建议默认手牌上限为 `6` 张，并允许身份、装备、状态或特殊规则进行调整。

当一次获取使玩家的手牌超过上限时，应先完成本次获取，再由玩家立即弃置多余策略牌，直至手牌数量不超过当前上限。

被弃置的策略牌进入弃牌堆。玩家不能通过暂缓选择、拆分获取或将结算停留在中间状态长期持有超出上限的手牌。

### 3.3 使用时机

除策略牌自身说明外，所有策略牌均可在满足使用条件时，于对应效果最终结算前的响应窗口中使用，不受当前是否为自己回合限制。

策略牌必须明确其响应对象，例如：

* 一次攻击
* 一次技能
* 一次移动
* 一次探索
* 一次交易
* 一个事件结果
* 一个天气或地图效果
* 另一张策略牌

不存在合法响应对象时，不能仅为了清空手牌而使用策略牌。

如果某张策略牌只能在自己的行动阶段、回合开始、回合结束或其他特殊时机使用，必须由该牌文本明确说明。

### 3.4 响应与结算

策略牌使用遵循《03-回合结构》中定义的响应窗口和响应链规则。

基本流程如下：

```text
行动或效果被声明
↓
系统检查是否开启响应窗口
↓
符合条件的玩家依次选择响应或放弃
↓
如有玩家使用策略牌，则继续处理新的响应
↓
所有玩家连续放弃响应
↓
关闭响应窗口
↓
按照响应链顺序完成最终结算
```

当任意玩家使用新的策略牌或发动其他响应效果时，本次响应链继续进行，其他符合条件的玩家重新获得响应机会。

当所有符合条件的玩家连续放弃响应后，响应窗口立即关闭并开始最终结算。窗口关闭后，不得再针对同一结算补打策略牌。

策略牌不能通过无限互相响应拖延结算。响应深度、重复状态和超时处理统一由回合系统管理。

### 3.5 使用与弃置

策略牌通常为一次性消耗品。

策略牌被合法使用并进入响应链后，无论其效果最终生效、被抵消或被其他规则改变，结算完成后均进入弃牌堆，除非该牌自身明确说明返回手牌、转移所有权或进入其他区域。

如果策略牌在使用合法性检查阶段即被判定为无法使用，则本次使用不成立，该牌仍然保留在玩家手牌中。

只有极少数特殊策略牌可以拥有额外去向规则，并且必须在牌面文本中明确说明。

## 4. 品质与获取

### 4.1 品质体系

策略牌按照稀有程度划分为五个品质等级：

| 品质 | 特点 |
| --- | --- |
| 普通 | 最常见，获取相对容易，提供基础的策略效果。 |
| 优秀 | 相较普通拥有更高的战术价值，获取方式较为稳定。 |
| 稀有 | 获取难度较高，通常拥有较强的功能性或特殊机制。 |
| 史诗 | 能够明显改变局部局势，多作为高级奖励出现。 |
| 传说 | 极其稀有，通常拥有能够影响整场游戏的重要能力。 |

品质主要表示策略牌的稀有程度、机制影响范围和获取难度，不代表高品质策略牌可以无视响应、使用条件或系统边界。

即使是传说品质策略牌，也必须拥有明确的使用时机、作用目标和结算方式。

通用品质体系中预留“神话”层级，但该品质仅作为未来扩展项存在。当前版本不定义神话策略牌的颜色、获取方式与效果规则，也不允许将其加入任何策略牌池；传说仍然是当前策略牌体系中的最高品质。

### 4.2 获取方式

策略牌不会通过固定回合抽取获得，而是主要来源于探索和游戏事件中的奖励。

常见获取方式包括：

* 对局开始时获得初始手牌
* 开启宝箱
* 完成事件或命运判定
* 完成任务
* 探索特殊地点
* 通关副本
* 击败 Boss 或稀有敌人
* 获得 NPC 奖励
* 在商店中购买
* 与其他玩家交易
* 通过技能、装备或特殊规则获得

不同来源可以配置不同的策略牌池，使玩家能够根据地图区域、事件类型和当前游戏阶段获得具有对应主题的策略牌。

例如：

* 遗迹宝箱更容易出现探索与知识类策略牌
* Boss 奖励更容易出现战斗与逆转类策略牌
* 商店提供相对稳定但价格明确的常规策略牌
* 裂变区域可能出现效果强大但使用条件特殊的策略牌

所有“抽取策略牌”的效果都必须拥有明确来源。此类抽取属于一次具体奖励或效果，不构成每回合自动执行的固定摸牌规则。

## 5. 系统联动

作为游戏中的辅助策略系统，策略牌可以与多个模块产生联动。

| 关联系统 | 联动内容 |
| --- | --- |
| 回合系统 | 管理策略牌的使用时机、响应顺序、响应链和最终结算。 |
| 战斗系统 | 提供攻击、防御、伤害、状态和目标变化等响应场景。 |
| 地图系统 | 提供宝箱、特殊地点、探索奖励和地图效果响应。 |
| 天气与昼夜系统 | 提供限定使用条件、环境效果和临时策略机会。 |
| 事件与命运系统 | 提供策略牌来源，以及可被干预的事件结果。 |
| 装备系统 | 提供手牌上限、策略牌获取或特定类型联动效果。 |
| 背包与物品系统 | 不管理手牌中的策略牌；只有明确转化为普通物品的特殊内容才进入背包。 |
| NPC 系统 | 提供奖励、商店、交换和特殊牌池。 |
| 经济系统 | 管理策略牌价格、购买、出售和玩家交易。 |
| 任务系统 | 提供策略牌奖励、使用目标或任务条件。 |

不同类型的策略牌能够在不同场景下发挥作用，使玩家面对同一局势时拥有更多解决方案，也让每一次探索具有更多未知与惊喜。

手牌系统只负责策略牌的持有、使用、弃置和基础规则，不重复实现战斗、地图、天气、经济或事件系统的具体业务逻辑。

## 6. 设计原则

手牌系统遵循以下原则：

### 6.1 辅助定位原则

策略牌用于补充角色在特定局势下的选择，不替代角色、装备、等级和任务形成的长期成长。

### 6.2 非固定产出原则

玩家每回合不会自动获得策略牌。所有新增策略牌都必须来自明确的初始配置、奖励、交易或特殊效果。

### 6.3 稀缺决策原则

策略牌应保持一定稀缺性，使保留、使用和交易每张策略牌都具有决策价值。

### 6.4 响应统一原则

策略牌统一进入回合系统的响应窗口和响应链，不为单张牌创建独立的即时结算流程。

### 6.5 文本明确原则

每张策略牌必须明确使用时机、使用条件、作用目标、具体效果和结算去向。

### 6.6 一次消耗原则

策略牌默认在使用后进入弃牌堆，返回手牌、重复使用或转移所有权必须作为少量特殊规则明确配置。

### 6.7 系统联动原则

策略牌应优先调用已有系统产生效果，不为单张牌重复实现战斗、地图、经济或状态规则。
