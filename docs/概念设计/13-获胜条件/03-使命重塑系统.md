# 《开天辟地之大地的裂变》使命重塑系统

## 1. 系统概述

使命重塑（Mission Reforge）是使命系统的重要补充机制。

在游戏过程中，由于地图变化、世界事件、其他玩家行为或自身发展方向的改变，玩家可能会发现部分使命的完成难度明显提高，或者不再符合当前的发展路线。

为了避免玩家因个别使命而长期陷入被动，本系统允许玩家消耗一定数量的元宝，重新规划自己的发展方向，将一个尚未完成的使命替换为新的同类型使命。

使命重塑不会直接完成使命，也不会改变五类使命的基本结构。它给予玩家的是一次重新选择路线的机会，而不是通过支付元宝购买使命进度或游戏胜利。

使命重塑分为两种形式：

| 重塑形式 | 触发方式 | 是否消耗元宝 | 是否占用次数 |
| --- | --- | --- | --- |
| 主动重塑 | 玩家根据自身发展方向主动申请。 | 是 | 是 |
| 自动转换 | 原使命因不可逆世界变化而客观无法完成。 | 否 | 否 |

两种形式均会生成同类型的新使命，但适用条件、资源消耗与设计目的不同，不能相互替代。

---

## 2. 设计目标

使命重塑系统主要用于解决以下问题：

* 避免个别使命因局势变化而变得过于困难。
* 为玩家提供有限的发展路线调整能力。
* 增强元宝在游戏中后期的持续价值。
* 保证不同局势下仍然存在合理的获胜机会。
* 避免玩家因为早期判断失误而失去整局游戏的竞争力。
* 在保留使命随机性的同时，提高游戏的容错率与策略性。

使命重塑属于有限且需要付出成本的战略资源，不鼓励玩家频繁使用。

该系统遵循以下核心原则：

**可以改变前进的道路，但不能购买已经抵达终点的结果。**

---

## 3. 重塑规则

玩家满足使用条件后，可以选择一个尚未完成的使命进行主动重塑。

重塑成功后：

* 原使命永久失效，不再记录后续进度。
* 系统从原使命所属类型的合法候选池中生成一个新使命。
* 新使命立即替代原使命，并向玩家本人展示。
* 已经完成的其他使命保持不变。
* 其余未完成使命的内容与进度保持不变。
* 本次重塑次数与元宝消耗被正式记录。

例如：

```text
原成长使命
将角色提升至指定等级
          │
          ▼
     执行使命重塑
          │
          ▼
新成长使命
打造一件史诗品质装备
```

两个使命均属于成长使命，因此替换不会改变玩家五类使命的整体结构。

重塑前，玩家只能看到本次重塑需要支付的元宝和将被替换的使命，不能提前查看新使命内容。新使命正式生成并替换原使命后，本次重塑不可撤销。

### 3.1 重塑流程

主动重塑按照以下流程进行：

```text
玩家选择未完成使命
          │
          ▼
检查操作时机、剩余次数与元宝
          │
          ▼
建立同类型合法候选池
          │
          ▼
排除原使命、重复使命与冲突使命
          │
          ▼
生成并验证新的候选使命
          │
          ▼
确认能够完成本次重塑
          │
          ▼
扣除元宝并增加已用次数
          │
          ▼
替换使命、计算进度并私下展示
```

使命生成、元宝扣除、次数增加与使命替换属于同一次完整操作。

如果任何条件检查失败，或系统无法生成合法的新使命，则整次重塑取消，不扣除元宝，不消耗次数，也不改变原使命。

### 3.2 隐藏信息

使命重塑属于玩家个人隐藏信息。

其他玩家可以看到玩家支付了对应服务费用时产生的公开行为，但默认不能查看：

* 被替换使命的具体内容。
* 新使命的具体内容。
* 新使命的当前进度。
* 玩家剩余的主动重塑次数。

若具体地点、NPC 或特殊规则明确要求公开部分信息，则以对应规则为准。

---

## 4. 使用条件

玩家主动重塑使命时，必须同时满足以下条件：

* 当前处于自己的回合开始阶段，并且尚未执行主要行动。
* 本回合尚未进行过主动使命重塑。
* 选择的使命尚未完成。
* 当前拥有剩余的主动重塑次数。
* 当前元宝不少于本次重塑所需费用。
* 原使命不存在正在进行且尚未结束的直接结算。
* 系统能够生成合法的同类型新使命。

任意条件不满足时，本次重塑不能开始。

玩家不能在以下时机主动重塑使命：

* 战斗、事件或其他响应链尚未完成时。
* 使命刚刚达到完成条件但尚未完成统一结算时。
* 已经进入待确认胜利状态时。
* 游戏结束或胜利结算开始后。

主动重塑不消耗主要行动，但每名玩家每回合最多进行一次，以避免连续刷新多个使命打断游戏节奏。

---

## 5. 重塑次数

每名玩家每局游戏拥有有限次数的主动使命重塑机会。

推荐默认规则如下：

| 项目 | 默认规则 |
| --- | --- |
| 每局主动重塑次数 | `2` 次 |
| 每回合主动重塑次数 | 最多 `1` 次 |
| 自动转换 | 不计入主动重塑次数 |

主动重塑成功后，已用次数增加 `1`。仅提出申请、取消确认或因条件不足导致操作失败时，不消耗次数。

次数耗尽后，玩家本局不能再次进行主动重塑，但使命因客观不可完成而触发的自动转换仍然正常执行。

默认次数由系统配置统一维护。后续特殊模式可以调整次数上限，但不能在对局进行过程中无提示地减少玩家已经获得的可用次数。

---

## 6. 元宝消耗

主动使命重塑需要支付一定数量的元宝。

为了提高连续重塑的决策成本，默认采用递增费用：

| 主动重塑次数 | 元宝消耗 | 设计定位 |
| --- | --- | --- |
| 第一次 | 较低 | 提供一次基础路线调整机会。 |
| 第二次 | 较高 | 作为局势不利时的最终调整手段。 |

具体数值由数值配置统一维护，不在本章节中规定。

本次费用只根据玩家已经成功完成的主动重塑次数确定。自动转换、失败申请和被系统取消的操作不会提高后续价格。

元宝结算遵循以下规则：

* 系统必须在操作前向玩家展示本次准确费用。
* 元宝持有数量不足时不能发起重塑，也不能使背包中的元宝总量变为负数。
* 只有合法新使命已经生成并通过检查后，系统才会正式扣除元宝。
* 扣除元宝、增加次数与替换使命必须同时成功或同时取消。
* 重塑成功后，玩家不能因为不满意新使命而要求退还元宝。

使命重塑费用属于系统服务消耗，支付后不会转移给其他玩家。

---

## 7. 同类型替换

使命重塑不会改变五类使命的整体结构。

新使命始终来自与原使命相同的使命池：

| 原使命类型 | 新使命来源 |
| --- | --- |
| 身份使命 | 当前身份或转职身份对应的身份使命池。 |
| 信仰使命 | 当前隐藏信仰对应的信仰使命池。 |
| 成长使命 | 成长使命池。 |
| 世界使命 | 符合当前地图与世界状态的世界使命池。 |
| 自由使命 | 通用自由使命池。 |

同类型替换保证玩家仍然需要面对不同系统所提供的发展目标，不能通过重塑将不擅长的使命类型全部转换为同一种玩法。

### 7.1 候选使命筛选

新使命按照《02-使命生成系统》的规则生成，并额外排除以下内容：

* 本次刚刚被替换的原使命。
* 与其他四个现有使命重复或冲突的使命。
* 当前世界状态下无法完成的使命。
* 依赖本局未启用模块的使命。
* 已经被该玩家通过主动重塑移除过的相同使命。
* 根据当前状态或历史记录已经满足全部完成条件的使命。

最后一项限制用于避免玩家通过反复重塑，直接抽取一个自己早已完成的目标并立即获得胜利记录。

如果合法候选使命不足，系统应按照使命生成系统的保底规则寻找同类型替代内容。仍然无法生成合法使命时，本次主动重塑失败，原使命保持不变。

### 7.2 难度约束

主动重塑允许玩家改变发展路线，但不保证新使命一定比原使命简单。

新使命应满足以下要求：

* 难度等级处于当前对局允许范围。
* 不会使五个使命的组合产生明显失衡。
* 与其他使命共同保留至少三种主要玩法方向。
* 不依赖其他玩家自愿配合才能完成。

系统可以根据当前局势适当调整候选权重，但不能承诺抽取到更低难度的使命。

### 7.3 进度计算

新使命生成后，应立即根据其进度口径计算当前进度。

进度处理分为以下情况：

| 进度类型 | 处理方式 |
| --- | --- |
| 当前状态 | 根据角色当前等级、装备、资源等合法状态重新计算。 |
| 本局累计记录 | 根据系统已经确认的历史记录重新计算。 |
| 重塑后行为 | 从新使命生效时开始记录，之前的行为不计入。 |
| 一次性条件 | 只响应新使命生效后发生的合法事件。 |

每项使命必须在配置中明确自己的进度类型，不能在重塑时临时决定是否追溯历史。

候选筛选会排除已经完全满足的使命，因此主动重塑不会在替换完成的同一时刻直接生成新的使命完成记录。已经合法获得但尚未达到目标值的历史进度，可以按照使命配置正常保留。

---

## 8. 自动使命转换

除玩家主动重塑外，系统还存在自动使命转换机制。

当发生以下不可逆变化，并导致某个未完成使命客观无法继续完成时，系统自动转换对应使命：

* 地图永久改变。
* 特殊区域永久消失或无法再次进入。
* 关键 NPC 永久死亡。
* 唯一目标被永久销毁且没有替代来源。
* 世界事件改变了使命成立所需的基础条件。
* 对应游戏模块因特殊规则永久失效。

自动转换遵循以下规则：

* 不消耗元宝。
* 不占用主动重塑次数。
* 不提高后续主动重塑价格。
* 不影响已经完成的使命。
* 新使命与原使命属于相同类型。
* 新使命的预计剩余难度不得明显高于原使命。
* 新使命重新接受可完成性、重复与冲突检查。

自动转换与主动重塑的主要区别如下：

| 对比项 | 主动重塑 | 自动转换 |
| --- | --- | --- |
| 发起者 | 玩家主动选择。 | 系统根据客观失效状态触发。 |
| 适用原因 | 路线改变、难度判断或个人策略。 | 原使命已经客观无法完成。 |
| 元宝消耗 | 消耗。 | 不消耗。 |
| 次数消耗 | 占用。 | 不占用。 |
| 操作时机 | 玩家回合开始阶段。 | 对应不可逆变化完成结算后。 |

临时封路、短期天气、当前战力不足、资源暂时缺少或玩家不愿继续，不属于客观无法完成，不能触发免费自动转换。

自动转换的进度继承与剩余难度保护，统一遵循《02-使命生成系统》中的世界变化规则。

---

## 9. 特殊规则

使命重塑遵循以下统一限制：

* 每次只能选择并替换一个使命。
* 已完成使命不能进行主动重塑或自动转换。
* 同一次重塑不会修改其他使命的内容与进度。
* 新使命不会立即重新生成本次刚被替换的使命。
* 主动重塑移除过的使命，本局默认不再向同一玩家生成。
* 新使命生成后立即按照自身进度类型计算进度。
* 重塑记录不会向其他玩家公开具体使命内容。
* 重塑不能撤销已经进入待确认状态的胜利。

### 9.1 与转职转换的关系

玩家完成转职后，尚未完成的身份使命可能按照转职路线升级。该过程属于身份使命转换，不属于主动重塑：

* 不消耗元宝。
* 不占用主动重塑次数。
* 不提高后续主动重塑费用。
* 按照转职映射与进度继承规则生成新身份使命。

转职转换完成后，玩家仍可在之后满足条件的回合中，对新的身份使命进行主动重塑。

### 9.2 与胜利结算的关系

使命重塑只能在胜利检查开始前执行。

已经完成的使命不能通过重塑取消，因此玩家不能主动降低自己的已完成使命数量，也不能借此延迟已经成立的胜利。

新使命必须通过正常游戏行为推进。主动重塑本身不视为使命完成行为，也不应直接满足个人胜利条件。

### 9.3 重塑记录

系统应记录每次使命变化，包括：

* 变化类型：主动重塑、自动转换或转职转换。
* 原使命标识与新使命标识。
* 发生时间与对应回合。
* 元宝消耗与重塑次数变化。
* 转换前后的使命进度。
* 自动转换的客观失效原因。

上述记录用于存档恢复、异常追踪与赛后复盘。游戏进行过程中，只向对应玩家展示其有权查看的内容。

---

## 10. 后续扩展

未来可以结合地图、NPC 与剧情扩展使命重塑玩法，例如：

* 玩家只能在命运神殿等指定地点进行使命重塑。
* 通过特殊 NPC 获得一次免费主动重塑机会。
* 使用稀有道具代替元宝完成重塑。
* 特殊世界事件期间降低重塑费用。
* 神鬼契约改变重塑次数、费用或候选使命范围。

上述内容均属于可选扩展，不影响使命重塑系统的默认规则。

任何扩展规则均应遵循以下原则：

* 不能允许重塑已完成使命。
* 不能绕过同类型替换规则。
* 不能通过付费直接生成已经完成的使命。
* 必须明确费用来源、使用时机与次数变化。
* 必须保留失败不扣费的完整结算原则。
* 不能使点卡或其他场外概念参与游戏内使命重塑。

通过有限次数、递增费用与同类型替换，使命重塑系统能够在保留隐藏目标和路线约束的同时，为玩家提供必要的局势调整空间，使使命系统保持公平、稳定且具有长期策略价值。
