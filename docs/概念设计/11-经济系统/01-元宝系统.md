# 《开天辟地之大地的裂变》元宝系统

## 1. 系统定位

元宝（Coin）是《开天辟地之大地的裂变》世界中的唯一通用货币，也是整个经济系统的核心资源。

无论是玩家之间的交易，还是与各类 NPC、商店及公共设施的交互，均默认使用元宝进行结算。游戏中不再设计金币、银币、钻石等多层货币体系，以降低理解成本，保证经济系统简单直观。

材料、装备、声望、荣誉及其他资源可以参与交换或作为玩法条件，但不具备通用货币职能。点卡仅属于场外可选彩蛋，不参与游戏内经济结算，具体内容将在《02-点卡设定》中说明。

元宝的主要作用不是作为角色成长数值，而是作为连接探索、战斗、交易、制造与资源管理的纽带，推动玩家不断参与游戏循环。

元宝在经济规则中是唯一通用货币，在物品规则中则是占据 `1 × 1` 格的可叠加背包物品。经济系统负责获取、计价、支付和交易规则；元宝进入背包后，其放置、叠加、拾取与临时存放均复用普通物品规则，由背包与物品系统负责实际持有与空间占用，不设置专用的背包放置机制。

当前版本中，每个元宝堆叠最多保存 `5` 个元宝。该数值由物品配置统一维护，经济系统只读取配置与背包结果，不在支付逻辑中写死叠加上限。

每个元宝物品数量单位固定代表 `1` 个元宝，也就是 `1` 个通用货币单位。元宝不区分面额，不设置价值倍率，也不会因为位于不同堆叠而拥有不同价值。因此，一个当前数量为 `5` 的元宝堆叠表示玩家持有 `5` 个元宝，而不是一枚价值为 `5` 的特殊货币。

## 2. 元宝获取方式

玩家可以通过多种途径获得元宝，不同玩法均能够形成相对稳定的经济来源。

### 2.1 战斗收益

玩家击败普通怪物、精英怪物或首领后，可获得一定数量的元宝奖励。

部分副本、世界事件及特殊战斗也可根据完成情况给予额外元宝奖励。具体奖励由对应敌人、战斗或事件自行配置，避免所有战斗采用相同收益标准。

### 2.2 探索收益

地图探索过程中，玩家可以通过开启宝箱、发现遗迹、完成隐藏事件及探索特殊地点等方式获得元宝。

部分地图区域还可设置一次性的隐藏财富或特殊奖励，用于鼓励玩家主动探索未知区域。

### 2.3 任务收益

完成主线任务、支线任务、NPC 委托、悬赏任务以及部分使命后，均可获得元宝奖励。

任务通常是游戏前中期较为稳定的经济来源，其奖励数量应与任务难度、流程长度及风险程度相匹配。

### 2.4 商业收益

玩家可以出售自己不需要的装备、材料、药剂及其他物品获得元宝。

玩家之间也可以通过自由交易获取收益。与地产、经营及公共设施相关的内容，还可根据对应系统产生租金、经营收入或其他商业收益。

### 2.5 随机事件收益

事件、命运、地图彩蛋、地方游戏以及部分特殊剧情，均可能给予玩家一定数量的元宝作为奖励。

此类收益具有一定随机性，主要用于增加游戏过程中的趣味性，不应成为稳定且可无限重复的主要收入来源。

## 3. 元宝消耗方式

元宝参与游戏中的大部分经济行为，是玩家成长过程中持续消耗的重要资源。

### 3.1 商店

各类商店可以出售基础消耗品及日常物资，例如：

* 回复药剂
* 状态恢复药剂
* 食物
* 投掷道具
* 基础装备
* 常见材料
* 其他日常用品

不同城镇及地区的商店可以拥有不同的商品种类、库存及售价，以体现区域差异和探索价值。

### 3.2 铁匠铺

铁匠铺负责装备制造与维护。

玩家掌握对应图纸，并同时提供材料与元宝后，即可委托铁匠打造装备：

```text
已掌握图纸 + 制造材料 + 元宝费用 → 制造装备
```

其中，元宝代表工匠的制造费用。制造完成后，材料与元宝被消耗，已经掌握的图纸作为制造知识永久保留。

除此之外，铁匠铺还可提供：

* 装备修理
* 装备分解
* 装备重铸（后续版本）
* 装备强化（后续版本）

### 3.3 鉴定所

未知图纸、未知装备及部分特殊遗物需要通过鉴定后才能正常使用。

玩家支付一定数量的元宝后，可以获知：

* 图纸配方
* 装备真实属性
* 遗物说明
* 特殊物品信息

鉴定系统用于增加探索过程中的未知感与收集乐趣，不应通过鉴定随机改变物品原本的内容。

### 3.4 酒馆与情报商

酒馆不仅是休息场所，也是玩家获取信息的重要地点。

玩家可以支付元宝：

* 获取附近怪物情报
* 打听隐藏地点
* 获取特殊任务线索
* 获得世界事件消息
* 查询部分 NPC 信息
* 购买悬赏情报

情报原则上只提供探索方向或必要线索，不直接给出事件的完整答案。

### 3.5 驿站

大型地图之间可以通过驿站进行快速移动。

玩家支付一定数量的元宝后，可快速前往已经解锁的重要城镇或据点，减少长距离移动带来的时间成本。尚未解锁的地点不能通过支付元宝直接抵达。

### 3.6 神殿

部分地区设有神殿。玩家可以支付元宝进行供奉，并获得基础服务，例如：

* 恢复生命值
* 消除异常状态
* 解除诅咒
* 获得短时间祝福

神殿提供的是服务而非商品，原则上不出售装备或制造材料。

### 3.7 大富翁广场

玩家可以支付少量元宝参与随机娱乐事件，例如：

* 抽取事件
* 抽取命运
* 参与幸运活动

这些内容主要用于增加游戏中的随机性与趣味性，不应稳定产出远高于参与费用的成长收益。

### 3.8 使命调整

玩家可以消耗一定数量的元宝，对符合条件且尚未完成的个人使命进行调整，例如重置一个使命并获得新的使命目标。

已经完成的使命、公共目标、核心身份目标及决定游戏胜负的最终目标，不能通过元宝重置。使命调整的费用、次数及可调整范围由使命系统统一规定，避免玩家通过反复重置筛选最有利的目标。

### 3.9 社交与规则行为

部分社交行为、地方规则及特殊互动可以消耗元宝发起，例如真心话大冒险、赌博、拍卖或其他由场景定义的规则活动。

此类行为必须明确参与条件、支付时机及结算结果，不允许仅通过支付元宝直接获得游戏胜利。

### 3.10 玩家交易

玩家之间可以自由交易装备、材料、策略牌及其他允许交易的资源，并使用元宝补足双方认可的价值差异。

交易价格由参与玩家自行协商，系统不干预市场价格。经济系统负责校验元宝与交易规则，背包与物品系统负责校验物品归属、数量、存放空间及转移合法性；双方确认后，由统一交易流程完成交换。

## 4. 交易与结算规则

元宝属于角色持有的经济资源，同时以可叠加物品形式存放在背包中，不属于基础属性、派生属性或属性修饰器。

所有元宝数量均使用非负整数，不允许出现小数或负数。玩家当前可用元宝等于其背包内所有合法元宝堆叠的数量总和，系统不再额外维护独立余额。任何需要消耗元宝的行为，均应先校验玩家持有数量及其他前置条件；条件不足时，本次行为不成立，也不会扣除任何资源。

所有价格、奖励与支付参数均直接使用元宝数量表示。例如，某项服务价格为 `3`，表示需要从玩家背包中的合法元宝堆叠中合计扣除 `3` 个元宝数量单位。系统不得按照堆叠数量扣费，也不得再乘以面额、汇率或其他货币换算系数。

临时拾取区中的元宝不属于正式背包持有内容，因此不计入当前可用元宝，也不能用于商店、制造、交易或其他支付行为。玩家必须先将其合法放入正式背包，才能参与经济结算。

元宝支付时，背包与物品系统按照以下稳定顺序扣除合法元宝堆叠：

```text
先按 Y 坐标从小到大
再按 X 坐标从小到大
最后按物品实例标识排序
```

固定顺序只用于保证服务端、回放与日志结果一致，不影响元宝的实际价值。

涉及元宝与物品交换的行为应采用统一的原子结算方式：

```text
校验交易条件 → 锁定交易内容 → 同时扣除与发放资源 → 记录结果
```

若任意条件校验失败，则整次交易取消，不得出现仅扣除元宝、未发放物品，或仅转移物品、未支付元宝的情况。

经济系统不直接修改背包内容。普通物品与元宝堆叠的锁定、扣除、转移和接收结果必须由背包与物品系统提供，并在同一交易中共同提交或共同撤销。

系统应记录元宝变化的来源、去向、数量及原因，以便处理规则追溯、异常排查与后续平衡分析。

## 5. 经济循环

元宝贯穿整个游戏流程，形成稳定且持续的资源循环：

```text
战斗 / 探索 / 任务 / 交易
              │
              ▼
          获得元宝
              │
              ▼
商店 / 铁匠 / 鉴定 / 酒馆 / 神殿
驿站 / 玩家交易 / 大富翁广场
              │
              ▼
 获得装备、补给、情报与成长资源
              │
              ▼
       挑战更高难度内容
              │
              └──────────→ 获得更多元宝
```

整个系统形成“获取资源—消费资源—提升实力—挑战更高难度内容”的正向循环，使玩家始终具有探索、战斗与交易的动力。

元宝的产出与消耗应保持相对平衡。对于可以重复获得的低风险收益，应通过次数、事件刷新、敌人刷新或收益配置进行限制，避免无限刷取导致元宝失去价值。

## 6. 设计原则

元宝系统遵循以下设计原则：

唯一货币原则

元宝是游戏世界中唯一的通用货币，不设计其他常规货币体系。其他物品与资源可以参与交换，但不能替代元宝承担统一计价与结算职能。

循环消费原则

元宝应持续流通于获取与消耗之间，避免因缺少有效用途而长期囤积并失去价值。

多途径获取原则

战斗、探索、任务、经营与交易等多种玩法均应能够获得元宝，保证不同玩法方向的玩家拥有合理收入来源。

成长联动原则

装备打造、图纸鉴定、补给购买与情报获取等内容需要一定数量的元宝支持，使经济系统持续参与游戏成长过程，但不允许元宝直接替代等级、属性、装备或使命本身。

自由交易原则

允许玩家之间自由协商交易内容与价格。系统不直接干预市场价格，但必须保证交易合法、双方确认且完整结算。

整数结算原则

元宝的持有、获取与消耗均采用整数，并遵循数值系统中的整数与边界规则。

配置驱动原则

所有商品价格、服务费用及奖励数值均通过资源配置文件统一管理，不在程序逻辑中写死，以便后续进行平衡调整与版本维护。
