# 《开天辟地之大地的裂变》资源 ID 命名规范

## 1. 设计目的

事件、任务、使命、装备、物品、手牌、NPC 等静态资源均需要稳定且唯一的资源 ID，用于代码引用、资源关联、存档、日志与状态管理。

资源 ID 仅负责唯一标识资源，不承担名称展示或业务描述职责。资源名称、类型、品质与效果均由独立字段保存。

---

## 2. 基本格式

所有资源 ID 统一采用：

```text
<type>_<number>
```

其中，`type` 为单个小写英文类型前缀，`number` 为六位十进制数字。

```text
event_000001
quest_000001
equip_000001
item_000001
```

数字编号有效范围为 `000001` 至 `999999`，不足六位时在左侧补 `0`。`000000` 为保留编号，正常资源不得使用。

---

## 3. 类型前缀

| 资源类型 | 前缀 | 示例 |
| --- | --- | --- |
| 事件 | `event` | `event_000001` |
| 任务 | `quest` | `quest_000001` |
| 使命 | `mission` | `mission_000001` |
| 装备 | `equip` | `equip_000001` |
| 物品 | `item` | `item_000001` |
| 图纸 | `blueprint` | `blueprint_000001` |
| 手牌 | `card` | `card_000001` |
| NPC | `npc` | `npc_000001` |
| Buff | `buff` | `buff_000001` |
| Debuff | `debuff` | `debuff_000001` |
| 地形 | `terrain` | `terrain_000001` |
| 区域 | `region` | `region_000001` |
| 天气 | `weather` | `weather_000001` |
| 技能 | `skill` | `skill_000001` |
| 契约 | `contract` | `contract_000001` |

新增资源大类时，应先在共享资源 ID 配置中登记新的单词前缀。已经投入使用的前缀原则上不得修改。

职业、种族等数量有限且具有固定枚举性质的数据不使用六位数字资源 ID，可以继续使用对应枚举或固定标识。

---

## 4. 分配原则

每种资源类型拥有独立编号空间。同一类型内 ID 必须唯一，不同类型可以使用相同数字编号。

资源 ID 一旦分配应长期保持稳定。资源名称、描述、数值、品质或类型发生变化时，不修改已经确定的 ID。

资源删除后，原 ID 永久废弃，不得重新分配给其他资源。新增资源应从该类型已经分配的最大编号继续顺延。

---

## 5. 业务分离

禁止将名称、子类型、品质或其他业务属性编码进资源 ID。

```text
正确：event_000127
错误：event_combat_rare_000127
```

运行时实例 ID、玩家 ID、对局 ID、效果处理器 ID、本地化字符串键及天气扑克牌面 ID 不属于静态资源 ID，可按照各自模块规范命名，但不得与资源 ID 混用。

---

## 6. 核心规范

整个项目统一遵循：

> **ID 负责唯一标识，name 负责名称展示，其他字段负责业务含义。**

新增或修改资源时，应同时校验格式、前缀、唯一性及引用关系。已经进入存档、日志或其他资源引用的 ID 不得随意修改。
