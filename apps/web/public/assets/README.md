# Web Assets

网页客户端直接加载的静态表现资源。该目录中的文件会由Vite原样复制到构建产物，并通过`/assets/...`路径访问。

资源目录约定：

- `images/`：棋盘、角色、信仰、装备、事件、策略牌和界面图片。
- `audio/`：背景音乐与界面、战斗等音效。
- `fonts/`：项目拥有合法使用权限的字体文件。

文件名统一使用小写英文和连字符，例如`world-tree-icon.webp`。业务代码应引用稳定资源路径，不应把图片转为大段Base64写入源码。

引入外部资源时，应同时确认版权、授权范围和来源记录。与《爱情公寓》相关的原剧素材不可在未获得授权的情况下直接纳入项目资源。
