# Faith Images

存放三种信仰对应的界面外框资源，可用于角色信息、信仰揭示或赛后结算等界面。

当前文件名约定：

- `faith-light.png`：光明（Light）信仰透明外框。
- `faith-chaos.png`：混沌（Chaos）信仰透明外框。
- `faith-balance.png`：中立（Balance）信仰透明外框。

三张外框均使用PNG透明通道，画布内部与外框之外不包含背景图层。外框应保持相同画布尺寸、安全区域和边缘宽度，以便界面在不调整布局的情况下切换不同信仰样式。

信仰图片直接存放于当前目录，不再增加`frames`子目录。新增同类透明资源时继续使用`faith-用途.png`或`faith-信仰.png`的命名方式。
