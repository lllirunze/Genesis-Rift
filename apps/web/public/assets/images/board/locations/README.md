# 特殊地点完整地块资源

本目录存放会完整替代基础地形视觉表现的特殊地点地块，例如城镇、村庄、神殿、港口与遗迹。

逻辑层中，这些内容仍可作为地块附属要素保存，并保留原有基础地形、高度、通行和区域数据；前端检测到对应地点后，应优先渲染本目录中的完整地块图，而不再渲染 `tiles/` 中的基础地形图。

每种地点使用独立目录，文件名统一采用：

```text
<location-type>-<two-digit-variant>.avif
```

例如：

```text
town-01.avif
village-02.avif
```

同一地点类型可持续补充变体。渲染层后续应通过稳定地块标识选择变体，保证同一地块始终显示相同图片。
