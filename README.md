# 开天辟地之大地的裂变

一个致敬《爱情公寓》第三季桌游《开天辟地之大地的裂变》的局域网多人网页桌游项目。

项目采用 React、Node.js 与 TypeScript 构建，并遵循“规则核心独立、服务端权威、配置数据驱动、运行状态与固定规则解耦”的设计原则。当前处于规则核心与服务端编排开发阶段，已经完成多项可独立测试的底层能力，但尚未形成可以完整游玩的游戏流程。

## 当前进度

### 规则核心

目前已经实现以下基础规则：

- 五维基础属性、派生属性通用公式、属性修饰器聚合与角色数值快照
- 最大生命、生命恢复、移动力等派生属性示例配置
- 角色身份与种族初始属性组合、永久属性成长与可扩展运行时资源
- 轻量等级成长、经验获取、升级资格、剩余经验保留与自由属性点分配
- 可复现主随机种子、多随机流、整数随机、概率、权重、选择、洗牌、D6 与 D20
- 使用标准 54 张扑克牌的天气牌堆、抽取、弃牌、重洗与恢复抽取规则
- 平顶六边形立方体坐标、六方向、距离、环数、范围、直线与基础地图结构
- 固定网格背包、等级解锁区域、矩形物品占格、叠加、拆分、移动与临时拾取
- 装备定义、装备栏、属性修饰器聚合及背包与装备栏之间的原子穿戴和卸下
- 元宝物品、余额查询、获得与支付规则，其中每个元宝数量单位固定代表一个元宝

### 服务端编排

服务端已经提供：

- 随机、天气牌、D6 与 D20 的统一调用和日志记录入口
- 经验获取、升级和基础属性点分配服务
- 背包整理、物品拾取、临时存放和装备栏交互服务
- 元宝查询、获得、支付及余额不足处理服务
- 固定格式日志、顺序写入队列、`latest.log`、50 MB 文件轮转与历史归档
- `/health` 健康检查、Socket.IO 服务入口与协议版本握手

### 配置与资源

项目已经配置部分身份、种族、等级、派生属性、角色资源和典型物品数据。网页资源目录已建立，并包含三种信仰外框及部分女性角色 AVIF 立绘。

完整游戏设计位于[概念设计文档](docs/概念设计)，具体开发约束位于[代码开发规范](docs/代码开发规范/01-代码开发规范.md)。

## 技术栈

- React 19 + Vite：网页客户端与资源加载
- Node.js 24 + Socket.IO：局域网权威服务与实时通信入口
- TypeScript：客户端、服务端、规则核心、配置和协议统一类型
- Zustand：客户端本地界面状态
- Vitest：规则核心、服务编排和工具测试
- npm workspaces：单仓多包管理
- Prettier：统一代码与文档格式

## 工程结构

```text
Genesis-Rift/
├── apps/
│   ├── web/                    # React 网页客户端、界面状态与静态资源
│   └── server/                 # Node.js 权威服务、业务编排与运行日志

│   ├── game-core/              # 与 UI、文件和网络无关的纯游戏规则

│   └── shared/                 # 跨端 ID、坐标、品质、物品与协议类型
├── docs/

├── TODO.md                     # 后续开发任务
├── package.json                # 工作区与统一脚本
```

详细目录职责见[工程目录结构](docs/代码开发规范/02-工程目录结构.md)。

## 环境要求

- Node.js `>= 24`
- npm `>= 11`

## 本地运行

安装依赖：

```bash
npm install
```

启动局域网服务端：

```bash
npm run dev:server
```

启动网页客户端：

```bash
npm run dev:web
```

开发时通常需要分别打开两个终端运行服务端和客户端。当前网页只提供工程架构展示，尚未实现房间创建、角色选择和正式棋盘界面。

服务端默认监听 `0.0.0.0:3000`，网页客户端默认由 Vite 提供开发地址。服务端运行日志保存在项目根目录的 `logs/` 中，并在正常关闭或达到容量限制后自动归档。

## 质量检查

执行全项目类型检查：

```bash
npm run typecheck
```

执行全部测试：

```bash
npm test
```

构建网页客户端：

```bash
npm run build
```

检查格式：

```bash
npm run format:check
```

## 当前边界

以下内容仍未形成完整业务闭环：

- 战斗、技能、Buff／Debuff、击倒与战斗结算
- 完整移动消耗、地形、高度、视野与寻路
- 手牌、事件、使命、胜利、复活和神鬼契约规则
- 商店、制造、鉴定及元宝与物品交换的完整原子交易
- 房间、玩家加入、命令同步、断线恢复和局域网多人流程
- 存档、读档、数据库和正式回放
- 角色创建、地图棋盘、背包、装备、日志等正式网页界面
- 可用于完整游戏的地图、装备、策略牌、事件、使命与 NPC 配置

后续工作按照 [TODO](TODO.md) 中的优先级推进。新增规则应优先写入 `packages/game-core` 并保持纯函数或不可变状态更新，再由 `apps/server` 负责权限、编排、日志和网络同步。

## 项目说明

本项目用于朋友之间的桌游设计、规则研究与非商业开发。项目会保留原剧中的经典概念和彩蛋，但具体规则、数值和程序实现均以本项目文档为准。
